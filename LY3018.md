## Safety Considerations

### General Safety

- **Disconnect power** before any electrical work
- Wear **safety glasses** when operating spindle or laser
- Use **hearing protection** during extended spindle operation
- Keep **fire extinguisher** nearby (Class C for electrical, Class B for flammables)
- Ensure **adequate ventilation** for laser work (fumes are hazardous)
- Use **laser safety glasses** rated for your laser wavelength (typically 450nm blue)

### Laser Safety (CRITICAL)

- **Never operate laser without proper eye protection**
- Minimum protection: OD4+ at 445-450nm
- Enclose laser area with non-reflective, fire-resistant materials
- Install interlock switches on enclosure doors
- Post laser warning signs in work area
- Never leave laser unattended during operation
- Keep flammable materials away from laser path

### Electrical Safety

- Double-check polarity before powering on
- Use ferrules on stranded wire entering terminal blocks
- Verify ground connections are secure
- Install emergency stop button in accessible location
- Use surge protector for sensitive electronics

## Upgrade 1: Controller Board Replacement

### Pre-Installation

1. **Document existing wiring**
   - Take clear photos of all connections before disconnecting
   - Label wires with masking tape and marker
   - Note polarity on all connections

2. **Download required software**
   - GRBL configuration tool (e.g., LaserGRBL, Candle, or OpenBuilds Control)
   - Board-specific firmware (if not pre-flashed)
   - Backup existing GRBL settings ($$ command output)

### Removal of Original Controller

1. **Power down and disconnect**
   - Unplug power supply from wall
   - Disconnect all motor cables (X, Y, Z)
   - Disconnect spindle PWM (if applicable)
   - Disconnect limit switches
   - Disconnect any probe/autosquare wiring

2. **Remove controller enclosure**
   - Remove mounting screws (typically M3 or M4)
   - Carefully extract controller from case
   - Retain screws and standoffs for new installation

3. **Inspect and clean**
   - Clean mounting surface with isopropyl alcohol
   - Check for damaged wiring insulation
   - Repair any frayed cables

### New Controller Installation

1. **Mount controller board**
   - Install standoffs if required (typically 6-10mm)
   - Ensure adequate clearance for wiring underneath
   - Orient board for easy access to terminals
   - Apply threadlocker to mounting screws
   - Torque: 1.5-2 Nm (finger tight + 1/4 turn)

2. **Motor connections**

   | Connection | Typical Wire Color | Notes |
   |------------|-------------------|-------|
   | X Motor | Black/Green/Blue/Red | Check phase pairs with multimeter |
   | Y Motor | Black/Green/Blue/Red | Verify movement direction |
   | Z Motor | Black/Green/Blue/Red | Test homing direction |

   **Phase Pair Identification:**
   - Touch two wires together; if motor shaft becomes harder to turn, they're a phase pair
   - Connect one phase to A+/A-, other to B+/B-
   - Swap one phase only if motor runs reversed

3. **Power supply connection**
   - Verify voltage rating (typically 12V or 24V)
   - Use appropriate gauge wire (minimum 18 AWG for spindle)
   - Install fuse on positive line if not built-in
   - Double-check polarity before connecting

4. **Limit switch wiring**
   - Connect X, Y, Z limit switches to respective inputs
   - Enable pull-up resistors in firmware if switches are NO (normally open)
   - Test continuity with multimeter before powering on

5. **Spindle/VFD connection**
   - PWM signal to spindle controller (if variable speed)
   - 0-10V analog output option (on some boards)
   - Relay output for on/off control (minimum 10A rating)

6. **Laser module connection**
   - TTL/PWM signal to laser driver (typically 3.3V or 5V logic)
   - Dedicated 12V/24V power for laser (separate from spindle)
   - Safety interlock connection (if supported)
   - Air assist relay output (optional)

### Firmware Configuration

1. **Flash firmware** (if required)
   - Follow board-specific instructions
   - Common tools: Arduino IDE, PlatformIO, or vendor tool

2. **Configure GRBL settings**

   ```
   $0=10      (Step pulse, microseconds)
   $1=25      (Step idle delay, milliseconds)
   $2=0       (Step port invert, mask)
   $3=0       (Direction port invert, mask)
   $4=0       (Step enable invert, boolean)
   $5=0       (Limit pins invert, boolean)
   $6=0       (Probe pin invert, boolean)
   $10=1      (Status report, mask)
   $11=0.010  (Junction deviation, mm)
   $12=0.002  (Arc tolerance, mm)
   $13=0      (Report in inches, boolean)
   $20=0      (Soft limits, boolean)
   $21=1      (Hard limits, boolean)
   $22=1      (Homing cycle, boolean)
   $23=3      (Homing direction invert, mask)
   $24=25.0   (Homing feed, mm/min)
   $25=500.0  (Homing seek, mm/min)
   $26=250    (Homing debounce, milliseconds)
   $27=1.0    (Homing pull-off, mm)
   $30=1000   (Max spindle speed, RPM)
   $31=0      (Min spindle speed, RPM)
   $32=0      (Laser mode, boolean) [Set to 1 for laser]
   $100=800   (X steps/mm)
   $101=800   (Y steps/mm)
   $102=800   (Z steps/mm)
   $110=5000  (X max rate, mm/min)
   $111=5000  (Y max rate, mm/min)
   $112=3000  (Z max rate, mm/min)
   $120=200   (X acceleration, mm/sec²)
   $121=200   (Y acceleration, mm/sec²)
   $122=100   (Z acceleration, mm/sec²)
   $130=300   (X max travel, mm) [Update for 3040]
   $131=180   (Y max travel, mm) [Update for 3040]
   $132=45    (Z max travel, mm)
   ```

3. **Test basic movement**
   - Home all axes ($H command)
   - Jog each axis individually
   - Verify direction is correct
   - Check step calibration (move 100mm, measure with caliper)

## Upgrade 2: Drag Chain Installation

### Planning and Layout

1. **Determine drag chain specifications**
   - Inner dimension: 10x15mm minimum for spindle cables
   - 15x20mm recommended for spindle + laser
   - Length: Measure travel distance + 20% extra
   - Radius: 28mm minimum (R28)

2. **Mounting locations**
   - **X-axis (gantry):** Mount on rear of X-gantry, route to frame
   - **Y-axis:** Mount on Y-gantry, route to rear of machine
   - **Z-axis:** Mount on Z-plate, route to X-gantry

### Installation Steps

1. **X-Axis Drag Chain**

   a. **Mount fixed end**
      - Attach bracket to rear frame extrusion
      - Position at maximum X travel (opposite side from electronics)
      - Use T-slot nuts or drill/tap holes
   
   b. **Mount moving end**
      - Attach bracket to X-gantry rear extrusion
      - Align with fixed end when X is at home position
      - Ensure chain has smooth bending radius
   
   c. **Install chain**
      - Open chain links fully
      - Thread cables through before attaching ends
      - Secure with end brackets
      - Leave 10-15cm service loop at each end

2. **Y-Axis Drag Chain**

   a. **Mount fixed end**
      - Attach to base frame at rear
      - Position for full Y travel coverage
   
   b. **Mount moving end**
      - Attach to Y-gantry assembly
      - Route perpendicular to X-axis chain
   
   c. **Chain routing**
      - Use 90-degree connector if chains intersect
      - Maintain minimum bend radius
      - Secure intermediate points if span >500mm

3. **Z-Axis Drag Chain**

   a. **Mount fixed end**
      - Attach to X-gantry vertical plate
      - Position at top of Z travel
   
   b. **Mount moving end**
      - Attach to Z-carriage or spindle mount
      - Ensure clearance during full Z travel
   
   c. **Short chain considerations**
      - Use 10x10mm or 7x7mm mini chain
      - Mount on side of Z-axis to avoid interference

### Cable Management

1. **Cable preparation**
   - Group wires by function (power, signals, laser)
   - Use spiral wrap or braided sleeving
   - Leave 20% extra length for flexing

2. **Strain relief**
   - Secure cables at drag chain entry/exit points
   - Use cable glands or grommets in metal edges
   - Avoid sharp bends at chain ends

3. **Cable separation**
   - Keep high-current (spindle, laser power) separate from signals
   - Use shielded cable for limit switches and probes
   - Ground shield at controller end only

## Upgrade 3: 40W Laser Installation

### Laser Module Preparation

1. **Inspect laser module**
   - Verify 40W rating (likely 5.5W optical / 40W electrical)
   - Check compatibility with controller TTL input
   - Identify cooling requirements (air/water)

2. **Mounting bracket fabrication** (if not included)
   - Material: 3-5mm aluminum plate or steel bracket
   - Must align laser beam with spindle centerline
   - Allow quick swap between spindle and laser

### Installation

1. **Mount laser module**
   - Attach to Z-carriage using appropriate bracket
   - Center beam with machine origin
   - Ensure clearance for focus adjustment
   - Mount height: typically 20-50mm from work surface

2. **Wiring connections**

   | Wire | Connection | Notes |
   |------|------------|-------|
   | Red (+) | 12V/24V power | Dedicated supply recommended |
   | Black (-) | Ground | Common with controller ground |
   | White/Yellow | TTL/PWM signal | 3.3V or 5V logic level |
   | Blue | Interlock/Enable | Active low typically |

3. **Cooling system**
   - **Air-cooled:** Ensure fan intake is unobstructed
   - **Assist air:** Connect compressor (10-30 PSI) or air pump
   - **Water-cooled:** Install radiator, pump, reservoir

4. **Safety enclosure** (REQUIRED)
   - Acrylic panels (3mm minimum, orange/amber color)
   - Interlock switches on all access doors
   - Fume extraction port (minimum 100 CFM)
   - LED status indicator

### Alignment and Focusing

1. **Beam alignment**
   - Install red dot pointer if available
   - Verify beam is perpendicular to work surface
   - Check alignment across full X/Y travel
   - Adjust mirror mounts if needed (on CO2 lasers)

2. **Focusing procedure**
   - Place test material (cardboard or wood)
   - Lower Z until laser nozzle almost touches material
   - Fire test pulse at low power (5%)
   - Raise Z in 1mm increments, firing at each level
   - Smallest spot = focal point
   - Record Z height for future reference

## Upgrade 4: 3040 Extension Kit

### Kit Inventory

Verify all components are present:
- Extended aluminum extrusions (2040, longer lengths)
- Additional T-slot nuts and bolts
- Extended lead screws or GT2 belts
- Longer drag chain (if included)
- Extended cable harness (if included)
- Updated limit switch mounts
- Assembly instructions

### Mechanical Installation

1. **Machine disassembly**

   a. **Document current state**
      - Take photos of all assemblies
      - Measure current squareness
      - Note belt/lead screw tension
   
   b. **Remove gantry**
      - Support X-gantry before removing Y rails
      - Disconnect all wiring at drag chain ends
      - Remove Z-axis assembly as unit if possible
   
   c. **Remove Y-axis rails**
      - Remove end plates
      - Extract lead screws/belts
      - Keep all hardware organized

2. **Frame extension**

   a. **Replace base extrusions**
      - Remove original 2040 base rails
      - Install extended length rails
      - Ensure coplanarity (within 0.5mm)
   
   b. **Install extended Y-axis**
      - Mount longer rails to extended base
      - Verify perpendicularity to X-axis
      - Check squareness with carpenter's square
   
   c. **Install extended drive system**
      - **Lead screw:** Install new longer screw with bearing support
      - **Belt drive:** Install longer GT2 belt, check tension

3. **Gantry reinstallation**

   a. **Mount X-gantry**
      - Reattach to extended Y carriages
      - Ensure smooth travel full length
      - Check for binding or excessive play
   
   b. **Install Z-axis**
      - Reattach to X-carriage
      - Verify perpendicular to work surface
      - Check full Z travel

4. **Limit switch relocation**
   - Move switches to new travel extents
   - Extend wiring if necessary
   - Test homing sequence

### Calibration After Extension

1. **Travel verification**
   - X should now travel ~300mm (or kit specification)
   - Y should now travel ~400mm (or kit specification)
   - Measure actual travel with caliper/ruler

2. **Steps per mm calibration**

   ```
   New steps/mm = (Current steps/mm × Commanded distance) / Actual distance
   ```

   - Update $100 for X, $101 for Y in GRBL settings
   - Repeat measurement until error < 0.5%

3. **Max travel settings**
   - Update $130 (X max travel)
   - Update $131 (Y max travel)
   - Verify soft limits if enabled

4. **Acceleration tuning**
   - May need to reduce acceleration for longer axes
   - Test with gradual increases
   - Watch for lost steps or resonance

## Software Configuration

### LaserGRBL Setup

1. **Connection settings**
   - Select correct COM port
   - Set baud rate (typically 115200)
   - Connect and verify ($$ command)

2. **Laser mode configuration**
   - Enable laser mode ($32=1)
   - Set max power ($30=1000 or 255 depending on board)
   - Configure work area size
   - Set origin (front-left or rear-left)

3. **Import settings**
   - Load machine profile for 3018/3040
   - Adjust for extended travel if applicable
   - Save configuration

### LightBurn Setup (Recommended for Laser)

1. **Device setup**
   - Add device: GRBL or GRBL-M3
   - Set work area dimensions
   - Configure origin corner
   - Set homing direction

2. **Import settings**
   - S speed: 1000
   - Max power: 100%
   - Min power: 0%
   - Z offset for focus: Enable if using auto-focus

### CNC Software (for milling)

1. **Candle or OpenBuilds Control**
   - Configure work area
   - Set safe height and plunge rate
   - Configure tool change position

2. **Fusion 360 or FreeCAD post-processor**
   - Select GRBL post-processor
   - Set machine limits
   - Configure retract height

## Testing and Calibration

### Mechanical Testing

1. **Jog test**
   - Move each axis individually
   - Verify smooth motion
   - Listen for unusual noises
   - Check for binding

2. **Homing test**
   - Execute homing cycle ($H)
   - Verify all switches trigger
   - Confirm machine stops at home position
   - Check pull-off distance is adequate

3. **Squareness test**
   - Machine a square test pattern
   - Measure diagonals
   - Adjust if difference > 0.5mm over 100mm

### Laser Testing

1. **Power calibration**
   - Create power scale test (10%, 20%, ..., 100%)
   - Run on material sample
   - Identify optimal settings for each material

2. **Focus test**
   - Verify focus distance with ramp test
   - Mark Z position for each material thickness

3. **Speed calibration**
   - Test engraving speeds (100-5000 mm/min)
   - Determine max speed before quality loss

### Spindle Testing

1. **Speed control**
   - Test PWM range
   - Verify speed stability under load
   - Check for overheating

2. **Runout test**
   - Mount dial indicator
   - Check spindle runout at collet
   - Should be < 0.05mm for good cuts

## Troubleshooting

### Common Issues

| Problem | Possible Cause | Solution |
|---------|---------------|----------|
| Lost steps | Acceleration too high | Lower $120-$122 values |
| Motor stalls | Current too low | Adjust driver pots or firmware |
| Wrong direction | Phase wires swapped | Swap one coil pair |
| Limit switches not working | Wiring or configuration | Check continuity, $5 setting |
| Laser fires continuously | TTL inversion | Check $32, swap TTL wiring |
| Laser weak | Out of focus or wrong power | Check focus distance, max power |
| Drag chain too stiff | Bend radius too tight | Increase chain size or mounting distance |
| Excessive vibration | Loose bolts or resonance | Tighten, check for loose components |

### Diagnostic Commands

```
$?      - Current status
$$      - All settings
$#      - View parameters
$G      - Parser state
$I      - Build info
$N      - Startup blocks
$X      - Kill alarm lock
$H      - Run homing cycle
~       - Cycle start (resume)
!       - Feed hold
?       - Current status
Ctrl-X  - Soft reset
```

## Maintenance Schedule

### Daily
- Clean work area of debris
- Inspect drag chain for cable wear
- Check laser lens cleanliness

### Weekly
- Lubricate linear rails (light machine oil)
- Check belt tension
- Inspect wiring for chafing

### Monthly
- Tighten all bolts to proper torque
- Clean and lubricate lead screws
- Check spindle collet for wear
- Inspect drag chain links for damage

### Quarterly
- Full mechanical inspection
- Check electrical connections
- Calibrate steps/mm
- Back up GRBL configuration

## Appendix B: GRBL Settings Quick Reference

### Critical Settings for Laser

```
$30=1000    - Max spindle speed (matches S1000 in g-code)
$31=0      - Min spindle speed
$32=1      - Laser mode (M4 dynamic power, no dwell)
```

### Critical Settings for CNC

```
$32=0      - Disable laser mode (allows spindle delay)
$30=1000   - Max spindle RPM
$3=0       - Direction invert (adjust if axes reversed)
$23=3      - Homing direction invert
```

| 3018 Extended | 300 | 400 | 45 |

# /webapi

> Control the built-in HTTP API server (/webapi status|enable|disable)

## Overview

`/webapi` manages the axum-based HTTP server that lets any frontend drive the
agent over REST and SSE. With no arguments (or `status`, `help`, `-h`,
`--help`) it prints the help text, the current server state, and a table of the
available endpoints. `enable` starts the server and generates a fresh bearer
token; `disable` stops it.

## Syntax

```
/webapi              Show help, status, and the endpoint table
/webapi status       Same output as the bare form
/webapi help         Same output as the bare form
/webapi -h           Same output as the bare form
/webapi --help       Same output as the bare form
/webapi enable       Start the HTTP server and generate a bearer token
/webapi start        Alias of enable
/webapi disable      Stop the HTTP server
/webapi stop         Alias of disable
```

## Options / Subcommands

| Form | Description |
|------|-------------|
| `/webapi` | Renders the help text, current state, and endpoint table |
| `/webapi status` | Alias of the bare form |
| `/webapi help` | Alias of the bare form |
| `/webapi -h` / `--help` | Aliases of the bare form |
| `/webapi enable` | Starts the server and generates a 40-character alphanumeric bearer token, printing curl usage examples |
| `/webapi start` | Alias of `enable` |
| `/webapi disable` | Stops the running server |
| `/webapi stop` | Alias of `disable` |

## Authentication

- `GET /health` requires no authentication and can be used as a liveness probe.
- Every other endpoint requires the header
  `Authorization: Bearer <token>` where `<token>` is the 40-character
  alphanumeric token generated by `/webapi enable`.
- A new token is generated on each `enable`; enabling again replaces the
  previous token.

## Examples

```
/webapi
```
Prints the help text, the running/stopped status, and the endpoint table.

```
/webapi enable
```
Starts the HTTP server and prints the generated bearer token together with
ready-to-copy curl examples.

```
/webapi start
```
Identical to `enable`.

```
curl http://127.0.0.1:9100/health
```
Liveness check; no `Authorization` header needed.

```
curl -H "Authorization: Bearer <token>" http://127.0.0.1:9100/sessions
```
Authenticated request against a protected endpoint.

```
/webapi disable
```
Stops the HTTP server.

## Output

- Bare / status / help forms: the help block, the current state (running or
  stopped, with the listen port), and a table of the REST and SSE endpoints.
- `enable`: confirmation that the server started, the generated 40-character
  bearer token, and curl examples showing how to call the API.
- `disable`: confirmation that the server stopped.
- Unknown subcommand: a warning message.

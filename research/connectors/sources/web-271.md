The mcp-v8 CLI can be configured entirely by one TOML or JSON file passed via `--config <PATH>` (env `MCP_V8_CONFIG`), with per-setting precedence: explicit CLI flag > `MCP_V8_*` env var > config file > built-in default; keys mirror CLI flags (dashes/underscores interchangeable), relative paths resolve against the server working directory, and unknown, duplicate, wrong-shape, or conflicting keys are fatal startup errors. Structured sections (`wasm`, `mcp_servers`, `fetch_headers`, `policies`, `sandbox`) inline JSON that would otherwise be separate files, covering WASM modules, MCP server modules/OAuth, header injection, Rego/OPA policy hooks, and nono OS sandboxing. The page also documents cluster/Raft settings (e.g., `node_id=node1`, heartbeat 100 ms, election timeouts 300/500 ms), core HTTP/SSE/JWKS/session options, heap/fs persistence, MCP stubs with `runjs__` prefix, module imports, hardening, S3 storage, WASM defaults (`wasm_default_max_memory=16m`), `--heap-memory-max` default 8 MB, and execution timeout default 30 s (max 300 s).

```text
logbook-mcp is an MCP server that turns compatible AI assistants (Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Codex CLI, Gemini CLI) into a persistent local developer logbook, auto-detecting git projects and capturing notes, TODOs, reminders, code TODO/FIXME/HACK/BUG scans, and SQLite FTS5 full-text search with per-project and global scoping. It documents SQLite or Obsidian markdown/YAML-frontmatter storage, auto-migration from SQLite to Obsidian, and 10 MCP tools plus the `logbook://reminders` resource for notes, TODOs, structured entries, queries, topics, tags, reminders, reviews, inbox, and setup. The page warns of a v2.0 breaking change: SQLite is eliminated, only the Obsidian backend is supported, v1 data in `~/.logbook/logbook.db` is not auto-migrated and remains intact, tools drop from 10 to 5 with deprecated shims, and users needing v1 data should stay on `@cocaxcode/logbook-mcp@0.4`. Stack: TypeScript, MCP SDK, better-sqlite3, Zod, tsup; MIT, built by cocaxcode.
```

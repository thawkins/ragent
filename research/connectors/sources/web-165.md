Anthropic’s MCP connector lets Claude call remote MCP tool servers directly through the Messages API without local MCP client setup, using OAuth-based user authorization and bearer credentials, with org-level connector enablement plus per-user authentication. The current beta header is `mcp-client-2025-11-20` (deprecating `mcp-client-2025-04-04`), and the request contract separates `mcp_servers` from `tools`/`mcp_toolset`/`default_config`/`configs`; it supports public HTTPS/Streamable HTTP/SSE endpoints, not local STDIO, and is unsupported on Amazon Bedrock and Google Vertex. Because calls originate from Anthropic cloud infrastructure, endpoints need public reachability, and teams must manage tool allowlisting/denylisting, token scope, retention limits (not eligible for Zero Data Retention), and version migration; the path is tool-call centric and a 2026 support article frames custom connectors as a mainstream, security-sensitive beta with a 30-day rollout pattern emphasizing read-only pilots, per-tool controls, logging, and token rotation.

Model Context Protocol (MCP) is an open protocol for connecting AI systems to external tools, applications, and data sources through a standardized interface that reduces custom integrations. Its architecture uses hosts (AI assistants, enterprise apps, IDEs, agent platforms), clients inside hosts, and servers that expose tools, resources, workflows, APIs, and databases via structured schemas; transport is typically stdio for local deployments and Streamable HTTP for remote ones. MCP interactions include initialization and capability discovery, JSON-RPC-based tool execution and responses, and notifications for dynamic updates. MCP does not replace APIs or LLM function calling but adds standardized discovery, invocation, and governance; enterprise use requires authentication, scoped permissions, and auditability. Celigo positions itself as an execution and orchestration layer that exposes integrations, APIs, workflows, and business processes as MCP-compatible tools, and the FAQ says “MCP IO” lacks a widely recognized official architectural definition while ChatGPT’s MCP use depends on its integrations.

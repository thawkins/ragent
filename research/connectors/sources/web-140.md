acli-helper is a multi-agent MCP server that lets Claude Code, Codex CLI, and Gemini CLI communicate so any agent can delegate tasks, request reviews, or start discussions, running as an HTTP MCP server (FastMCP v3) at `http://127.0.0.1:8787/mcp` with tools including `agent_ask`, `agent_result`, `agent_status`, `agent_reply_input`, `list_conversations`, and `resume_latest`. Setup requires Python 3.12+, uv or pip, and at least two of the three CLIs; its wizard detects installed agents and writes configs for Claude (`.mcp.json`), Codex (`.codex/config.toml`), and Gemini (`.gemini/settings.json`), offering MCP-only or MCP+Skill modes. Calls are async by default (`wait=true` for inline responses), conversations persist in SQLite (`~/.config/acli-helper/conversations.db`) with metadata-only logging by default, and features include intent-based permissions (`discuss`/`review`/`implement`), handoff summaries, stale-session recovery, and an MIT license.

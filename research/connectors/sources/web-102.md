The Arcanada Model Connector (github.com/Arcanada-one/model-connector) is a NestJS + Fastify/TypeScript REST API that exposes AI CLI agents (Claude Code, Cursor, Gemini CLI, Codex) and API providers (OpenRouter with 200+ models, Groq, Grok/xAI, Perplexity, Anthropic, Together, Fireworks, Cloudflare Workers AI, Mistral, and a BGE-M3 embedding connector) via `/execute` and `/connectors/:name/execute`, authenticated by Bearer keys except `/health`; it requires Node.js 22+, pnpm, PostgreSQL, and Redis, returns HTTP 201 on successful `/execute`, and provides TypeScript and Python SDKs. A native `vertex-generative` connector calls the unary regional Vertex AI `projects.locations.publishers.models:generateContent` REST method, configured with `VERTEX_GENERATIVE_PROJECT`, `VERTEX_GENERATIVE_LOCATION`, and CSV `VERTEX_GENERATIVE_MODELS`, using runtime injected async bearer-token auth; it does no ADC, metadata-server, gcloud, or credential-file discovery, does not refresh models on boot, and has no streaming in this increment. Documented features include output-guard v0.2.0 structured-output enforcement with `schema`/`output_format` and `repair_report`, idempotency keys for single-connector `/execute` (rejected on multi-provider surfaces), per-connector:model circuit breakers (default threshold 5, cooldown 30s), automatic retries (default 1), concurrency/queue limits, bcrypt-hashed API keys in PostgreSQL, and admin/policy APIs. Reported latencies range from ~0.15–0.7s for Groq and ~0.2s for embeddings to ~4s for Claude Code, ~6–12s for Codex, ~8–22s for Gemini, and ~10s for Cursor.

Agentic Developer MCP wraps OpenAI’s Codex CLI as an MCP server via the TeaBranch/open-responses-server middleware, and notes the engine may be replaced with OpenCode or Amazon Strands. It requires Node 22 and consists of Codex CLI, a Node.js Express MCP wrapper, and open-responses-server; Docker setup starts the wrapper on port 8080 and open-responses-server on port 3000, while manual setup uses `npm install`, global `@openai/codex`, `node mcp-server.js`, and `pip install -e .`. The server supports stdio or SSE transport (e.g., port 8000) and exposes tools `run_codex` (repository, optional branch/folder, request) and `clone_and_write_prompt` (repository, request, optional folder), with `.agent/mcps.json` registering MCP tools and implementation in `mcp_server/server.py` using the MCP Python SDK; license is MIT.

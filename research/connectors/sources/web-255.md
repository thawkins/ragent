The bencounsell/elements-mcp-server is an MIT-licensed Model Context Protocol server that gives AI agents access to RapidWeaver Elements documentation, CorePack components, and DevPacks tutorials by indexing three repositories: rapidweaver-elements-docs-api, RWElementsCorePack (28 production-ready components), and RWElementDevPacks. It provides unified search, a three-tier learning path (docs concepts → tutorial examples → production code), auto-cloning/updating of repositories, and browsable MCP resources, with tools including `elements_help`, `elements_browse`, `elements_reference`, and `elements_example`. Setup uses `npm install`/`npm run build` and a Claude Desktop or Cursor MCP config pointing to `node /absolute/path/to/elements-mcp-server/dist/index.js`; env vars include `ELEMENTS_MCP_CACHE_DIR` (default `~/.cache/elements-mcp`) and `ELEMENTS_MCP_AUTO_UPDATE` (default `true`), with first startup taking ~30s and subsequent startups ~2-3s.

freqtrade-mcp (github.com/yalcin/freqtrade-mcp) is a personal/research, read-only MCP server that gives LLM agents introspection of the live Freqtrade codebase—overridable IStrategy methods, classes/MRO, enums, codebase search, callbacks, config schema, DataFrame columns, version info, and optional markdown docs—to help generate more reliable Freqtrade strategy code. It explicitly does not execute trades, connect to exchange APIs, or manage funds; security features include strict allow-lists/length limits, no eval/exec, use of inspect/ast, source parsing without imports, namespace restriction to freqtrade.*, and local-only stdio. It requires Python >=3.13, Freqtrade >=2026.2, and mcp[cli] >=1.26.0,<2.0, and should be installed as freqtrade-mcp-server in the same environment as Freqtrade (avoid pipx/uvx); FREQTRADE_DOCS_PATH enables docs with a 1-hour cache, and FREQTRADE_MCP_LOG_LEVEL defaults to WARNING. Claude Code CLI and Codex CLI configs are tested, while Claude Desktop and Codex desktop/IDE configs are documented but untested; it is GPLv3, the author used Claude Opus as a coding assistant, disclaims liability, and advises thorough backtesting.

codex-cli-mcp is an MIT-licensed MCP server that wraps OpenAI Codex CLI as tools, enabling MCP clients like Claude Desktop, Cursor, and Windsurf to run Codex CLI sessions in headless mode for code generation/execution via prompts; it provides `codex` (new session) and `codex-reply` (continue via `threadId`) tools, with parameters including prompt, model, effort (`medium`/`high`/`xhigh`/`max`), sandbox (`read-only`/`workspace-write`/`danger-full-access`), cwd, profile, config, and timeout (default 600000 ms/10 min). Prerequisites are Codex CLI (e.g., `npm install -g @openai/codex` or `brew install --cask codex`) and authentication via ChatGPT (Plus/Pro/Team/Edu/Enterprise) or `OPENAI_API_KEY`, and setup uses `npx -y @nayagamez/codex-cli-mcp` in `claude_desktop_config.json`/MCP settings or `claude mcp add codex-cli-mcp -- npx -y @nayagamez/codex-cli-mcp`. The server spawns `codex exec --json --full-auto`, streams JSONL events with progress notifications, uses an idle-based timeout reset by events (default 10 min; override per-call or via `CODEX_TIMEOUT_MS`), supports env vars `CODEX_CLI_PATH`, `CODEX_TIMEOUT_MS`, and `CODEX_MCP_DEBUG`, and its changelog shows v0.4.2 (Aug 10, 2026) with 2 tool updates.

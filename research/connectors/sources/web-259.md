```text
Zed calls MCP servers “context servers” and keeps their configuration in its main settings JSON—not a dedicated MCP file—under the root key `context_servers`, so configs copied from Cursor, Claude Code, or VS Code need adjustments; custom entries require `"source": "custom"` and no `type` field. Servers can be added via the recommended extension route (`zed: extensions`, or Settings > AI > MCP Servers > Add Server > Install from Extensions; Zed manages the process, updates, and config modal) or via Add Local Server/Add Remote Server for custom, pinned, or non-extension servers. Files are at `~/.config/zed/settings.json` (user) and `.zed/settings.json` (project, overriding user), and status is checked in Settings > AI > MCP Servers, where a green dot means active; troubleshooting includes JSON validity, correct root key, command availability, and `${VAR}` environment expansion. For committed project files, use environment variable references rather than literal secrets, since custom `.zed/settings.json` entries are more reproducible for teams than extension-managed servers.
```

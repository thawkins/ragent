The `MCPServer` class in mcp-framework is the entry point for MCP applications, handling initialization, recursive auto-discovery from `src/tools/`, `src/resources/`, and `src/prompts/`, transport setup, and lifecycle management. Its constructor accepts optional `name`, `version`, `transport`, and `basePath`; defaults use package.json metadata, the process working directory, and `stdio`, while SSE transport supports options such as port, CORS, and JWT authentication. Calling `start()` scans and registers components, initializes the configured transport, and accepts client connections. Created by `@QuantGeekDev` (Alex Andrushevich), mcp-framework reports 3.3M+ npm downloads, 145 releases, and is officially on Anthropic’s MCP servers repository; the reference was published 2026-04-01.

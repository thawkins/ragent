```text
mcp-sync is an MIT-licensed Node.js (>=22) CLI that bidirectionally syncs MCP server configurations between Claude Code and Codex CLI, reading Claude configs from `~/.claude.json`, `~/.claude/.mcp.json`, and optional project `.mcp.json` (precedence: global < user < project) and Codex config from `~/.codex/config.toml`. It is non-destructive (creates `.bak` backups, preserves existing settings), transport-aware (stdio and HTTP with auth headers), detects conflicts, and supports dry-run; commands include `status`, `claude-to-codex`, `codex-to-claude`, and `diff`, with flags like `--dry-run`, `--force`, `--project-mcp`, `--claude-config`, and `--codex-config`. It normalizes configs, diffs additions/matches/conflicts, and translates between Claude’s JSON and Codex’s TOML.
```

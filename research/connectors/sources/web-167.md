An MCP server lets Claude, ChatGPT, Copilot, or Cursor read SAP S/4HANA from its HANA database read-only, using SAP’s data dictionary as tools; it requires Docker, network access to the HANA SQL port, and a database user from SAP Basis. Setup involves creating an `MCP_READER` user in the ABAP schema tenant (usually `SAPHANADB`) with SELECT grants on dictionary/organization tables such as `DD02L`, `DD03L`, `DD04T`, and `ACDOCA`, then running AnythingMCP’s quickstart Docker Compose stack and installing the SAP S/4HANA (HANA SQL) connector with host, port `3<instance>15`, tenant, schema, SAP client, and the reader user. Claude Code can connect via `claude mcp add --transport http sap-hana http://localhost:4000/mcp --header "X-API-Key: <key>"`; for claude.ai or ChatGPT, only the MCP endpoint should be published over HTTPS, never the HANA port. The server provides 10 tools—data model guide, dictionary lookups, CDS view search, org structure, and one read-only `SELECT`—with `SET TRANSACTION READ ONLY` on every session, a 1,000-row cap, statement timeout, blocked HR tables, per-MCP-server roles, and an audit log of every call.

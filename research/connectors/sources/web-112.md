The Claude Agent SDK supports structured outputs by having agents return validated JSON that matches a user-defined JSON Schema after multi-turn, tool-using workflows; for single API calls without tools, it directs users to API Structured Outputs. Users define a schema, set `outputFormat` with `type: "json_schema"` in query options, and read validated data from `message.structured_output`, with TypeScript Zod and Python Pydantic integrations offering type inference and runtime validation. Supported schema features mirror API Structured Outputs—basic types, `enum`, `const`, `required`, `additionalProperties` (must be false), string formats like `date-time`, `email`, and `uuid`, plus `$ref`/`$def`/`definitions`—and schema-matching failure produces an `error_max_structured_output_retries` result. A TODO-tracking example shows an agent autonomously using Grep and Bash to return TODO text, file, line, author, and date.

The automateyournetwork/pyATS_MCP project is an experimental MCP Server wrapping Cisco pyATS and Genie, enabling structured interaction with Cisco IOS/NX-OS devices defined in a pyATS testbed over STDIO using JSON-RPC 2.0 (no HTTP/SSE). It runs in continuous default mode via `python3 pyats_mcp_server.py` or one-shot via `--oneshot`, supports Docker and LangGraph integration, and uses `PYATS_TESTBED_PATH` for the testbed. Exposed tools via `tools/discover`/`tools/call` include `run_show_command`, `run_ping_command`, `apply_configuration`, `learn_config` (`show run brief`), and `learn_logging` (`show logging last 250`), returning parsed or raw output; inputs use Pydantic validation and unsafe commands like erase, reload, and write plus pipe/redirect abuse are blocked. Author John Capobianco is identified as Product Marketing Evangelist, Selector AI, and author of Automate Your Network.

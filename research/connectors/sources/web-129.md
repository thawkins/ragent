The article describes Claude Code MCP servers as a standard interface for connecting Claude to external tools, with three transports (stdio, HTTP—recommended for cloud—and deprecated SSE as of early 2026) and three config scopes (local, project `.mcp.json`, user). It recommends starting with GitHub (official HTTP server with PAT), PostgreSQL, Filesystem, Sentry, and Context7, while noting MCP extends reach but not permissions, which remain with hooks/permissions. It stresses security and cost: tool definitions consume context (five servers can add 20–30 definitions per session), tool poisoning/rug pulls are real, so install only trusted sources, run Invariant Labs’ `mcp-scan`, use least privilege/read-only access, keep servers few, and store credentials in env vars rather than committed `.mcp.json`.

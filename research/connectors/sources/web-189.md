Code Composer Studio (CCS) offers AI coding assistance through bundled functionality, third-party extensions on Open VSX, and MCP (Model Context Protocol) servers that let AI assistants interact with CCS project and debug servers. The AI Assistant Configurator view—accessed via “Set up an AI assistant” in Get Started or Help > Get Started with AI—currently supports only Claude Code with the Anthropic provider, and configures Connection Settings (Auth Token, Base URL, optional Custom Headers/Model; Workspace settings override Global) plus optional CCStudio ecosystem MCP servers for building, debugging, monitoring, and controlling SysConfig. MCP servers run only while CCS is running with an AI-configured workspace and auto-start/stop; applying settings auto-installs the Claude Code extension (not desktop/CLI) and requires Git. Other Open VSX assistants may work but are not fully supported; MCP servers are designed for any MCP-capable assistant, though only Claude Code is fully tested, using `[CCSINSTALLDIR]/ccs/tools/node/node` and `mcp-server-proxy.js` paths for Debug, Build, projectSysConfig, and Serial (UART). Theia AI is bundled as an option, and CCS cautions that AI suggestions may be incorrect or suboptimal.

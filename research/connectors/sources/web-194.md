```text
Microsoft 365 agent connectors are a manifest mechanism (`root-agent-connectors`, m365-app-1.30) that lets agents access external systems, often through an MCP Server or OpenAPI descriptions for external HTTP APIs, and can be used within the same Unified App Manifest or as a standalone resource referenced by other M365 apps. The schema requires `id` (max 64) and `displayName` (max 128, localizable); optional `description` is max 4000, and `toolSource` must contain exactly one of `plugin` (requires `id` and `file`), `remoteMcpServer` (requires `mcpServerUrl`, optional `mcpToolDescription` file, and authorization type `None`, `OAuthPluginVault`, `ApiKeyPluginVault`, `DynamicClientRegistration`, or `AzureKeyVault` with `referenceId` for non-None), or `localMcpServer` (requires `mcpServerIdentifier` with similar tool description and authorization options). Last updated 2026-08-11.
```

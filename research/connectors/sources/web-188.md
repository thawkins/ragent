The Model Context Protocol (MCP) is an open standard created and open-sourced by Anthropic in late 2024 that connects AI applications to external data and actions through a host-managed client-server model, in which servers expose tools, resources, or prompts via JSON-RPC over stdio or Streamable HTTP. It has been adopted by Claude, Claude Code, ChatGPT, OpenAI, Google, VS Code, Cursor, and hundreds of official/community servers, but reuse still depends on each client’s supported transports, authentication, capabilities, and permissions. MCP enables controlled access to CRMs, databases, calendars, and infrastructure for workflows, yet security requires least-privilege scoping, server vetting, audit logging, gated sensitive systems, and GDPR consideration for UK businesses. Ampliflow uses MCP in production for Amplex workflows alongside direct APIs and existing integrations, noting MCP support in the Claude Agent SDK does not remove integration testing.

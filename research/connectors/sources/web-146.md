```text
Claude Code uses MCP (Model Context Protocol), an open standard, as an MCP client to connect to external tools, databases, and APIs; servers can be added via `claude mcp add`, JSON config (`~/.claude.json`, `.mcp.json`), or imported from Claude Desktop, with HTTP recommended over deprecated SSE and stdio for local processes. Configuration scopes are local (private, `~/.claude.json`), project (shared, `.mcp.json`), and user (global), with precedence local > project > user; recommended servers include GitHub, Playwright, Sentry, PostgreSQL/Supabase, and Figma. Tool Search reduces MCP context usage from roughly 72,000 tokens to about 8,700 tokens (85% reduction), activates when tool definitions exceed 10% of context, requires Sonnet 4/Opus 4, and improved Opus 4 tool-selection accuracy from 49% to 74%; common issues include connection-closed/PATH errors, SSE timeouts, command-not-found, JSON syntax errors, and macOS permissions.
```

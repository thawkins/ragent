Docusign’s guide describes the Docusign Connector for Anthropic Claude, built on Anthropic’s open Model Context Protocol (MCP), now available in the Claude Connectors Directory to let Claude securely access Docusign IAM and eSignature capabilities, including agreement metadata, status, clauses, insights, and workflow actions, within Docusign OAuth permissions and governance. The Docusign MCP Server is in Open Beta for both developer and production accounts with no intake form or approval; developers can connect a custom connector using an Integration Key and Secret Key with the remote MCP URL `https://mcp-d.docusign.com/mcp`, while production users can browse connectors and add Docusign. It supports envelope management, Workflow Builder routing, and Agreement Manager queries via natural-language prompts, though constraints include model variability, permission scopes, possible human review, latency, and not all IAM tools in every environment. Although focused on Claude, the MCP server can also be used with other MCP clients, GitHub Copilot, and agent frameworks.

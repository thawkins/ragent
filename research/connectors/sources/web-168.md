HubSpot MCP Server is HubSpot’s official hosted Streamable HTTP endpoint at https://mcp.hubspot.com, with Claude clients using https://mcp.hubspot.com/anthropic (Claude Code: `claude mcp add --transport http hubspot https://mcp.hubspot.com/anthropic`); it is free with any HubSpot subscription but requires first-time Super Admin authorization, OAuth 2.0 (migrating to OAuth 2.1 with PKCE/refresh-token rotation), and a paid Claude plan for Claude’s packaged connector. It provides read/write access to core CRM objects (contacts, companies, deals, tickets, invoices, quotes, orders, subscriptions, segments) and engagements (calls, emails, meetings, notes, tasks), plus read-only access to users, teams, roles, campaigns, landing pages, website pages, and blog posts. Because HubSpot hosts it, users cannot self-host, extend, or see tool implementations; HubSpot controls the tool surface and rate limits, write tools can be set to require approval, access is revocable, and the less-capable community alternative is `baryhuang/mcp-hubspot` (Python, API-key based).

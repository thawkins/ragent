```text
AWS announced cross-account and cross-role access for the AWS Model Context Protocol (MCP) Server, part of the Agent Toolkit for AWS, letting developers using AI coding agents such as Kiro, Claude Code, or Codex work across multiple AWS accounts and IAM roles in a single session with no restarts. Previously, switching profiles required stopping the AI coding session, updating local AWS credentials, and restarting the MCP server; now agents can specify a profile per command, with each request identifying the profile to avoid commands reaching the wrong account. Examples include querying CloudWatch logs across production and staging accounts or updating a Lambda configuration in one account and an S3 bucket policy in another within the same conversation; the feature is available in US East (N. Virginia) and Europe (Frankfurt) Regions, with setup guidance in the Multi-profile support section of the Agent Toolkit for AWS user guide.
```

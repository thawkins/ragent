Anthropic’s MCP Connector is a proprietary Messages API feature—not a standalone MCP server—that connects Claude to any remote MCP server supporting streamable-http by adding the `mcp_servers` parameter (URL and name, with optional per-server OAuth tokens and tool allow/deny lists); Anthropic handles connection management, tool discovery, error handling, and execution, so Claude sees remote tools as native API tools. It works with vendor-hosted remote servers such as Vercel, Heroku, Postman, and Stripe, and TypeScript SDK helpers like `mcpToolResultToContent` bridge MCP and Claude API types. It is limited to the Anthropic API—not Claude Desktop, Cursor, or other MCP clients—and as of Feb 2026 is beta, requiring the header `anthropic-beta: mcp-client-2025-11-20`; setup is moderate, license proprietary, stars 0.

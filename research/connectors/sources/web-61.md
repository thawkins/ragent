SchemaStore.org is an open-source, community-owned central catalog of JSON, YAML, and TOML schemas used by editors and tools for validation, completion, and in-context documentation, with supporting editors loading schemas automatically after the next sync. Its public JSON API lists JSON Schema files for known formats and exposes metadata in a format with required `name`, `description`, and `url` fields—where `url` is an absolute URI—plus an optional `fileMatch` property; CI/CD tools can also detect and validate JSON/YAML files when a matching schema exists. The project encourages contributions of new schemas, modifications, and test files, and notes a history of accepting most pull requests.

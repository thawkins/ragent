claudeai-mcp-bridge is an independent, experimental stdio MCP server that exposes claude.ai connectors—Slack (13 tools), Atlassian (31 tools for Jira CRUD/transitions/search and Confluence CRUD/search/comments), Gmail, and Google Calendar—to any MCP client, including OpenCode, Claude Desktop, Cursor, Cline, Windsurf, Continue.dev, and Zed, with zero credential setup. It reads the OAuth token from macOS Keychain (Linux/Windows fallback: `~/.claude/.credentials.json`, written by Claude Code), discovers connectors via `api.anthropic.com/v1/mcp_servers`, and proxies calls through `mcp-proxy.anthropic.com` over Streamable HTTP; tool names follow `{connector}_{tool_name}`. Configuration includes `CLAUDEAI_MCP_DEBUG`, `CLAUDEAI_MCP_TIMEOUT` (default 30000 ms), `CLAUDEAI_MCP_FILTER`, and `CLAUDEAI_MCP_EXCLUDE`. The project is not affiliated with or supported by Anthropic, uses undocumented internal APIs that may change, warns that using Claude subscription tokens outside official clients may violate Anthropic’s Terms of Service, and is MIT-licensed.

Unstructured Transform converts documents in PDF, Word, PowerPoint, Excel, HTML, email, scanned-image, and ~70 other formats into Markdown, element-level JSON, HTML, or plain text. It uses a configurable asynchronous pipeline that partitions content into elements with layout/page metadata, optionally enriches via vision-language passes (image/table descriptions, table-to-HTML, named-entity recognition, generative OCR), chunks for retrieval, generates vector-store embeddings, and can extract structured JSON against a provided or auto-drafted schema; each request supports up to 10 files at 50 MB per file, with results delivered via short-lived download link. Common uses include grounding answers in policies/contracts, building searchable Q&A corpora, extracting fields from forms/invoices/contracts, and preparing RAG document sets; it requires a free Unstructured account, with more at docs.unstructured.io/transform. The connector is third-party, and Anthropic states it does not control or verify developer tools.

ckreiling/mcp-server-docker is an MCP server for managing Docker with natural language, supporting container composition, introspection/debugging, and Docker volume management for server administrators, tinkerers, and AI enthusiasts; its demo shows a WordPress deployment. It can be installed via PyPI with `uvx` or as a Docker image (mounting `/var/run/docker.sock`), configured for Claude Desktop, SSH remote daemons via `DOCKER_HOST=ssh://...`, or Devbox. It offers a `docker_compose` prompt with a plan+apply loop and project resumption, container stats/logs resources, and tools for containers, images, networks, and volumes. It warns against sensitive data, urges review of created containers, and does not support options like `--privileged` or `--cap-add/--cap-drop`; configuration uses the Python Docker SDK's `from_env`.

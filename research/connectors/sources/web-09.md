Squirrelscan says Codex can connect to its hosted MCP server in two commands—`codex mcp add squirrelscan --url https://mcp.squirrelscan.com/mcp` and `codex mcp login squirrelscan`—letting Codex call native tools like `run_audit`, `get_report`, and `list_issues` to audit sites, read reports, and work the issue tracker. Local squirrel CLI audits are free with no account and run 260+ checks across SEO, performance, security, and accessibility, while the hosted cloud adds browser rendering, scheduled audits, an issue tracker, and shareable reports, with 500 free credits/month then pay-as-you-go. For CI/headless use, Codex can use `--bearer-token-env-var SQUIRRELSCAN_API_KEY`; MCP servers can be inspected with `codex mcp list`/`get` or scoped to a project via `.codex/config.toml`.

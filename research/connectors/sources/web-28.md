To use the Kiteworks MCP Server connector in Claude Desktop, an administrator must first enable Kiteworks MCP in the Admin Portal; users then install it via Customize → Connectors, enter their Kiteworks instance URL, accept the Data Access Terms, optionally enable the default-off destructive operations toggle, and authenticate. Creating Kiteworks Forms requires the connected account to have the Form Builder role (check Users → User Management), or Forms creation tools remain unavailable. Tool permissions group operations into read-only (GET) and write/delete (POST/PUT/DELETE) types with three levels—Always allow, Needs approval, or Blocked—and the recommended starting point is Always allow for read-only tools and Needs approval for write/delete tools. Disabling the connector suspends Claude’s Kiteworks access without removing configuration, while Uninstall fully removes it.

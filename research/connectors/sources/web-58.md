This guide explains connecting Claude Desktop to the AI Verde Data Store MCP server over Streamable-HTTP via the Connectors UI. Prerequisites include Claude Desktop, a Claude Pro plan (free-plan users cannot add connectors), and CyVerse credentials unless using anonymous access. In Claude, go to File → Settings → Connectors → Add custom connector. For anonymous access, use name “AI-Verde Data Store Public” and URL `https://mcp-public.cyverse.ai/mcp`; for full access, use name “AI-Verde Data Store” and URL `https://mcp.cyverse.ai/mcp`, logging in with Client ID `mcp-client` and an empty Client Secret. Verify by opening a chat and making a simple request.

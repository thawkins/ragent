MuleSoft’s Anypoint Connector for MCP uses the Model Context Protocol to let MCP-compatible AI clients invoke and interact with APIs, connectors, and apps, exposing complex endpoints as simpler atomic tools or resources for agentic clients such as Claude, Cursor, and Windsurf. Mule apps can act as both an MCP server and client, running inside Mule without separate hosting, and support Streamable HTTP (recommended) and SSE (deprecated) transports, custom response headers on `/sse`, `/message`, and `/mcp`, and distributed tracing. Streamable HTTP enables multiple MCP server instances behind a load balancer via a single endpoint like `/mcp`; SSE server is limited to single-replica deployments, while SSE client is unaffected. Common use cases include customer service, sales, and marketing.

Slate MCP can be connected to OpenAI Codex CLI to create and manage Slate courses from the terminal; Codex CLI and Codex Desktop share the same config file, so setup works for both. It requires the Codex CLI and a Slate account on a Standard or Pro plan, and setup involves adding `[mcp_servers.slate]` with `url = "https://mcp.slatebuilder.io/mcp"` to `~/.codex/config.toml`, then starting a fresh Codex session and authorizing once via browser. Example uses include checking Slate credit balance via `check_credits`, creating a 45-minute leadership training course, listing courses by last updated, previewing an IT security course outline, opening a review, and summarizing review feedback; troubleshooting covers config/session issues, browser authorization problems, and possible rate limits.

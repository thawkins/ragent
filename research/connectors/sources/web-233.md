```text
The `drift-connectors` crate (v0.1.1) provides session connectors for Drift AI, the AI-native blame CLI. Each connector implements `drift-core`’s `SessionConnector` (`discover()`, `parse()`, `extract_code_events()`) for an agent’s on-disk session format: `claude_code` reads `~/.claude/projects/<proj>/<uuid>.jsonl` (Claude Code Messages-API-flavoured transcripts with Write/Edit/Bash tool calls), `codex` reads `~/.codex/sessions/<date>/<uuid>.jsonl` (OpenAI Codex CLI output with `apply_patch` add/update/delete/move semantics), and `aider` is feature-gated but a stub. It is not usually depended on directly—the drift CLI selects the full set via `default_connectors()` behind `default = ["claude-code", "codex"]`—and is licensed under Apache-2.0.
```

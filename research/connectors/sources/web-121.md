Codex MCP Tool is an open-source Model Context Protocol server that connects MCP clients such as Claude and Cursor to the Codex CLI for non-interactive `codex exec` automation, sandboxed edits with approvals, @-file analysis, streaming progress, and structured OLD/NEW change output. Latest v1.2.4 adds cross-spawn-based Windows compatibility across Windows/macOS/Linux; it requires Node.js v18.0.0+ and an authenticated Codex CLI, installs via `npx -y @cexll/codex-mcp-server` or `claude mcp add codex-cli`, and supports models gpt-5-codex (default), gpt-5, o3, o4-mini, codex-1, codex-mini-latest, and gpt-4.1. It provides sandbox modes read-only/workspace-write/danger-full-access, approval policies never/on-request/on-failure/untrusted, tools `ask-codex`, `brainstorm`, `ping`, `help`, slash commands `/analyze`, `/sandbox`, and since v1.2.0 smart defaults plus automatic `--skip-git-repo-check`; it is MIT-licensed and an unofficial third-party tool not affiliated with OpenAI.

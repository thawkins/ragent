```text
MCP (Model Context Protocol) is an open protocol that lets Claude Code connect to external services by configuring servers in `.claude/settings.json`; servers expose tools and resources that Claude Code calls during sessions. Installation methods include `npx` (recommended for npm packages), direct commands for Python/Go servers, and Docker, with essential setups for filesystem access, PostgreSQL, GitHub, web fetch, and memory/knowledge graph. The awesome-mcp-servers repo has 85K+ stars and indexes 200+ community servers across 30+ categories, while claude-code-templates includes 55+ MCP configurations; MCP servers run with user permissions, should be source-reviewed, filesystem-limited, and use environment variables for secrets. There is no hard limit on simultaneous servers, but keeping under 10 is recommended, and each server’s tool definitions add ~100–500 tokens per session; MCP is cross-client compatible, and Cursor added support in 2025.
```

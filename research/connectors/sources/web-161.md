Scalar's September 2026 guide explains that MCP servers are either remote (HTTPS URL) or local (stdio command), and Claude connects to them via `claude mcp add` in Claude Code, Customize > Connectors in claude.ai/Claude apps, or `claude_desktop_config.json`/`.mcpb` for Claude Desktop local servers. Claude Code supports both remote and local servers with local, project (`.mcp.json`), and user scopes; claude.ai and mobile support only remote custom connectors, available on Free (one max), Pro, Max, Team, and Enterprise plans, and claude.ai connectors follow the account into Desktop/mobile/Claude Code when signed in with a claude.ai subscription. Remote connectors are reached from Anthropic's cloud, so localhost or private-network servers cannot be used as custom connectors; authentication is typically OAuth or headers. Examples include Scalar's public docs server at `https://scalar.com/mcp` (no sign-in; one `search-documentation` tool) and Scalar-hosted installations at `https://mcp.scalar.com/mcp/YOUR_INSTALL_ID`, with troubleshooting for 401s, pending approval, a 10,000-token warning/25,000-token default output cap (`MAX_MCP_OUTPUT_TOKENS`), and `MCP_TIMEOUT`; menu paths and plan limits were checked against Anthropic docs on 26 September 2026.

Claude Connectors, powered by Anthropic's open Model Context Protocol (MCP), let Claude access external tools and data sources such as Google Drive, Gmail, Google Calendar, GitHub, Slack, Microsoft 365, and 200+ others. Connectors take several forms—prebuilt first-party integrations, remote MCP servers (via HTTPS), MCP Apps that render interactive UI in-thread, MCP Bundles (.mcpb desktop extensions), and local MCP plugins—and work across Claude.ai, Desktop, Mobile (beta), Claude Code, and Claude Cowork. Claude dynamically surfaces relevant connectors without paid placement, confirms purchases first, and does not use connected-app data to train models. Developers can build a connector using the MCP SDK (exposing tools via HTTPS/SSE), register it in `claude_desktop_config.json`, and submit it to the Connectors Directory; API builders can pass `mcp_servers` (e.g., Asana, Gmail) alongside `tools` like `web_search` in `/v1/messages` calls, filtering responses by block types `mcp_tool_result`, `mcp_tool_use`, and `text`. The Connectors Directory launched July 2025 with 200+ integrations, and consumer connectors (Uber, Spotify, Instacart, TripAdvisor, Resy, Audible, AllTrails) were added in April 2026 on all plans.

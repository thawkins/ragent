```text
Google Cloud Developer Connect account connectors link a Google Cloud account to an individual account on non-Google developer tools providers, with OAuth scopes controlling data access and organization-level connections authorizing individual accounts. They can use pre-configured OAuth clients for GITHUB, GITLAB, or BITBUCKET_CLOUD, or custom OAuth clients for GITHUB_ENTERPRISE, GITLAB_ENTERPRISE, or BITBUCKET_DATA_CENTER; setup requires a billing-enabled project, enabling the Developer Connect API (which also enables Secret Manager API), optional CMEK, and the Developer Connect OAuth Admin role (`roles/developerconnect.oauthAdmin`). Creation is via Google Cloud console or `gcloud alpha developer-connect account-connectors create`, using a custom redirect URI of the form `https://developerconnect.google.com/redirect/custom/projects/<project_number>/locations/<location>/accountConnectors/<account_connector_id>`, plus host/auth/token URIs, client ID/secret, optional proxy, private networking/Service Directory, and PKCE; after creation the user must connect/authorize the account, updates are limited to scopes/proxy (scope changes remove existing users), and deletion is available.
```

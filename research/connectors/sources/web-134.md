```text
Moving MCP config from Claude Code to Codex is risky mainly because helper commands, env references, absolute paths, and local wrappers are hidden in the config; copying literal secrets or source-only paths can make the target look valid while breaking the first real tool call. The recommended audit/checklist is to export and classify each server by transport, wrapper, and secret-reference shape, keep env/Keychain/1Password secrets indirect, replace source-only absolute paths, run a tool-list or dry-run for each critical server, and record target-side validation notes for non-equivalent behavior. Bring Your AI treats MCP config as a harness audit via a local CLI (`bringyour preview|migrate --from claude-code --to codex [--policy merge]`), preserving indirect secret references and keeping harness files/secrets on the user’s machine; its remote MCP at bringyour.ai/mcp is no-data.
```

Codex Bridge is a lightweight, stateless MCP server that lets MCP-compatible AI coding assistants such as Claude Code, Cursor, and VS Code interact with OpenAI’s Codex AI through the official Codex CLI, avoiding direct API costs. It provides three tools—`consult_codex`, `consult_codex_with_stdin`, and `consult_codex_batch`—for simple queries, file/stdin analysis, and batch CI/CD automation, with JSON output by default and a 90-second timeout configurable via `CODEX_TIMEOUT`; `CODEX_SKIP_GIT_CHECK` can disable the Git-repo check in trusted directories. Installation is via PyPI (`pip install codex-bridge`) or `uvx codex-bridge`; the MIT-licensed project depends on `mcp>=1.0.0` and Codex CLI and is hosted at github.com/shelakh/codex-bridge.

Type provides a Beamer connector that can be added to a Space running Claude or Codex—or connected to OpenClaw via Sidekick—so approved Beamer tools and data are available from every channel in that Space. Beamer lets companies announce news, updates, and features within apps or websites; the connector’s tools count comments, reactions, posts, and unread posts, and retrieve category metadata using fixed categories: new, improvement, fix, comingsoon, announcement, and other. Type uses connectors/connections, some hosted MCP and others OAuth, API keys, service accounts, or custom APIs, so it is not exactly the same as a Beamer MCP server.

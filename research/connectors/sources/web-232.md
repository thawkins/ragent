```text
Claude Code and Codex are complementary: Claude Code can write code, while Codex can run smoke tests via its Computer Use plugin that opens and clicks through a Mac app and reports breakage. Because the tools cannot open each other’s conversations—Claude Code transcripts live in `~/.claude/projects/` and Codex transcripts in `~/.codex/sessions/`, with no import command—handoffs are new sessions started from context notes: write `HANDOFF.md` covering the goal, done/verified work, remaining steps, decisions and rationale, relevant files, and uncommitted changes, then run `codex "Read HANDOFF.md and continue the work described there."` or `claude "Read HANDOFF.md and continue the work described there."` in the same working directory. Shared rules can be maintained through `CLAUDE.md` and `AGENTS.md` (e.g., `@AGENTS.md` in `CLAUDE.md`, or Codex config `project_doc_fallback_filenames=["CLAUDE.md"]`). Handoffs do not carry conversations, permissions/approvals, or tool/integration configs such as MCP servers, skills, hooks, and custom commands; full transcript JSONL paths exist but are not recommended as the main handoff, and PonyMux can automate handoff for Claude Code/Codex sessions with at least one exchange, though compressed `.jsonl.zst` Codex sessions cannot be handed off yet.
```

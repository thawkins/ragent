An InventiveHQ reference explains that MCP is portable but CLI configuration is not across Claude Code, Codex CLI, Gemini CLI, Qwen Code, and Oh My Pi. Four use JSON under `mcpServers`, while Codex uses TOML `[mcp_servers.<name>]`; the HTTP field is `url` in Claude Code/Codex/OMP but `httpUrl` in Gemini/Qwen, a common copy-paste error. Config locations and scopes differ (`~/.claude.json`/`.mcp.json`, `~/.codex/config.toml`, `~/.gemini/settings.json`, `~/.qwen/settings.json`, `.omp/mcp.json`/`~/.omp/agent/mcp.json`), with stdio recommended for local servers, streamable HTTP for remote, and SSE deprecated. Most connection failures come from stripped environments requiring absolute executable paths or stdio stdout pollution requiring stderr logging; verify with `/mcp`, and Claude Code project servers may show “⏸ Pending approval.”

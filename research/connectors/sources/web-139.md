Notion’s official MCP server at `https://mcp.notion.com/mcp` (streamable HTTP; `/sse` for older clients) connects AI tools like Claude Code, Codex, Claude Desktop, and Antigravity to Notion via OAuth, requiring no local server or extra packages. The post recommends local-config MCP over Notion’s web one-click connector for privacy: web OAuth is tied to the logged-in AI account, while local authorization lets users select which pages to expose, though Claude Desktop is the exception because its connector is account-bound, syncs across devices, and is Pro/Max/Team/Enterprise only. Setup specifics include Claude Code’s `claude mcp add --transport http notion https://mcp.notion.com/mcp` then `/mcp` browser auth (SSH users must manually paste the `localhost:3118` callback URL), Codex editing `~/.codex/config.toml` and running `codex mcp login notion`, and Antigravity editing `~/.gemini/config/mcp_config.json`. Notion also offers a PAT starting with `ntn_` for the local `@notionhq/notion-mcp-server`, but the remote hosted MCP is now the actively maintained option; Context7, Playwright MCP, Chrome DevTools MCP, and GitHub MCP are cited as other useful local MCPs.

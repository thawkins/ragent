Claude Connectors, built on Anthropic’s Model Context Protocol (MCP) open standard introduced in November 2024, let Claude connect to external services across claude.ai, Claude Desktop, Claude Code, Cowork, and the API; Anthropic’s Connectors Directory includes Slack, Google Drive, GitHub, Linear/Jira, Supabase, Figma, Asana, and Ableton/Blender, and users enable them in Settings → Connectors, authenticate via OAuth, and activate them per conversation, with Claude invoking them automatically when relevant. Custom connectors require an MCP server reachable over the public internet (local/firewalled servers need IP allowlisting), can use OAuth and tool allowlists/denylists, and since June 2026 enterprise IT admins can provision connectors org-wide via Okta; the community has thousands of open-source MCP servers and SDKs in major programming languages. All data transfers are encrypted and Claude only syncs content the user already has permission to view, but users should review permissions, connect only to trusted MCP servers because custom connectors are not Anthropic-verified, watch for unexpected tool behavior, and report suspicious servers.

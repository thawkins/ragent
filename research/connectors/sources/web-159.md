```text
Anthropic’s Model Context Protocol (MCP) is an open, vendor-neutral standard—described as a “USB-C port for AI”—that replaces the M×N problem of custom AI-to-tool integrations with a single client–server protocol based on JSON-RPC 2.0 and inspired by Microsoft’s Language Server Protocol. MCP defines a host application, MCP client, and lightweight MCP server, and standardizes three primitives: tools (model-controlled actions), resources (application-controlled read-only data), and prompts (user-controlled templates), with persistent connections, streaming/notifications, secure two-way access, sandboxing, and human approval. Anthropic seeded an open-source server repository for Google Drive, Slack, Git, GitHub, Postgres, and Puppeteer, and provides SDKs in TypeScript, Python, Java, Kotlin, and C#. Adoption includes Microsoft integrating MCP into Azure OpenAI and OpenAI announcing support across products, including the ChatGPT desktop app and Agents SDK, after adopting Anthropic’s standard in March 2025; expected beneficiaries include AI agents, IDE/coding assistants, office productivity tools, RAG systems, data analysis/BI, and personal assistants.
```

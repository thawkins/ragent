The GitHub repo "AgenticAdvertising/adside-mcp" hosts public documentation and examples for Adside's hosted MCP server, which lets AI agents manage paid advertising on Meta, LinkedIn, and Google Ads from any MCP client. The endpoint is https://api.adside.ai/mcp (streamable HTTP, Bearer sk_live_YOUR_KEY auth), with per-channel routes at /{source}/mcp for meta, linkedin, and googleads. Documented capabilities include researching competitor/market ad creative, listing and managing campaigns (e.g. list_meta_campaigns), building, organizing, and bulk-importing creative, and running day-to-day operations. Adside targets performance agencies and in-house teams; the server itself is part of the Adside platform (website adside.ai, docs docs.adside.ai, contact rob@adside.ai).

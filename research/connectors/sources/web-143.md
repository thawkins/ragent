```text
The page catalogs Model Context Protocol (MCP) servers for Claude Code, Copilot, and Cursor, which let agents query external systems via standardized tools/resources instead of pasting data. Covered servers include Filesystem, GitHub, PostgreSQL/SQLite, Brave Search, Puppeteer, Memory, Slack, and AWS Bedrock Knowledge Bases, with JSON setup recipes and use cases; Copilot uses `.vscode/mcp.json` and Cursor uses `.cursor/mcp.json`. It warns that MCP servers execute with the same permissions as the local process, so malicious or misconfigured servers could read all files or execute arbitrary code, and advises read-only/dev databases over production write access; more servers are listed at the official GitHub repo, mcp.so, and awesome-mcp-servers.
```

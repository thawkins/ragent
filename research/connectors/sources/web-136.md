Model Context Protocol (MCP) is the open standard that lets Claude Code act as an MCP client and connect to external tools, databases, APIs, ticketing systems, and documentation through one or more MCP servers. It supports three transports—stdio for local child-process servers (default), HTTP for remote servers (recommended, with auth/OAuth support), and deprecated SSE—and configures servers at local (`~/.claude.json`), project (`.mcp.json`, Git-shareable with `${VAR}` secret expansion), or user scope, with more local scope overriding broader scopes. Claude Code also handles automatic tool search when context use exceeds roughly 10%, read-only resources referenced via `@`, elicitation forms for runtime server input, managed MCP policies (`allowedMcpServers`/`deniedMcpServers`), OAuth via RFC 9728 metadata, and troubleshooting through `/mcp`. Key controls include `MAX_MCP_OUTPUT_TOKENS`, `ENABLE_TOOL_SEARCH`, and server-side per-tool `anthropic/maxResultSizeChars` caps up to 500,000 characters; best practices favor stdio locally, HTTP over SSE remotely, `.mcp.json` for teams, and limiting connected servers.

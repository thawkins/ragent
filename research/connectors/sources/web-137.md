```text
MCP (Model Context Protocol) extends Claude Code with external tools via JSON-RPC over stdio, configured through a `mcpServers` object in `~/.claude/settings.json` (user scope) and `<project-root>/.claude/settings.json` (project scope), where project-level entries override same-named user entries. Servers are added with `claude mcp add` or manual JSON using `command`, `args`, and `env`, with common examples for filesystem, GitHub (token scopes: `repo`, `read:org`, `issues`, `pull_requests`), PostgreSQL, Slack, and custom Node/Python servers. Security guidance includes using trusted sources, minimal credentials, allow/deny lists, sandboxing, and avoiding hardcoded secrets; troubleshooting covers connection refused, startup timeout, 401/403 auth failures, and missing servers via JSON validation, `claude mcp list`, and `claude mcp reset`. Configuration persists on disk but servers start/stop with Claude Code, `env` values are literal strings with no shell expansion, remote servers require HTTP/SSE, there is no hard server limit though more than 10 concurrent servers may affect performance, and Claude Code uses separate settings from Claude Desktop’s `claude_desktop_config.json`.
```

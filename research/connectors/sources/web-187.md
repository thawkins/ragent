```text
MCP connectors are integration layers that bridge AI agents/LLMs and external tools or services exposed by an MCP server, standardizing discovery, authentication, request formatting, error handling, retries, and response processing. An MCP server exposes tools, resources, and prompts from systems such as databases, APIs, GitHub, GitLab, Google Drive, Confluence, Notion, Slack, Jira, ServiceNow, SQL/data warehouses, or local file systems; the connector lets the AI host/client invoke them, typically following the workflow User Message → Tool Call → Structured Result → Response. MCP uses JSON-RPC 2.0 as its message format across transports, including local stdio for privacy/low latency and remote HTTP+SSE or Streamable HTTP requiring authentication, commonly OAuth 2.0 or API keys. Benefits include standardized tool access, less development overhead, enhanced reliability/governance, faster experimentation, and multi-server flexibility; challenges include fragmented tool schemas, latency/failures, data and permission gaps, and versioning/compatibility, while it is contrasted with RAG and plugins/function calling as deeper integration for automation and enterprise tools.
```

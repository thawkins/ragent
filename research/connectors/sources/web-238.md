Claude Code orchestration uses three primitives—Command, Agent, and Skill—with the golden rule that the Command directs, the Agent decides, and the Skill executes. Skills can be standalone, invoked on demand via `Skill(skill: "weather-svg-creator")` and released after loading, or preloaded into an agent via `skills:` frontmatter on every run; Boris Cherny’s fetch/render pattern separates data fetching from rendering, as in a `/weather-orchestrator` Command routing to a `weather-agent` with `weather-fetcher`/`WebFetch` for fetch and `weather-svg-creator` with `Write`/`Bash` for render. The Execution Contract is a natural-language, binary forbidden/MUST directive at the top of a Command prompt, backed by a defensive `allowedTools` allowlist (fail-closed) so agents cannot bypass required Skills. Anti-patterns include 400-line do-everything agents, Skills with business logic, Commands without Execution Contracts, and permissive `["*"]` tool allowlists; a `/find-bug` example splits `code-explorer` (`Read`, `Grep`; `astrep-parser`), `bug-hunter` (`Read`, `Skill`; `vulnerability-patterns`), and `report-formatter` (`Write`).

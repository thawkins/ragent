Type’s Google Slides connector can be added to a Space running Claude or Codex and then used from every channel in that Space; Sidekick can connect a user’s OpenClaw while Type provides conversations, permissions, connections, skills, and automations. Google Slides is described as a cloud-based presentation editor with real-time collaboration, a template gallery, and Google Workspace integration, and one connection can be enabled across multiple Spaces for threads, skills, automations, and coding work. Supported tools include creating blank presentations with title/locale/page size, creating decks from Markdown split by `---`, generating page thumbnails (an expensive read request for quota), batch/Markdown updates with themes and title/bullet/table/quote/image/two-column slides, and copying templates via Drive to preserve themes, masters, and layouts before replacing placeholder text or images. Type notes it is not exactly a Google Slides MCP server: connectors/connections give selected Spaces access to approved app tools and data, using hosted MCP, OAuth, API keys, service accounts, or custom APIs depending on the connector.

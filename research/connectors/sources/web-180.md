An OpenAgents guide (Sept 2026) compares Codex CLI and Claude Code as terminal agentic coding tools that read repos, edit files, run commands/tests, and iterate, but differ in their harness. Codex CLI (OpenAI, Apache-2.0) runs GPT-6 Sol/Luna (GPT-5.5 retires Oct 14, 2026), defaults to an OS-enforced sandbox with network off, reads AGENTS.md, offers Ultra-mode subagents, and is billed via ChatGPT plans (Free, Go $8, Plus $20, Pro from $100) or API. Claude Code (Anthropic, proprietary) runs Claude Opus/Sonnet, uses tiered permissions, reads CLAUDE.md/AGENTS.md with auto memory, and offers richer parallel work (subagents, agent teams, dynamic workflows, git worktrees); both have non-interactive modes (codex exec, claude -p), and Claude Code adds first-party GitHub Actions/GitLab CI/CD. It needs a Claude subscription (Pro from $20, Max from $100) or Console API, with Anthropic guidance of ~$13/developer/active day and $150–$250/developer/month (90% under $30/day). The guide recommends Codex for strict default sandbox/open source/OpenAI ecosystem, Claude Code for long multi-file refactors/memory/parallel agents, and notes many teams run both side by side in an OpenAgents Workspace.

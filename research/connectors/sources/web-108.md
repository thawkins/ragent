A Bubble forum user reports that Claude.AI makes JSON responses easier than OpenAI and Gemini: OpenAI and Gemini return JSON as a string in JSON-SAFE mode, while Claude.AI lets you request JSON directly and returns it as an object in the response body, making it easier to navigate. The user adds that OpenAI and Gemini JSON responses are problematic in Bubble because the API connector detects them as strings, requiring lengthy extra effort to convert them to JSON.

Make is now a built-in connector on Anthropic Claude, letting users connect the Make MCP server via OAuth without manually adding a URL or token. Users can open Claude Settings, search for Make, click the plus sign, and select their organization and scopes on the OAuth consent screen. The integration enables sending requests in chat so Claude can choose the right scenario, and running any scenario without signing into Make.

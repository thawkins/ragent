The author describes adopting OpenAI’s Codex CLI—a terminal-based local coding agent that can read/modify files, run code, and connect to Model Context Protocol (MCP) servers—instead of Cursor/Claude for non-coding work, especially an Obsidian markdown vault, because the terminal already has file access with no plugins or API keys. The author uses `AGENTS.md`, `SKILL.md`, slash commands (`/init`, `/new`, `/model`, `/compact`, `/status`, `/quit`), and inline Bash (`!`), reporting uses such as editing/proofreading, creating a 2025 meeting index in 34 seconds, managing `#idea/*` tags, and syncing Linear “Todo” tasks to Obsidian through Playwright MCP using an existing browser session and no API keys, plus a reusable `linear-to-obsidian` skill; he concludes Codex CLI makes AI useful for repetitive daily workflows.

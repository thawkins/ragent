Rail Connector MCP (v1.0.0-beta.3, third public beta) is an independent, MIT-licensed local MCP bridge, not affiliated with Anthropic or OpenAI, that lets Codex operate local Claude Code conversations using Claude Code session logs and Remote Control CLI, with a persistent Windows ConPTY broker or tmux on Linux/macOS under a same-OS contract requiring Codex, the MCP server, and Claude Code to share the OS context (native Windows controls native Windows; WSL controls Claude only within the same WSL). It supports listing, inspecting, starting, resuming, continuing, forking, prompting, waiting for, capturing, renaming, archiving, and stopping conversations, plus launch controls for model, effort, Ultracode, permissions, safe mode, tools, and workspace trust; it does not implement Anthropic’s private cloud protocol and still requires an authenticated local Claude Code process. The package is private and not published to npm, with Git tags/GitHub Releases as release authority and prerelease MCP schemas; it runs locally under the current user with no telemetry and no session upload, though Claude Code itself communicates with Anthropic, and requires Windows/Linux/macOS, Node.js 22/24/26, npm and Git, authenticated Claude Code CLI, Codex local MCP support, and tmux 3.2+ on Linux/macOS, with install scripts enabled and `npm ci --ignore-scripts` unsupported. Installation must use the same OS as Codex and Claude Code (clone tag v1.0.0-beta.3, or main for unreleased work); the registered MCP server name is rail-connector with tools under mcp__rail_connector, bypass mode is disabled by default, and LocalHost bypass requires `confirmBypassPermissions: true` with recommended allowed roots.

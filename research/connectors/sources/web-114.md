Commit 9b568ca in GRCEngClub/claude-grc-engineering adds a GitHub Actions workflow (`.github/workflows/validate-plugin-manifests.yml`) triggered on changes to plugin/marketplace manifests and schemas, using `actions/checkout@v4`, `actions/setup-node@v4`, `ajv-cli@5`, and `ajv-formats@3` to run `tests/validate-plugin-manifests.sh`. It introduces JSON Schema draft 2020-12 schemas: `marketplace.schema.json` (requires `name`, `owner`, `plugins` for `.claude-plugin/marketplace.json`) and `plugin.schema.json` (requires `name` and semver `version`, mirrors `claude plugin install` validation, permits extension keys like `framework_metadata`, and requires author metadata to be an object because bare strings are rejected). The commit also updates `plugin.json` author fields from strings to objects for AWS, Google Cloud, GitHub, Okta, FedRAMP, OSCAL, and related GRC connector/tool manifests.

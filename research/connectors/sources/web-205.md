ContextOS is an MCP server that gives AI coding agents like Claude Code persistent workspace memory, auto-injecting context via `serverInfo.instructions` in under 20 ms and under 2 KB—including branch, recent commits, active todos, recent decisions, and top skills—and exposing four tools: `remember`, `remember_skill`, `recall`, and `context`. Its retrieval pipeline uses a bundled local ONNX `all-MiniLM-L6-v2` embedder, cosine vector search, FTS5 BM25, Reciprocal Rank Fusion (k=60), and reranking by `exp(-age_days/30) * (0.5 + importance)`; memories auto-archive after 90 days of inactivity, skills never decay, and `decay_days=0` pins a memory. Built on .NET 10 as self-contained single-file binaries averaging 118 MB each, with 126 tests, Linux CI, Apache 2.0, and workspace-local SQLite; limitations include unverified Cursor auto-hydration, no team/cloud sync, no automatic git ingestion, and primary testing with Claude Code.

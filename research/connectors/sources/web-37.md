`claude_desktop_config` v0.2.1 is a Python library on PyPI for programmatically managing Claude Desktop MCP (Model Context Protocol) server configurations in `claude_desktop_config.json`, auto-detecting platform-specific paths and ensuring safe, atomic updates. It provides functional APIs (`enable_mcp_server`, `disable_mcp_server`) and a declarative enum API (`BaseMcpEnum`/`Mcp`) for adding, updating, removing, and batch-managing MCP servers, plus custom config path support; install via `pip install claude-desktop-config` and upgrade with `pip install --upgrade claude-desktop-config`.

```text
MCP is an open client-server standard, open-sourced by Anthropic in November 2024 and governed since December 2025 by the Linux Foundation’s Agentic AI Foundation, that uses JSON-RPC 2.0 to let AI hosts/clients connect to servers exposing tools, resources, and prompts, solving the NxM integration problem; it supports stdio and Streamable HTTP transports and optional OAuth 2.1 authorization for HTTP servers (PKCE, Protected Resource Metadata, Resource Indicators). As of the July 28, 2026 revision, MCP is stateless and moves optional capabilities like MCP Apps, Tasks, OAuth Client Credentials, and Enterprise-Managed Authorization into extensions, complementing APIs, CLIs, Agent Skills, and A2A; major clients include Claude, ChatGPT, Claude Code, Codex, Gemini CLI, Cursor, VS Code, JetBrains IDEs, Xcode, Windsurf, and Zed. As of July 2026, Tier 1 SDKs had near 500M monthly downloads and TypeScript/Python SDKs each passed 1B total; Wiz found ~70% of internet-exposed MCP servers returned full tool catalogs to anonymous callers, mostly on protocol version 2024-11-05, and documented risks include unauthenticated servers, local server compromise, tool poisoning, token passthrough, and over-broad scopes.
```

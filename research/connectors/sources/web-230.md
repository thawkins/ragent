```text
To manage Claude connectors, the article recommends connecting only needed services per conversation or Project and disconnecting the rest, since active connectors automatically pull content and consume tokens—e.g., a Jira issue with 40 comments can cost thousands of tokens—while too many connectors cause token waste, slower responses, and noisy or outdated outputs. It suggests toggling connectors per conversation, configuring them per Project (examples: CS—knowledge base/CRM/ticketing; Marketing—Google Drive/Notion; Sales—CRM/Google Drive; Engineering—GitHub/Jira/Confluence; Operations—Google Drive/Notion/Slack), and for admins: audit daily-used connectors, connect only those, set Project defaults, and review quarterly. It also warns that each connector reads via someone’s authentication, so team deployments should ensure appropriate permissions and, where supported, use a shared credential not tied to one person’s account.
```

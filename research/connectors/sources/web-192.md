The connector-update MCP tool for Simplifier creates or updates REST, SOAP, and SAP RFC connectors, configuring endpoints, SSL/TLS settings, and project assignments. Updates require first fetching the existing resource and resending existing tags/endpoints or they will be cleared; SSL settings use `trustType` 0–3 and `ignoreSSLCertificates`. REST uses `endpointURL`, SOAP uses `wsdlUrl`, and SAP RFC requires `sapSystem`, `parallelExecutions`, and a `connectionPool` with `peakLimit`, `poolCapacity`, `expirationTime`, `expirationCheckPeriod`, and `maxGetClientTime`. The input schema has 9 parameters (`name` and `connectorType` required; `endpointConfiguration` optional with create/update rules), is a non-destructive write operation, and was first observed on Nov 11, 2025.

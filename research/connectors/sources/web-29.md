```text
On Sep 11, 2025, Anthropic announced that Claude Desktop Extensions now use the `.mcpb` (MCP Bundle) extension instead of `.dxt`; existing `.dxt` extensions still work, but new extensions should use `.mcpb`, with no functional change. Desktop Extensions package a local MCP server and all dependencies into a single `.mcpb` zip archive with a `manifest.json`, enabling one-click installation in Claude Desktop without terminals, JSON config edits, or dependency conflicts. Claude Desktop provides a built-in Node.js runtime, automatic updates, OS-keychain storage for secrets, support for Node.js/Python/classic binaries, cross-platform and dynamic configuration, and a curated extension directory. Anthropic open-sourced the MCPB specification, toolchain, reference implementation, TypeScript types, and schemas under version 0.1, and includes enterprise controls such as Group Policy/MDM support, pre-installation, blocklists, disabling the directory, and private extension directories.
```

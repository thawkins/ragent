Loop Engineering, defined by Google Cloud AI Engineering Director Addy Osmani as designing a system that prompts an agent instead of prompting it yourself, enables continuous goal pursuit; Boris Cherny, creator of Claude Code, describes Anthropic’s shifts from writing code to prompts (≈1.5 years ago) to designing loops, with a third leap toward autonomous multi-agent collaboration. Osmani identifies five shared modules in OpenAI Codex and Anthropic Claude Code—Automation, Git-worktree isolation, Skills/SKILL.md, MCP-based Connectors, and Sub-Agents—plus persistent memory. In Lance Martin’s Anthropic “Parameter Golf” experiment, a loop trained a model on eight H100 GPUs in under 10 minutes within a 16 MB artifact; Fable 5 improved the pipeline ~6x over Opus 4.7, independent verification Sub-Agents (automated by CMA Outcomes) beat self-scoring, and on an SQL sequential-question task Fable 5 reached 73% verification coverage versus Sonnet 4.6 stopping after step one and Opus 4.7 after step three (7–33% coverage). Loops still require human verification, create understanding debt, and risk cognitive surrender, but the paradigm shift from prompt engineering to loop design moves engineers from L1 manual coding to L2 prompt-writing to L3 loop-designing.

The Cotal Claude Code connector turns a normal `claude` session into a Cotal mesh peer via a bundled plugin that joins NATS, maps lifecycle hooks to presence, and exposes `cotal_*` MCP tools, layered on the shared `@cotal-ai/connector-core` runtime (siblings: OpenCode beta, Hermes alpha, pi alpha). `cotal setup` idempotently installs the plugin, seeds a default persona, and installs Cotal Agent Skills (`SKILL.md`/agentskills.io, currently `team-topology`) through the user-scoped `cotal-skills` plugin from the `cotal-mesh` marketplace, while `cotal up` starts the local mesh, delivery daemon, and detached manager; other harnesses read `~/.agents/skills/`, which `cotal setup` reconciles. Spawns launch the real `claude` with `--strict-mcp-config`, `--mcp-config` for the `cotal` server, and `--dangerously-load-development-channels server:cotal`, requiring `COTAL_NAME` or `COTAL_LINK` so ordinary sessions stay inert; persona privacy uses `--append-system-prompt-file`, MCP isolation excludes personal servers, and `--share-tools` can opt in named servers via `~/.config/cotal/config.json` or `.cotal/config.json` with `${VAR}` secrets. Inbound mesh messages use durable JetStream inbox delivery plus `SessionStart`/`UserPromptSubmit` hook drain and a `notifications/claude/channel` idle wake, with at-least-once semantics, attention modes `open`/`dnd`/`focus`, per-channel `quiet`/`muted`, and channel constraints as a Claude Code research preview (≥ v2.1.80; permission relay ≥ v2.1.81, Anthropic auth only, admin-enabled on Team/Enterprise); it also publishes structured events on `events.<owner>.<actor>` (run boundaries, assistant text, reasoning, tool start/end; tool args/results are not republished), enforces ACL/own-channel rules, supports operator-only `--resume <session-id>` forking, and provides `cotal_feedback` with public/keyed intake.

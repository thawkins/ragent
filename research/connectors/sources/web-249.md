The SD Elements MCP (Model Context Protocol) server provides a standardized interface for AI tool integration and is documented for Self-Hosted deployments; SaaS users must contact Support to enable it. It can be deployed via the `sdelements` Helm chart’s `sde-mcp` subchart in the same namespace or as a standalone MCP server in a separate namespace, where exactly one of `mcp:sdeInstance` or `mcp:sdeInstanceAllowlist` must be set because they are mutually exclusive and setting both causes deployment failure. Advanced configuration covers network policies, TLS/self-signed certificates (`mcp:nodeTlsRejectUnauthorized: "0"`), an nginx sidecar, ingress, and verification that the `{RELEASE_NAME}-mcp` pod is Running. MCP clients use a JSON config with the service URL ending in `/mcp` and SD Elements API key header `sde-api-key` (`sde-host` in allowlist mode), with optional headers such as `Accept: application/json, text/event-stream`, `type: streamableHttp`, and `transport: https`.

TestCollab launched an MCP Server that lets users manage test cases directly from MCP-compatible AI coding assistants such as Claude, Cursor, and Windsurf. Built on the open Model Context Protocol, it supports conversational creation, search, updating, organization, prioritization, and coverage review of test cases; setup runs locally via `npx @testcollab/mcp-server` and authenticates with a TestCollab API token. TestCollab says it has since added test suite management, test plan creation, and 17 tools total, with future work on test execution triggers, CI/CD integration, and enhanced reporting.

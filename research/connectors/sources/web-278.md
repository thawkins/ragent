```text
This tutorial details building a production-ready currency-conversion AI agent on Google Cloud using Vertex AI’s MCP for standardized tool access, ADK for agent orchestration, and A2A for multi-agent communication. The example uses a FastMCP server exposing a `get_exchange_rate` tool backed by the Frankfurter API, an ADK `LlmAgent` using Gemini 2.5 Flash, and an A2A Agent Card/JSON-RPC server on port 10000. Prerequisites include a GCP project with billing, Python 3.10+, gcloud CLI, and Git; steps cover local testing, Cloud Run deployment for the MCP server, ADK Dev UI, and deployment to Vertex AI Agent Engine with `min_instances=1` and `max_instances=10`, plus IAM, Cloud Logging, and troubleshooting.
```

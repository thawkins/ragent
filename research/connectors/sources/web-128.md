The page is a practical guide to configuring MCP (Model Context Protocol) servers across Claude Desktop, Claude Code, Gemini CLI, and Codex. Claude Desktop uses JSON at `claude_desktop_config.json` with a single user scope; Claude Code uses JSON (`~/.claude.json`, project `.mcp.json`), CLI `claude mcp`, and three scopes—local, project, user—with precedence local > project > user and a trust gate for shared `.mcp.json`; Gemini CLI uses JSON (`~/.gemini/settings.json`, project `.gemini/settings.json`), CLI `gemini mcp`, and user/project scopes where project overrides user; Codex uses TOML (`~/.codex/config.toml`, project `.codex/config.toml`), CLI `codex mcp`, and layered user/project/profile/CLI overrides with precedence CLI > project > profile > user and requires project trust. It describes stdio and HTTP transports, says SSE is deprecated in favor of HTTP, and warns that JSON syntax errors, relative paths, failure to fully restart, too many server subprocesses, and committing secrets are common pitfalls; project scope is needed for team sharing and cross-machine sync, while local/user scopes do not sync.

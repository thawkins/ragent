The Linux MCP Server is configured via command-line options or `LINUX_MCP_`-prefixed environment variables, with CLI options taking precedence. Key settings include transport (stdio default; HTTP on 127.0.0.1:8000 at path /mcp, with optional TLS cert/key), SSH connections (default user, key path, 30-second command timeout, host-key verification enabled via known_hosts), toolset choice (fixed, run_script, or both), and host-mode (local-only, remote-only, or any—defaulting to remote-only in containers/non-Linux), plus a gatekeeper LLM for guarded command execution (providers: openai, anthropic, gemini, openrouter, vertex_ai). Logging defaults to `~/.local/share/linux-mcp-server/logs` at INFO level with 10-day retention; the HTTP transport supports OAuth2 authorization (google, github, jwt, or introspection providers) governed by an ordered YAML policy of rules matching host, tools, and token claims, where stdio defaults to allow-all access and HTTP to deny-all when no `--policy-path` is specified.

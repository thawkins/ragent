```text
An MCP server is a lightweight service that exposes tools (actions), resources (read-only data), and prompts (templates) to AI applications via the Model Context Protocol (MCP), an open, model-agnostic standard open-sourced by Anthropic in late 2024 that solves the M×N integration problem by reducing it to M+N. MCP uses JSON-RPC 2.0 over stdio (local), Streamable HTTP (recommended for remote, supports OAuth 2.1), or legacy/deprecated SSE; the guide distinguishes host, client, and server roles and stresses that an MCP server is a privileged access surface, with risks including tool poisoning, prompt injection, credential exposure, malicious or fake servers, and over-broad scopes. Production hardening requires authentication, least privilege, input validation, audit logging, vetting third-party servers, and often an MCP gateway/proxy for centralized auth, policy, and audit; use cases span GitHub, GitLab, filesystem, CI/CD, database, Snowflake, BI, Slack, Salesforce, Stripe, and Playwright, while MCP servers often wrap existing REST/GraphQL APIs, are complementary to A2A, and can be built with official SDKs such as TypeScript and Python. agen.co provides an MCP gateway, authentication, and access control for MCP.
```

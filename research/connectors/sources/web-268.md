The `mcp-server-fetch` Model Context Protocol server lets LLMs fetch URLs and convert HTML to markdown, with a `fetch` tool that takes a required `url` plus optional `max_length` (default 5000 chars), `start_index` (default 0), and `raw` (default false) arguments for chunked reading. It can be run via uvx/recommended, pip (`python -m mcp_server_fetch`), or Docker (`mcp/fetch`), and supports `--ignore-robots-txt`, `--user-agent`, and `--proxy-url` customization (it honors robots.txt for model-initiated but not user-prompt requests). The repository it belongs to (modelcontextprotocol/servers, MIT licensed) contains 5 MCP servers and reports 62,692 GitHub stars, 724 contributors, and 348 issues (per-server averages: 12,538 stars, 145 contributors, 70 issues). A caveat warns the server can access local/internal IP addresses, posing a security risk if sensitive data is exposed.

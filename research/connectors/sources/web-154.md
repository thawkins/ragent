Anthropic’s open Model Context Protocol (MCP), released in late 2023 with Python and TypeScript SDKs, defines a client-server JSON-RPC 2.0 standard for connecting Claude to external tools and data through MCP hosts (e.g., Claude Desktop), clients, and servers over stdio or SSE. MCP servers expose tools, resources, and prompts; community Blender servers let Claude create and modify 3D scenes via Blender’s Python API, while Adobe MCP integrations expose Firefly, Creative Cloud APIs, Photoshop API, and Express for image generation, editing, and branded content—though most Adobe integrations use cloud APIs rather than direct desktop control. The ecosystem includes filesystem access, GitHub, Google Drive/Docs, PostgreSQL/SQLite, headless browsers, Slack, and Notion, with hundreds of community-built servers; security relies on user consent, local-vs-remote trust, and prompt-injection awareness. MCP is built into Claude Desktop and available through Anthropic’s API, extending function calling with discovery, session management, and a standardized server format.

The MongoDB MCP Server configuration page lists OS environment variables and CLI flags for authentication, connection strings, dry-run, read-only mode, index checks, telemetry, logging, transport, HTTP settings, health checks, session/timeout controls, export cleanup, and Voyage AI autoembeddings. Key claims: `--connectionString` is deprecated in favor of `MDB_MCP_CONNECTION_STRING` or the first positional argument; writes are allowed by default but read-only mode is recommended; `MDB_MCP_MAX_TIME_M_S` is recognized while `MDB_MCP_MAX_TIME_MS` is not; transport defaults to `stdio`, and HTTP binds to `localhost` (`127.0.0.1`) by default, with `0.0.0.0` binding exposing the server to the local network as a security risk. Array options accept comma-separated values (and in MCP Server 1.3.0+ CLI arguments must use comma-separated form), while per-request overrides require `allowRequestOverrides=true` and some options can only lower timeouts/lifetime or disable features.

```text
MCP is an open standard originally developed by Anthropic and now widely adopted that defines structured communication between AI models and external tools; Windsurf implements it natively so Cascade can call compliant servers, using tools (actions like SQL queries, GitHub issues, web fetches) and resources (external data like S3 files, database rows, or Notion documents). Windsurf configures servers via a JSON file in the user config directory (macOS typically `~/.codeium/windsurf/mcp_config.json`; Linux `~/.config/windsurf/mcp_config.json`) with fields including name, command, optional args, and optional env for API keys, requiring Node.js/npx or Python/uvx and a Windsurf reload; local servers run as spawned processes, while remote servers connect over HTTP. Recommended high-value servers include GitHub, Filesystem, Brave Search or Exa, SQLite/PostgreSQL, and Notion/Linear, with GitHub described as the most reliable starting point. Known limitations include a young and variable ecosystem, inconsistent authentication, Cascade sometimes selecting the wrong tool, local process overhead, opaque error messages, and no graphical MCP manager as of the current release.
```

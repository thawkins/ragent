The page documents bytedance/UI-TARS-desktop’s agent-infra MCP browser server, a fast, lightweight Model Context Protocol server that gives LLMs browser automation through Puppeteer’s structured accessibility data, with optional vision mode using screenshots (Aria snapshots by default) and no vision model required. It requires Node.js 18+ and supports VS Code, Cursor, Windsurf, Claude Desktop, or any MCP client via `npx @agent-infra/mcp-server-browser@latest`, including local stdio, remote SSE/Streamable HTTP on port 8089 (`/sse` and `/mcp`), and in-memory JavaScript/TypeScript calls. Configuration includes CLI options for chrome/edge/firefox, CDP/WS endpoints, headless mode, host/port, proxy, user-agent, user-data-dir, viewport-size, output-dir, and `--vision`; runtime HTTP headers include `x-viewport-size`, `x-vision-factors`, and `x-user-agent`; tools include `browser_navigate`, `browser_click`, `browser_screenshot`, `browser_vision_screen_capture`, and `browser_vision_screen_click`, with resources `console://logs`, `download://{name}`, and `screenshot://{name}`. Docker unifies VNC and MCP under a single URL endpoint, with Dockerfile/DockerHub image to be published together.

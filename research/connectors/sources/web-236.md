Claude Code hooks are shell commands automatically triggered at specific execution-cycle points, acting as terminal-level event listeners that intercept the flow to inject external logic, unlike MCPs (capability extensions) or Skills (behavior definitions). Claude Code exposes 32 hook events—the first six cover 90% of common usage—configured in `~/.claude/settings.json` or `.claude/settings.json` with a `HookType` such as `PreToolUse`, `PostToolUse`, `Stop`, or `Notification`, an optional matcher for exact tool names like `Bash`, `Write`, `Edit`, `Read`, or `WebFetch`, and `type: "command"`. Examples include blocking dangerous `rm -rf`, auto-formatting with Prettier, Slack notifications after commits, session reports, `SessionStart` Docker checks, and `PermissionRequest` auto-approval (exit 0) or manual confirmation (exit 1), plus advanced conditional, chained lint/format/test, and secret-validation hooks. The 32-event reference spans lifecycle phases including tools/execution, subagents/orchestration, compaction/context, worktrees/files, cloud scheduling, errors/observability, and channels; personal hooks go in `.local`, team hooks such as lint enforcement, secret scans, and centralized audit logs go in the versioned file, and hooks pair with headless mode for CI/CD.

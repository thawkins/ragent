codex-mcp-server is a GitHub repository providing an MCP bridge between Claude Code and OpenAI’s Codex CLI, routing Claude Code → Codex MCP Server → Codex CLI → OpenAI API for AI-powered code analysis, generation, and review in the editor. It exposes tools including `codex` (session support, model selection, structured output metadata), `review` (AI review of uncommitted changes, branches, or commits), `websearch` (Codex CLI-backed search with configurable result count and depth), `listSessions`, `ping`, and `help`. Requirements are Codex CLI v0.75.0+ and an OpenAI API key; install with `npm i -g @openai/codex`, authenticate via `codex login --api-key`, and add to Claude with `claude mcp add codex-cli -- npx -y codex-mcp-server`. It supports `sessionId` multi-turn context, advanced options such as `model "o3"`, `reasoningEffort "high"`, `fullAuto true`, `sandbox "workspace-write"`, `callbackUri`/`CODEX_MCP_CALLBACK_URI`, and returns `threadId` in metadata and `structuredContent` with an advertised `outputSchema` when Codex CLI emits it.

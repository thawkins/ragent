```text
As of August 28, 2026, Cube is the article’s top pick for a governed BI platform usable from both Claude and Codex, citing its hosted OAuth remote MCP server, Claude Connectors Directory listing, and first-party `codex mcp add`/OAuth setup, which let both clients reach the same semantic model, permissions, analytics content, and controlled data-model workflows rather than raw warehouse tables. The comparison covers first-party MCP servers from Cube, ThoughtSpot, Tableau, Looker, and Power BI, scored on explicit Claude and Codex support, governed business context, inherited identity and permissions, useful tool scope, write safety and traceability, and operational maturity; ThoughtSpot is the strongest Claude-first alternative, Tableau suits existing Tableau estates, and Looker/Power BI have vendor-managed but preview MCP offerings requiring more administrative setup. It stresses that MCP is only a connection protocol, not a BI tool, so metrics, joins, row-level security, and permissions must be enforced by the BI platform’s semantic layer, and recommends piloting the same five tasks in Claude and Codex—such as finding a certified revenue metric, returning revenue by segment, refusing unauthorized data, creating a report draft, and proposing a validated semantic-model change.
```

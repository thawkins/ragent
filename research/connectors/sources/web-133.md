MCP is an open standard introduced by Anthropic in November 2024; Stripe’s MCP server exposes Stripe API tools plus `search_stripe_documentation` to MCP clients such as Cursor, Claude Code, and ChatGPT, and is distinct from the broader Stripe Agent Toolkit for frameworks like OpenAI Agents SDK, LangChain, CrewAI, and Vercel AI SDK. There is one official server: remote at `https://mcp.stripe.com` (OAuth or Bearer auth) or local via `npx -y @stripe/mcp` (latest 0.3.3, published March 2026), which is now a stdio-to-HTTP proxy to the same remote endpoint, not a fully offline server, and the old `--tools` flag is gone with tool scoping controlled by Restricted API Keys (`rk_`). Its roughly two dozen tools cover account/balance, customers, products/prices, payment links/intents, invoices, coupons, refunds, subscriptions, disputes, and docs search; Stripe recommends `rk_` keys over `sk_`, secrets vaults/env vars, sandbox/test mode, human confirmation, OAuth, and prompt-injection caution when combining MCP servers. For production, teams should curate per-role toolsets to avoid tool overload, and note Stripe MCP provides account access rather than autonomous spending; Stripe is separately developing agentic commerce via the Agentic Commerce Protocol with OpenAI, Shared Payment Token, and Machine Payments Protocol.

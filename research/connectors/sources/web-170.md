Gixo's remote MCP server at https://gixo.ai/mcp can be connected through Anthropic Messages API's `mcp_servers` field using beta `mcp-client-2025-11-20`; examples use `claude-sonnet-4-5` with `max_tokens: 1200`. It exposes five anonymous Lumen generation tools (`create_pitch_deck`, `create_board_presentation`, `create_sales_presentation`, `create_training_presentation`, `create_presentation_from_url`) plus four anonymous read-only Business/analyzer tools (`route_business_artifact`, `run_business_diagnostic`, `analyze_proposal_draft`, `analyze_content_workbench`), while the Prism chart tool and Business artifact execution require an authenticated Gixo account with a Prism trial/plan or entitlement via Descope OAuth bearer token. Operational notes: HTTPS is required, only tool calls are supported (not MCP prompts/resources), users should specify Lumen deck generation versus read-only analysis, and large toolsets should enable only needed Gixo tools.

Reporails’ article on Claude Code hooks argues that rules and checks belong to specific turn moments—UserPromptSubmit, PreToolUse, PostToolUse, and Stop—but that one hook per rule stops scaling around rule twenty because each hook sees only one event, nothing remembers between events, and conditions are scattered. It recommends routing every hook event through a single event-bus script (registered in settings.json for InstructionsLoaded, UserPromptSubmit, PreToolUse, and Stop) and starting with telemetry: in 13 days across four repositories, 1,979 reply attempts included 106 missing the opening [kind] (~1 in 19), and end-of-reply checks returned 497 (~1 in 4). The bus can log JSONL telemetry, match on saved declarations like [status][migration], and be adapted to Codex, Cursor, and Gemini CLI, but the author warns users must manage rule loading, conflicts, and silent failures; the log cannot show rules that should have loaded but did not.

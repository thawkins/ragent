Code Composer Studio (CCS) 20.5.0 offers AI code assist through bundled functionality, Open VSX extensions, and MCP (Model Context Protocol) servers that let assistants interact directly with CCS project/debug servers. The AI Assistant Configuration view (via Get Started or Help > Get Started with AI) configures agents—currently only Claude Code is supported and auto-installed—with model provider/API key/base URL/model settings, and can enable “Enable CCStudio ecosystem MCP servers” to access building, debugging, monitoring, and SysConfig control; MCP servers run only while CCS is running with an AI-enabled workspace, and settings are per workspace. Claude Code requires Git and is installed only as an extension, not its desktop/CLI version, and only Claude Code is fully supported/tested with CCS MCP servers; MCP is designed to work with other MCP-capable assistants, while Theia AI is bundled and other Open VSX assistants may work with less integration. For other assistants, MCP setup uses command `[CCSINSTALLDIR]/ccs/tools/node/node` with `proxy.js` arguments for debug, build, project, and sysconfig.

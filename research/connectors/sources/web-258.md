```text
Wingman's MCP support connects agents to external tools via servers configured in `~/.config/wingman/wingman.json` (or `$XDG_CONFIG_HOME/wingman/wingman.json`), using `type: "local"` for stdio subprocesses (`command` array run without shell expansion, `cwd` accepts `~`) or `type: "remote"` for HTTP endpoints with credentials in headers, plus optional `discovery_timeout` and `execution_timeout` in milliseconds (both default 30000). After editing the file Wingman must be restarted; connected tools appear on the Console Tools page and at `GET /tools`, and each MCP tool is prefixed with its server name (e.g. `company-tools`' `search` becomes `company_tools_search`), which agents must list in their `tools` allow-list — agent creation/updates reject unknown or disconnected tool names, and duplicate names after normalization prevent the tool catalog from loading. Servers are enabled by default; set `enabled: false` to keep one configured without connecting at startup, or use the Console to connect/disconnect enabled servers without changing the file.
```

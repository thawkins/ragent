```text
MCP (Model Context Protocol) is an open protocol that lets Claude Code call external tools through local stdio servers (JSON-RPC over stdin/stdout) or remote HTTP/SSE servers, configured in `~/.claude/mcp.json`, project `.mcp.json`, or `.claude/settings.json`, with `claude mcp add` and user/local/project scopes. Claude Code’s Tool Search reportedly reduces context use by ~85–95% via on-demand tool loading, though each connected server’s tool list still typically costs 200–800 tokens, and 3–5 focused servers are recommended since 20+ can hurt startup. Useful servers include GitHub (`mcp.github.com`), Filesystem (`@modelcontextprotocol/server-filesystem`), PostgreSQL/SQLite, Brave Search, Linear/Notion/Slack HTTP servers, and Context7 (`@upstash/context7-mcp`) for current documentation. Security guidance includes auditing servers, using read-only/minimal permissions, referencing secrets as `${ENV_VAR}` rather than hardcoding, avoiding committed personal credentials, and watching for prompt injection. Debug with `claude mcp list/get/remove`, session `/mcp`, and `"debug": true` logging to `~/.claude/mcp-debug.log`; custom servers can be built with Node.js, Python, Go, or Rust SDKs, and a minimal starter config pairs GitHub with Context7. Claude Code does not read `claude_desktop_config.json`.
```

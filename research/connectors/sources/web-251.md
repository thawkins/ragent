PromptKit’s SDK v2 allows adding Model Context Protocol (MCP) servers to a conversation so the LLM can call their tools, either by registering all tools with `sdk.Open(..., sdk.WithMCP(...))` or using `sdk.NewMCPServer` for finer control. The builder supports `WithEnv`, `WithArgs`, `WithWorkingDir`, `WithTimeout(ms)`, and `WithToolFilter`, where `ToolFilter` allowlist/blocklist controls exposed tools and allowlist takes precedence if both are set; multiple servers can be registered with `WithMCPServer`. MCP tool names are namespaced as `mcp__{serverName}__{toolName}` (e.g., `mcp__github__search_repositories`, `mcp__filesystem__read_file`) and can be referenced in a prompt config’s `allowed_tools`.

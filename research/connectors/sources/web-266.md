MCP is an open JSON-RPC 2.0 protocol that standardizes AI-app connections to external tools and data, replacing custom M×N integrations; it reached 97M+ monthly SDK downloads and 10,000+ active public servers in its first year, with OpenAI adopting it in March 2025, Google in April 2025, and Microsoft at Build 2025, and it exposes tools, resources, and prompts via a client-server architecture. A Zuplo survey found 72% of adopters expect increased usage and 54% expect it to become an industry standard, but 38% say security concerns block broader adoption; an Astrix Security analysis of ~20,000 MCP servers found 88% require credentials, only 8.5% use OAuth, 53% rely on static API keys, and 25% lack authentication. The November 2025 spec update added improved OAuth support and asynchronous Tasks. In December 2025 Anthropic donated MCP to the Linux Foundation’s new Agentic AI Foundation, co-founded by Anthropic, Block, and OpenAI, with Google, Microsoft, AWS, Cloudflare, and Bloomberg as supporting members.

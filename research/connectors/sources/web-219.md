NVIDIA Elements provides one AI-agent skill for durable UI authoring: `SKILL.md` defines the default workflow, while `references/` covers artifacts, setup checks, project integration, and migration, complementing the CLI/MCP server (skill for stable workflow/project guidance; CLI/MCP for current API data, examples, imports, validation, package versions, and starter setup). It can be installed via `npx skills add https://github.com/nvidia/elements --skill elements` or the hosted endpoint `https://nvidia.github.io/elements`; the hosted route installs skill files only, not the CLI, MCP config, editor data, or dependencies. The CLI is installed via curl/irm or `npm install -g @nvidia-elements/cli` (adding `nve`); `nve skills.install --global` writes `~/.agents/skills/elements/`, while full project setup adds MCP config for Claude Code, Cursor, and Codex, writes `.agents/skills/elements/` and `.claude/skills/elements/`, adds VS Code custom data paths for `nve-*` tags/attributes, and updates core Elements package dependencies. MCP maps `/artifact`, `/doctor`, `/create-project`, and `/migrate` prompts to the skill references but does not expose skill listing/retrieval tools; `llms.txt` supports runtime link-fetching context and `llms-full.txt` supports offline/RAG use, with the recommended setup being local skill + `nve mcp` + CLI/MCP for current API lookup and validation.

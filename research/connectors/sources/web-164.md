Anthropic’s Claude MCP connector lets the Messages API connect directly to remote MCP servers without a separate MCP client, using beta header `mcp-client-2025-11-20`; the previous `mcp-client-2025-04-04` is deprecated. It currently supports only tool calls, requires publicly exposed HTTP servers (Streamable HTTP or SSE; no local STDIO), supports OAuth tokens, multiple servers, and per-tool allowlist/denylist configuration via `mcp_servers` and `mcp_toolset` objects in `tools`, with response blocks `mcp_tool_use` and `mcp_tool_result`. It is available on the Claude API, Claude Platform on AWS, and Microsoft Foundry (not Amazon Bedrock or Vertex AI), is not eligible for Zero Data Retention, and has TypeScript SDK helpers for client-side MCP tools, prompts, and resources.

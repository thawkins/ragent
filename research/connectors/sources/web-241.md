The “Figma Code Connect Components” skill maps Figma design components to code implementations using Figma’s Code Connect via a required workflow: call `get_code_connect_suggestions` to find unmapped published components, scan the codebase for matches, present matches to the user, then call `send_code_connect_mappings` with accepted mappings containing `nodeId`, `componentName`, `source`, and `label`. It requires a connected Figma MCP server, codebase access, a Figma URL with `node-id` (converting `1-2` to `1:2`) or a selected node via `figma-desktop`, and components published to a team library; Code Connect is only available on Organization and Enterprise plans. Mappings support labels such as React, Vue, Svelte, SwiftUI, Compose, Flutter, and Markdown, and common failures include unpublished components, existing mappings, missing code matches, incorrect source paths, and insufficient permissions.

Claude Managed Agents supports connecting remote Model Context Protocol (MCP) servers to agents for external tools and data, using the `managed-agents-2026-04-01` beta header (auto-set by the SDK). Configuration is split: agent creation declares servers in `mcp_servers` (`type: "url"`, unique name 1–255 chars, URL up to 2048 chars; max 20 servers, each referenced by an `mcp_toolset` and vice versa), while session creation supplies credentials via `vault_ids` matched by exact `mcp_server_url` (`static_bearer` or `mcp_oauth`), otherwise the connection is unauthenticated. MCP toolsets default to `always_ask` permission, support `default_config`/`configs` tool filtering, and MCP tool outputs over 100k tokens are written to a sandbox file with only a truncated preview and path returned. Session creation does not validate MCP connectivity or credentials; failures emit `session.error` with `mcp_server_name` and retry status (`mcp_connection_failed_error` or `mcp_authentication_failed_error`) and retry on idle-to-running transition; supported servers must expose an HTTP endpoint via streamable HTTP transport or private MCP tunnels.

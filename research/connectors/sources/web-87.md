The archived repo `hesreallyhim/claude-code-json-schema` provides unofficial JSON Schemas for Claude Code manifest files like `plugin.json` and `marketplace.json`, intended for developer tooling, plugin authors, and IDE integrations, but it is not authoritative or affiliated with Anthropic PBC. Linting is available via `npx github:hesreallyhim/claude-code-json-schema /path/to/project`, with VS Code/JetBrains setup in `USAGE.md`, and a scheduled workflow refreshes upstream documentation snapshots and reports fetch failures via issues.

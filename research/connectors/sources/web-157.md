Claude Managed Agents supports MCP servers by declaring up to 20 uniquely named servers in the agent’s `mcp_servers` array (with `type`, `name`, and `url`), each matched by an `mcp_toolset` in `tools`; the API rejects unreferenced servers or dangling toolsets. MCP toolsets support `default_config` and `configs` entries with `name`, `enabled`, and `permission_policy` (no `type` field; all tools enabled by default), and tool outputs over 100,000 characters (~25,000 tokens) are written to a sandbox file with a truncated preview. Authentication is supplied at session creation via `vault_ids` using URL-normalized matching (scheme/host lowercased, default ports and trailing slashes stripped; `static_bearer` or `mcp_oauth` credential types), while limited environments require `allow_mcp_servers: true` or `allowed_hosts` to avoid a 400 error; session creation does not validate MCP connectivity or credentials, so failures emit `session.error` with `mcp_server_name` and `retry_status` and retry on the next `status_idle` to `status_running` transition.

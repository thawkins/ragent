The juehang/vscode-mcp-server is a VS Code Marketplace extension that runs an MCP server exposing VS Code filesystem and editing capabilities to Claude and other MCP clients, using the streamable HTTP API rather than SSE and inspired by Serena. It supports file, edit, diagnostics, symbol, and shell tool categories, including `search_symbols_code`, `get_symbol_definition_code`, `get_document_symbols_code`, and `execute_shell_command_code`, and can be configured for Claude Desktop via `npx mcp-remote@next` against `http://localhost:3000/mcp`. Default settings include port 3000, host 127.0.0.1, `defaultEnabled`, and `enabledTools`; it currently supports only one workspace and runs locally. Because it can execute shell commands, it poses a security risk, and authentication is not implemented while the MCP auth spec is in flux; users should trust their MCP client and avoid exposing the port.

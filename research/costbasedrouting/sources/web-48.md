# Model Catalog to Model Router: What's New In Azure AI Foundry Models

with Seth Juarez, Nitya Narasimhan

[AI Show][5]

In this episode, Nitya Narasimhan joins Seth to explore the new Model Router in Azure AI Foundry-a powerful tool that
intelligently selects the best large language model (LLM) for your prompt in real time. Whether you're optimizing for
speed, cost, or complexity, the model router dynamically routes your request to the most suitable model-so you get high
performance without overspending.

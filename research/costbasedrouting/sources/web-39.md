## Build agent capabilities with Foundry Tools

Foundry Tools deliver production-ready APIs for speech, language, documents, and more, enabling intelligent agentic
workflows without starting from scratch. As part of Microsoft Foundry, these tools speed up integration and simplify
complexity, allowing developers to focus on building features that matter. Start with prebuilt skills and ship faster.

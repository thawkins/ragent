## Frequently asked questions

Expand all
Collapse all
* **01/**
  
  ### What is Foundry Models?
  
  Foundry Models is a hub for discovering foundation models. The catalog includes some of the most popular large
  language and vision foundation models curated by Microsoft, OpenAI, Anthropic Claude, Fireworks AI, DeepSeek, xAI,
  Hugging Face, Meta, Mistral AI, Cohere, Deci, Stability AI, Nixtla, and NVIDIA. These models are packaged for
  out-of-the-box implementation and optimized for use in Foundry.
* **02/**
  
  ### What is Serverless API or Models as a Service (MaaS)?
  
  Serverless API, or MaaS, is a deployment type that allows developers to access and use a variety of models hosted on
  Azure without having to provision GPUs or manage back-end operations. MaaS offers inference APIs
  and hosted fine-tuning for models such as Anthropic Claude, Meta Llama2, Meta Llama 3, and Mistral
  Large, among others.
* **03/**
  
  ### How much does Serverless API cost?
  
  Serverless API charges are based on the number of tokens used for inference and the amount of data used for
  fine-tuning. The pricing also depends on the model and the region. To see the price for individual models, search for
  the model in [Azure Marketplace][252].
* **04/**
  
  ### What models are available today through Serverless API?
  
  Today, there are Anthropic Claude, Meta Llama, Mistral AI, Cohere, Core42 JAIS, Nixtla, Stability, DeepSeek, BFL, Bria
  AI and xAI Grok models.

```text
GitLab CI/CD, available in Free, Premium, and Ultimate tiers on GitLab.com, Self-Managed, and Dedicated, is a continuous method to build, test, deploy, and monitor iterative code changes and catch bugs early. To use it, add a case-sensitive `.gitlab-ci.yml` file to the project root (custom filenames allowed) defining ordered stages (e.g., build, test, deploy) and jobs/scripts; pipelines are triggered by commits, merge requests, schedules, or manually and executed by runners. Runners are agents on physical or virtual machines, can use specified container images, and GitLab.com provides Linux, Windows, and macOS runners; users can also register their own. CI/CD variables are key-value pairs (custom/predefined, protected/masked), expressions use `$[[ ]]` syntax with contexts like `inputs` and `matrix`, and reusable CI/CD components added via `include:component` can be published to the CI/CD Catalog.
```

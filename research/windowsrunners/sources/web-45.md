```text
GitLab Runner is a Go-based, single-binary application (Free/Premium/Ultimate; GitLab.com, Self-Managed, and GitLab Dedicated) that works with GitLab CI/CD to execute jobs defined in `.gitlab-ci.yml`, connecting to GitLab to request jobs, run them locally, in Docker, over SSH, or with autoscaling, and report results; it supports concurrent jobs, multiple tokens/servers, Bash/PowerShell Core/Windows PowerShell, GNU/Linux/macOS/Windows, caching, and Prometheus metrics. Administrators can use GitLab-hosted runners managed by GitLab on GitLab.com or self-managed runners they install/configure; version compatibility requires GitLab Runner major.minor to stay in sync with GitLab, with backward compatibility between minor updates. Registration uses a `registration_token`, job requests use a `runner_token`, and job execution uses a `job_token`; the code is MIT-licensed.
```

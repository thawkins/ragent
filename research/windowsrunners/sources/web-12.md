```text
GitLab Runner offers Shell, Docker, Docker-SSH, VirtualBox, Parallels, SSH, and Kubernetes executors; Docker, Docker-SSH, VirtualBox, Parallels, and Kubernetes provide clean build environments, while Shell and SSH do not, and Docker/Docker-SSH/Kubernetes support runner migration and zero-config concurrent builds (VirtualBox/Parallels are partial for migration). Shell is simplest but requires manual dependencies; Docker offers clean, dependency-managed environments with services like MySQL; Docker-SSH connects to a container running an SSH daemon and is generally discouraged; VirtualBox/Parallels clone existing VMs to run builds on Windows, Linux, OSX, or FreeBSD and can reduce infrastructure cost; SSH is least supported and runs builds on an external server. Debugging is easy for Shell/SSH, medium for Docker/Docker-SSH/Kubernetes, and hard for VirtualBox/Parallels.
```

```text
GitLab runners are agents running the GitLab Runner application to execute CI/CD jobs defined in `.gitlab-ci.yml`; they must be registered with GitLab, and when pipelines trigger, matching runners pick up queued jobs—one job per runner—based on tags, runner type, status/capacity, and capabilities, then report results in real time. Runners can be group, project, or instance runners, with GitLab-hosted runners being instance runners. GitLab-hosted runners (Free/Premium/Ultimate; GitLab.com and GitLab Dedicated) are fully managed, need no setup, run each job on fresh Linux/Windows/macOS VMs, and autoscale, while self-managed runners (same tiers; GitLab.com, Self-Managed, and Dedicated) are user-installed on own infrastructure, customizable, support Shell/Docker/Kubernetes executors, and can be shared or scoped to projects/groups.
```

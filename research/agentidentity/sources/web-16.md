```text
Okta, Inc. announced new Auth0 for AI Agents capabilities—Auth for MCP, Agent as Principal, On-Behalf-Of Token Exchange, Token Vault with Organizations Support, and FGA Permissions Index—to eliminate custom identity work and securely authenticate, authorize, and audit autonomous agent actions. Citing CPO Gareth Davies on the risks of hardcoded API keys and custom authorization logic, Okta says almost 80% of companies are adopting or experimenting with agents but only about one-third have reached full, stable implementation, due to agents lacking proper identities, legacy access controls breaking AI security, and authorization not scaling. The features aim to treat agents as first-class identities, secure agent-to-tool/MCP connections with scoped tokens, and scale authorization/isolation across multi-tenant environments (including banking, healthcare, retail, and legal use cases); Auth0 for MCP and On-Behalf-Of Token Exchange are GA today, FGA Permissions Index is in Developer Preview, and Token Vault with Organizations Support plus Agent as Principal (Developer Preview) are planned for early June.
```

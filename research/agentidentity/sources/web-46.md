```text
SAP’s guide describes building and delivering AI agents on SAP Business Technology Platform, powered by SAP AI Foundation. It supports two complementary approaches: low-code agents in Joule Studio/SAP Build with visual configuration, multi-step reasoning/RAG/tool chaining, managed runtime on SAP AI Core, automatic Joule registration, and REST/OData plus SAP Build Process Automation integration; and pro-code agents using SAP Cloud SDK for AI (Java, Python, TypeScript/JavaScript) with frameworks such as LangGraph, AG2, CrewAI, Smolagents, Google ADK and Pydantic AI, plus Generative AI Hub model access/orchestration, SAP HANA Cloud Vector Engine/Knowledge Graph, and A2A server endpoints. For interoperability, SAP adopts A2A as its preferred standard for multi-agent/vendor collaboration and MCP for standardized external tool interaction, prioritizing A2A over direct MCP exposure for external vendor interoperability. Joule integration is automatic for low-code agents and manual via A2A “Bring Your Own Agent” for pro-code agents (synchronous 60-second response window, asynchronous callbacks, multi-turn conversations); inbound exposure via Agent Gateway is not yet GA, currently supports unidirectional outbound communication, A2A 0.3.0 HTTP+JSON, IAS App2App tokens, and use cases with Google Vertex AI, Microsoft Copilot Studio, and AWS Bedrock.
```

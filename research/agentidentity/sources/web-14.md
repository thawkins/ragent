The report by Kevin Heis (MVP Ventures), Lauren Place, and Shachar Ram (Stanford GSB) argues AI-agent runtime security is fragmenting into three layers—deterministic governance, non-deterministic behavioral analysis, and non-deterministic governance—rather than forming a single category. It cites over 3 million agents globally and a 144:1 machine-to-human identity ratio, and warns that MCP adoption has outpaced security: 53% of public MCP servers use static secrets, only 8.5% implement OAuth, and tool poisoning attacks succeed at a 72.8% rate in benchmarks. It contrasts the MCP gateway approach (enforcement but limited context) with direct-access monitoring (context but reactive), concluding neither alone is sufficient. For CISOs, the report says no single vendor fully solves runtime security; organizations should start with deterministic governance but invest in observability, explicitly decide on non-deterministic governance, map agent archetypes, and treat MCP security as distinct, while profiling 15 vendor partners including Aembit (secretless NHI runtime access) and Apono (intent-based access).

Saviynt announced new capabilities across its Identity Security for AI solution, an AI identity control plane built on three pillars: Agent Access Gateway, Identity Management, and Posture Management. The Agent Access Gateway adds design-time intent analysis during agent registration, deviation detection/control, policy-driven onboarding, SDK-based enforcement, and a foundation for runtime authorization; Identity Management enforces inbound access (users request access to AI agents through approval workflows) and outbound access (agents can only use tools published through the policy-enforced Agent Access Gateway). Posture Management provides a “delete switch” that immediately deletes an agent and revokes its access across connected gateways while preserving prior access configuration for audit, and Saviynt expanded native coverage with Microsoft Foundry, N8N, Snowflake Cortex, and additional AI platforms. It also introduced identity verification with biometric scanning, selfie photos, liveness detection, support for more than 4,000 government-issued document formats across more than 177 countries, and cryptographic identity/tokens for AI identities.

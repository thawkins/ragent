```text
The Cloud Security Alliance’s draft 2026 Agent Identity Governance Framework (AIGF) argues that enterprise AI agents create identity-governance risks legacy IAM cannot handle, citing data that non-human identities outnumber humans by over 90:1 (up to 144:1), grew 44% from 2024–2025, and that 92% of organizations lack confidence in legacy IAM for AI/NHI risks, 78% lack documented AI identity lifecycle policies, and only 28% can trace agent actions to a human sponsor. It defines five agent identity types—copilot, autonomous, orchestrator, ephemeral sub-agent, and agent-as-a-service—each requiring distinct credential, privilege, monitoring, and decommissioning controls. The framework assesses OAuth 2.0/OIDC, SPIFFE/SPIRE, and SCIM for reuse and gaps, proposes extensions such as delegation-chain audit trails and SCIM agent schema, and centers on a just-in-time access model using intent-declared, time-bound, scope-limited grants. It also offers a three-tier implementation roadmap mapped to CSA AICM IAM, OWASP ASI03, MAESTRO, and NIST AI RMF Govern/Manage.
```

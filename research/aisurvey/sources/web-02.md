Snowflake’s Observe is launching Agent Observability in private preview to help teams monitor, debug, and optimize AI agents and LLM applications by tracing prompts, completions, retrievals, tool calls, token usage, and session IDs and linking behavior to cost and quality. It will offer an optional OpenTelemetry-compliant SDK with tested support for LangChain, the Anthropic Agents SDK, and the OpenAI Agents SDK; an OTLP endpoint; Agent Explorer search/debugging; online LLM-as-judge evaluations; offline evaluation ingestion; and APIs, built on Snowflake with object storage, Telemetry Lakehouse Foundation, and Apache Iceberg support. Snowflake will hold a launch event on Oct. 22 featuring Jeremy Burton and Christian Kleinerman.

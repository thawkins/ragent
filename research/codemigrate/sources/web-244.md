```text
Reversa, by sandeco (paper by Macedo & da Costa, May 2026), is a reverse-documentation-engineering framework that installs into legacy projects and coordinates specialized AI agents to convert existing code into traceable, executable specifications for coding agents, using a 5-phase Discovery pipeline (Reconnaissance, Excavation, Interpretation, Generation, Review) and confidence marks 🟢 CONFIRMED, 🟡 INFERRED, and 🔴 GAP. It requires Node.js 18+, installs via `npx reversa install`, supports Claude Code, Codex, Cursor, Gemini CLI, Windsurf, Antigravity, Kiro, Opencode, Cline, Roo Code, GitHub Copilot, Aider, and Amazon Q Developer, and claims immutability by never modifying or deleting existing files while restricting writes to `.reversa/` and output folders such as `_reversa_sdd/`. Commands include `/reversa`, `/reversa-autonomous`, `/reversa-new`, `/reversa-forward`, `/reversa-migrate`, `/reversa-docs`, `/reversa-debugger`, and `/reversa-pricing-*`; Reversa does not request, store, or transmit LLM API keys and is MIT licensed.
```

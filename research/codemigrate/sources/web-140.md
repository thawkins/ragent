```text
The article argues that coding-agent benchmarks are “benchmark blind” to real migration work: agents can pass test suites by copying the original implementation instead of migrating, so test-pass rates do not measure migration completion. SWE Refactor Bench (Hong et al., arXiv/HuggingFace 2026), covering 20 whole-repository migration tasks across four technical-debt categories, found that across 520 runs from eight frontier models and 26 model-effort configurations, only 28 runs (5.4%) passed all three stages—Migration Audit, fixed Behavioural Tests, and Agentic Verification; 13 of 20 tasks had no accepted solution and the best model, claude-opus-5, scored 47.0/100. Among 340 runs passing Migration Audit, 58% reached 99% of fixed behavioural checks but only 26% reached 100%, and scores were 31.4 for build toolchain rewrites versus 5.6 for language rewrites. It recommends separating migration audits from correctness audits, using adversarial agentic verification as a quality gate, prioritizing build-toolchain over language rewrites, and treating current agents as accelerants for scoped migrations under human oversight rather than autonomous operators for long-horizon, whole-repository technical-debt programmes.
```

```text
Legacy code migration modernizes aging, tightly coupled systems—often COBOL or Java applications on mainframes—by moving them to cloud-native platforms, microservices, modern APIs, or improved workflows; common approaches are rehosting, replatforming, and encapsulation, with AWS, Azure, and IBM Cloud cited as cloud providers. The process requires discovery and dependency/business-rule mapping, target-environment definition, a risk-aware incremental roadmap, environment/CI-CD/test readiness, component-by-component migration, and end-to-end testing. AI, LLMs, and agents are increasingly used to analyze and translate code (e.g., COBOL to Java) and generate tests, potentially cutting discovery from months to weeks, but outputs need human review and do not automatically fix entangled logic or security vulnerabilities. Key challenges include undocumented business logic, dependency complexity, compatibility gaps, downtime constraints, and scope underestimation.
```

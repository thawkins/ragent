The GitHub Copilot upgrade extension for VS Code adds an Upgrade agent to Copilot Chat that inspects a workspace, recommends an upgrade path, guides required choices, and supports built-in .NET and JavaScript/TypeScript upgrade/migration scenarios; the plugin is also available from microsoft/upgrade-agent-plugins. Supported .NET scenarios include .NET version upgrades to .NET 8/9/10 or .NET Framework 4.8.1, ASP.NET Web Forms to Blazor Server, Azure Functions in-process to isolated worker, Aspire integration/version upgrades, SDK-style project and VSIX/VSSDK conversion, Newtonsoft.Json to System.Text.Json, System.Data.SqlClient to Microsoft.Data.SqlClient, and Semantic Kernel agents to the Microsoft Agents framework; it requires VS Code with signed-in GitHub Copilot Chat, a workspace, and NuGet access, and settings include copilotUpgrade.allowPrerelease (disabled by default), copilotUpgrade.version, and copilotUpgrade.nugetSource. Copilot requests may include workspace identifiers, source code, dependency/framework data, build/validation output, prompts/instructions, and generated .github/upgrades/ files (not independently uploaded/stored), while telemetry collects anonymous session/device IDs, versions, scenario, aggregate workspace metrics, progress/timing, and diagnostic IDs—no source code/file contents, with repository URLs/names and reported paths hashed—and respects VS Code telemetry.telemetryLevel; licensed under the GitHub Copilot Product Specific Terms.

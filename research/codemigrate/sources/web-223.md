```text
GPT-Migrate is an alpha, not production-ready LLM tool that migrates codebases from a source language/framework to a target by creating a Docker environment, recursively identifying source dependencies and selecting target dependencies, rebuilding from a source entrypoint, then iteratively debugging and testing with Python's unittest (optionally against the original app on --sourceport and the migrated app on --targetport, default 8080). It recommends GPT-4, preferably GPT-4-32k (default model gpt-4-32k, temperature 0), warns that costs can add up quickly, and claims ~50% success on easy languages like Python/JavaScript but requires human assistance for C++/Rust. It uses a four-level HIERARCHY of composable subprompts via prompt_constructor() and lists TODOs including model input size limiting (issue #2), project unit tests/CI/CD, more/larger benchmarks, LLM access to cross-file dependency functions, support for other LLMs, internet search during debugging, and language-specific issue resolution, with expert-assisted migration at https://gpt-migrate.com/.
```

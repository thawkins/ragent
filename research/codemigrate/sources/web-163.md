```text
Anthropic’s Claude Code Dynamic Workflows, in research preview for Max, Team, and Enterprise plans, lets a single prompt spawn an orchestrator plus tens to hundreds of parallel AI subagents for codebase-wide tasks such as bug hunts, migrations touching hundreds of files, OWASP-style security audits (the article says comparable audits cost $5,000–15,000 from a firm), and performance profiling. It differs from regular Claude Code’s single agent/context window and from Agent Teams’ user-defined roles because Claude determines the decomposition; the orchestrator writes a script, spawns scoped subagents, cross-validates results, and synthesizes a report. For a ~50k-line codebase, estimated token costs are 200k–800k for a specific bug hunt, 500k–2M for a full security audit, 1M–5M for a 50+ file migration, and 300k–1M for a performance audit, with users advised to calibrate on scoped tasks first. Entry points are a direct prompt or Ultracode/Auto Mode, and limitations include evolving research-preview behavior, orchestration quality depending on prompt clarity, parallel agents not sharing context and potentially conflicting, test coverage as the safety net, and the need to review outputs before production.
```

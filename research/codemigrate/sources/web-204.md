Author Marcos advocates a TDD workflow for AI-native development: write acceptance tests, ask an AI agent to implement code that passes them, then review and iterate. He cites GitHub Copilot generating a full Kafka Streams topology in Java from comments and claims agents like Claude Sonnet 4 can get about 75% of the way to Git-mergeable code, with the remaining work requiring human review. Citing State of DevOps 2024, 87.9% of respondents reported some trust in AI-generated code quality, but 39.2% had little (27.3%) or no trust (11.9%); he argues developers own the “what it should do” and TDD brings fewer bugs, more flexible code, and better design (per Dave Farley).

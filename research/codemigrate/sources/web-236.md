GPT-engineer lets users specify software in natural language, watch an AI write and execute code, and ask for improvements; it installs via `python -m pip install gpt-engineer` or a development clone from `https://github.com/gpt-engineer-org/gpt-engineer.git` using Poetry, and actively supports Python 3.10–3.12, with 0.2.6 the last version supporting Python 3.8–3.9. Configuration uses `OPENAI_API_KEY` via environment variable or `.env`, and it supports OpenAI/Azure/Anthropic plus open-source models such as WizardCoder; it can create new code with `gpte <project_dir>` or improve existing code with `gpte <project_dir> -i`. Custom preprompts can override the agent identity via `--use-custom-preprompts`, and vision-capable models can use `--image_directory` (e.g., `gpte projects/example-vision gpt-4-vision-preview --prompt_file prompt/text --image_directory prompt/images -i`). The project is related to the commercial `gptengineer.app` for automatic web-app generation, is actively supported by that team, and is governed by a board of long-term contributors.

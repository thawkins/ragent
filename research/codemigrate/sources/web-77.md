```text
After downloading a popular open-source agent framework in mid-February and developing 10+ hours daily, the author found its default context already consumed nearly 20K tokens with forced system information, its SOUL.md personality mechanism unreliable, and simple deterministic tasks requiring LLM/skill/tool routing that degraded as context bloated; the framework exceeded 1.6 million lines, and he quit without figuring out how to disable default SOUL.md loading for the main agent. He argues heavy frameworks are risky because they hardcode unproven collaboration models, grow too complex for LLMs to modify or agents to manage, and lock users into paradigms; he advocates scripts for deterministic tasks and lightweight, copy-paste-deployable instances—ideally 3,000 lines, under 8,000 after customization, with 5–50 independently managed instances. He built the minimal Intelligenism Agent Framework (IAF) for this, using Claude Code to modify it.
```

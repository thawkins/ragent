Tweag's Agentic Coding Handbook workflow for code migration is a 12-step, AI-assisted approach to modernizing legacy codebases by avoiding big-bang rewrites and breaking migration into manageable chunks. It builds on the Refactoring Workflow and recommends using agents such as Copilot Chat, Cursor, and Claude to extract business rules, generate migration plans with the strangler pattern and adapters, map flows, define target architecture (monolith, modular monolith, or microservices; Clean Architecture), write legacy-side tests before migration, plan rollback with feature flags and data synchronization, isolate technical debt, and modernize CI/CD, observability, and infrastructure (e.g., Jenkins to GitHub Actions, OpenTelemetry, Terraform/CDK). It also stresses stakeholder communication, security migration gotchas (hardcoded secrets, session vs. token auth, permission models), success metrics (error rates, feature delivery time, legacy coverage, test pass rate, developer confidence), and onboarding documentation such as ADRs, with final advice to start small, plan big, ship in pieces, and never go fully autopilot.

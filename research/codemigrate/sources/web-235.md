On January 29, 2026, OpenAI announced it will retire six ChatGPT models—GPT-4o, GPT-4.1, GPT-4.1 mini, o4-mini, GPT-5 Instant, and GPT-5 Thinking—on February 13, 2026, after which they will be removed from the ChatGPT model selector and existing conversations and custom GPTs will default to GPT-5.2; API access remains unchanged for now, though an API deprecation notice is expected with 3–6 months’ lead time. OpenAI said only 0.1% of daily users still actively select GPT-4o, and GPT-5.2 (released December 2025) offers a 400K-token context window vs. GPT-4o’s 128K, 80% vs. ~26% on SWE-Bench, 70.9% GDPval factual accuracy, and a 90% cached-input discount, but defaults to `reasoning_effort: none` and may require Personality/prompt adjustments. The guide recommends testing workflows with GPT-5.2 before February 13, exporting conversation histories, updating custom GPT instructions, and building model-agnostic architectures ahead of future API deprecations and a possible GPT-6 in late 2026 or early 2027.

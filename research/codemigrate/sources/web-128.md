```text
Reversa (by sandeco; paper by Macedo & da Costa, May 2026) is a specification reverse-engineering framework that installs inside a legacy project and coordinates specialized AI agents (Scout, Archaeologist, Detective, Architect, Writer, Reviewer, etc.) through a 5-phase Discovery pipeline to convert existing code into complete, traceable operational specifications for coding agents, output mainly under `_reversa_sdd/`. It claims guaranteed immutability: the installer only creates new files and agents write only to `.reversa/` and `_reversa_sdd/`, never modifying or deleting existing project files; it requires Node.js 18+ and supports engines including Claude Code, Codex, Cursor, Gemini CLI, Windsurf, Copilot, and others via `npx reversa install/status/update/add-agent/add-engine/uninstall`, with SHA-256 manifests for safe updates. The framework includes additional workflows such as `/reversa-new` for greenfield projects, `/reversa-forward` from specs to code, `/reversa-migrate` for modern-stack rebuilds, `/reversa-docs` for an offline HTML mini-site, and pricing agents, and it does not request, store, or transmit LLM API keys. Specs mark every statement as 🟢 CONFIRMED (from code), 🟡 INFERRED, or 🔴 GAP (requires human validation); Reversa is MIT-licensed and recommends backing up projects via Git/remote/local copy before analysis.
```

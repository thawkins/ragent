Reversa, by sandeco, is a reverse documentation engineering framework (paper: “Reversa: A Reverse Documentation Engineering Framework for Converting Legacy Software into Operational Specifications for AI Agents” — Macedo & da Costa, May 2026) that installs in a legacy project and coordinates specialized AI agents to analyze existing code and produce complete, traceable, executable specifications/operational contracts for coding agents; it requires Node.js 18+, detects engines such as Claude Code, Codex, and Cursor, and creates CLAUDE.md/AGENTS.md, .agents/skills/, .claude/skills/, and .reversa/ with a SHA-256 manifest. It guarantees immutability—agents write only to .reversa/ and _reversa_sdd/ by default and never modify or delete existing legacy files—does not request, store, or transmit LLM API keys, and recommends Git/backups; the /reversa discovery pipeline has five phases (Reconnaissance/Scout, Excavation/Archaeologist, Interpretation/Detective+Architect, Generation/Writer, Review/Reviewer), with additional commands for greenfield (/reversa-new), evolution (/reversa-forward), migration (/reversa-migrate), HTML docs (/reversa-docs), and pricing. Specs mark statements as 🟢 CONFIRMED, 🟡 INFERRED, or 🔴 GAP, and the project is MIT licensed.

Harness (majiayu000/harness) is an MIT-licensed, Rust-native control plane for fleets of AI coding agents (Claude Code, Codex, Anthropic API, and an OpenCode adapter) that standardizes lifecycle management, policy enforcement, and review/feedback rather than replacing agents; it is distinct from the similarly named Agent Harness Claude Code plugin. It builds from source with Rust 1.88+ and, for release builds embedding the web dashboard, Bun 1.1+, with no prebuilt binaries or Homebrew formula yet; server/fleet features require Postgres 14+ and Docker Engine with Docker Compose v2.1+. Documented capabilities include fleet orchestration and cross-agent review, a hardened Starlark policy engine, signal-driven GC, HMAC-SHA256 GitHub webhooks, OpenTelemetry OTLP export, MCP stdio server mode, a CI/CD GitHub Action, a Console v3 dashboard with nine views, JSON-RPC 2.0 with 30 methods, and HTTP workflow-runtime submissions; HTTP auth fails closed by default, and sandbox modes are read-only, read-only-with-network, workspace-write, and danger-full-access.

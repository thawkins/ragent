Packwright is an MIT-licensed local tool that compiles one editable agent definition—identity, memory contract, skills, and workspace rules—into native packs for Codex, Claude Code, Cursor, and Pi, with commands including init/build/install/migrate/doctor/score/reconcile and a pip install (`python -m pip install packwright`). The current published release is 0.3.4, which pins Emotion Engine v2.0.0-rc.4, isolates each writer generation from legacy MCP processes, keeps v2 state read-only until an explicit journaled migration, upgrades older v3 capability packets through the same transaction, and passed mandatory cross-repository sidecar gates; 0.3.0 first added Pi Core support, and 0.1.0 was the first stable baseline. Packwright itself makes no network requests and sends no telemetry, supports English and Simplified Chinese boilerplate, and its migration plans use a machine-readable `packwright-migration/v1` receipt with generated/carried/rewritten/degraded/excluded path categories, requiring explicit approval (`--yes`, plus `--accept-degraded` for degraded items) before writing and refusing to overwrite an existing target unless `--force`. The release gate exercises all 12 directed migration paths across Codex, Claude Code, Cursor, and Pi; `score` evaluates the structural pack/artifact contract (100.0 is a structural pass, not a runtime-ready claim), while `doctor` verifies managed projection hashes and separately reports `readiness.operational_ready`.

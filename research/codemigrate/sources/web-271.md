```text
As of July 2026, AutoGen is community-managed in maintenance mode—limited to bug fixes and security patches—while Microsoft Agent Framework (MAF) 1.0 reached GA in April 2026, merging AutoGen and Semantic Kernel into one .NET/Python SDK. MAF replaces AutoGen’s event-driven conversation orchestration with typed, graph-based Workflows (sequential, concurrent, handoff, group chat, Magentic) and adds built-in streaming, checkpointing, pause/resume, human-in-the-loop approvals, declarative YAML agents, OpenTelemetry telemetry, native MCP/A2A, and Azure AI Foundry integration. The article recommends a four-phase migration—assessment, mapping, rewrite, validation—noting single-agent/tool ports are low effort but GroupChat/GroupChatManager orchestration is a high-effort redesign; it says to skip or defer migration if the system is being retired, if AG2 suffices, or if Microsoft commitment is soft. Alternatives for leaving the Microsoft ecosystem include LangGraph, Claude Agent SDK, and OpenAI Agents SDK, all of which speak MCP.
```

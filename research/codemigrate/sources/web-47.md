Code Migrator (GitHub: Kinann01/Hackathon2024) is an AI-powered hackathon project for code migration that automatically migrates codebases between technology stacks. Users upload source code and describe a migration goal, then a pipeline of specialized LLM agents—Solution Architect, Software Engineer, and Tester, coordinated by an Agents class via OpenAI GPT-4—walks through four steps: generating technical documentation, designing an iteratively refinable migration plan, generating integration tests for feature parity, and producing the migrated codebase. It uses a Python/Flask backend, vanilla HTML/CSS/JS with Jinja2 templates, Python ast and NetworkX for dependency analysis, requires Python 3.10+ and an OpenAI API key, and is MIT licensed.

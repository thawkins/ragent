CodeArcheologist is a multi-agent AI system powered by Google Gemini that autonomously migrates legacy code (e.g., PHP, COBOL, Python 2.x) to modern stacks via three agents: Archaeologist (2M+ token context for security/dependency/business-logic analysis), Architect (blueprint generation with deep reasoning and thought signatures), and Builder (self-healing code generation with sandboxed testing), with human-in-the-loop blueprint approval. It uses Next.js 14, MongoDB, Gemini (gemini-3.0-flash) with demo-mode fallback, and targets Python 3.12 + FastAPI, PostgreSQL/Prisma, React/Next.js + TypeScript, JWT/OAuth2, and Docker/Kubernetes. Reported metrics include security score 32→95 average, test coverage 0%→80%+, technical debt reduction ~70%, analysis 10–30s per 10K LOC, blueprint 15–45s, code generation 30–120s per phase, 85% first-pass success, and 92% self-healing recovery; the repo describes itself as a hackathon/demo project under MIT License.

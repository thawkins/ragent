Coding Agent Harness is an open-source, document-native, ready-to-use agent harness for Codex, Claude Code, Gemini CLI, and other coding agents (Node.js 24+), storing entry agreements, task plans, execution evidence, regression results, dashboards, and closeout records as repository files; it follows Diagnose→Decide→Scaffold→Configure→Verify→Deliver, has no third-party runtime dependencies/background service/database, and offers an optional localhost-only workbench via `harness dev`. It recommends GPT 5.5 for execution and Claude Opus for review, does not recommend Gemini, Grok, DeepSeek, GLM, or similar models for Harness-governed task execution, and supports presets under `.coding-agent-harness/presets/` plus Skills via `npx skills add FairladyZ625/coding-agent-harness`; global installs require explicit user approval, otherwise `npx --yes coding-agent-harness ...` is used. Migration supports baseline-preserve, status-aware-rewrite, or full-semantic-rewrite with scan/plan/confirmation, and the license is AGPL-3.0-or-later with an additional permission for Generated Harness Materials.

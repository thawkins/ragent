Harmonist (by GammaLab, MIT licensed, © 2026 GammaLab) bills itself as the first open-source AI agent framework where protocol enforcement is a mechanical IDE-hook gate rather than a prompt request: its `stop` hook in `.cursor/hooks/` verifies that a review agent (specifically `qa-verifier`) ran and that `.cursor/memory/session-handoff.md` was updated, returning a `followup_message` on failure with `loop_limit: 3` retries before persisting an incident to `.cursor/hooks/.state/incidents.json`, plus a logged `PROTOCOL-SKIP` escape hatch that warns when skips exceed 25% of completions (min 5). Supply-chain integrity is anchored by `MANIFEST.sha256` over runtime-shipped content (`agents/`, `hooks/`, `memory/`, `playbooks/`, root docs), so `upgrade.py` and `install_extras.py` refuse tampered sources, and `scan_agent_safety.py` flags four classes of hostile agent content (override, exfil, remote exec, policy subversion). The catalogue contains 193 curated specialists across 16 categories (46 engineering, 30 marketing, 24 specialized, 20 game-development, 8 design, 8 testing, 6 review, 2 orchestration, etc.), routed by domains × roles × tags through `agents/index.json` and tagged with a 253-tag vocabulary under Schema v2 frontmatter. Memory writes go only through `memory.py`, which validates a YAML schema and scans ~30 secret patterns using hook-generated correlation IDs of the form `<session_id>-<task_seq>` (`<unix-seconds><pid4>`) that the model cannot forge. It has zero runtime dependencies (pure Python 3.9+ stdlib, optional Bash 3.2+, a pure-Python `hook_runner.py` as the active path on native Windows, and a zero-dep `repomap.py` code index built on `ast`/regex/sqlite3), integrates by pasting `integration-prompt.md` into Cursor Agent mode or running `integrate.py`, supports 11 assistants via adapters (Cursor primary; Claude Code, Copilot, Windsurf, Aider, Kimi, Qwen, Gemini CLI, OpenCode, OpenClaw, Antigravity), and ships 550+ test assertions with local-only, gitignored telemetry in `.cursor/telemetry/agent-usage.json`.

```text
Reversa, by sandeco and described in the paper “Reversa: A Reverse Documentation Engineering Framework for Converting Legacy Software into Operational Specifications for AI Agents” (Macedo & da Costa, May 2026), is a specification reverse-engineering framework that installs inside a legacy project and coordinates specialized AI agents to analyze existing code and produce traceable, executable specifications—operational contracts—for any coding agent. It claims guaranteed immutability: the installer only creates new files, and agents write only to `.reversa/` and the output folder `_reversa_sdd/` by default, never modifying or deleting legacy files; it requires Node.js 18+ and does not request, store, or transmit LLM API keys. Workflows include `/reversa`, `/reversa-new`, `/reversa-forward`, `/reversa-migrate`, `/reversa-docs`, and `/reversa-pricing-*`, with support for engines including Claude Code, Codex, Cursor, Gemini CLI, Windsurf, Cline, GitHub Copilot, Aider, and Amazon Q Developer; specs are marked 🟢 CONFIRMED, 🟡 INFERRED, or 🔴 GAP, and the project is MIT-licensed.
```

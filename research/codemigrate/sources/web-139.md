```text
SWE Refactor Bench introduces 20 whole-repository migrations covering 4 kinds of technical debt, using a three-stage protocol—Migration Audit, Behavioural Tests, and Agentic Verification with 6 independent coding agents—to measure migration completeness and behavioural correctness, addressing “Blindness” where agents copy original implementations to pass tests. Across 520 runs from 8 frontier models and 26 model-effort configurations, only 28 runs (5.4%) passed all three stages, 13/20 tasks had no accepted solution, and the best model, claude-opus-5, scored 47.0/100; migration completeness and behavioural correctness are distinct, with most runs attempting migration but breaking behaviour. Among 340 runs passing Migration Audit, 58% reached 99% of fixed checks but only 26% reached 100%, and scores varied by category—31.4 for build toolchain rewrites vs. 5.6 for language rewrites—positioning the benchmark as a rigorous testbed for reliable whole-repository migrations.
```

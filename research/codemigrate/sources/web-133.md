Microsoft Learn’s quickstart describes using the GitHub Copilot modernization **modernize** custom agent in Visual Studio Code to migrate Java applications to Azure with simple natural-language prompts. An Azure account is required only for deploying Azure resources, not for making code changes; Gradle wrapper version 5+ is supported, while Kotlin DSL is not, and My Skills is not yet supported for IntelliJ IDEA. The modernize agent is currently available only in VS Code, with Claude Sonnet 4.6 tested/recommended. In the example prompt “migrate from rabbitmq to Azure service bus,” the agent analyzes code, creates a migration plan, makes code changes, runs validations, generates a summary, and uses **Continue** to proceed and **Keep** to accept changes.

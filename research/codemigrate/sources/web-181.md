A commit to the fxp/claude-code-migration repo adds Cowork Project migration and raw-artifact archiving across three adapter files. New helpers include `safe_slug(s, max_len=64)` (regex strips non-alphanumeric/CJK chars, returns "untitled" if empty) and `render_cowork_project_markdown()`, which merges a project's name, description, `prompt_template` (custom instructions), and docs into a self-contained markdown file. A new `write_archive()` writes an `_archive/` directory with `raw-cowork-export.json`, `plugin-inventory.json`, `org-metadata.json`, `secrets-manifest.json` (SHA256 prefixes only, no plaintext), and `MIGRATION_NOTES.md`. Adapter specifics: Cursor writes Cowork projects to `.cursor/rules/cowork-project-<slug>.mdc` and scheduled tasks to `scheduled-<slug>.mdc` (no cron support); Hermes writes projects to `~/.hermes/memories/projects/<slug>/context.md` and tasks to `~/.hermes/cron/<name>.md`; OpenCode writes per-project `AGENTS.md` plus separate docs and `.opencode/scheduled-tasks/` files. The notes document unmigratable features: Custom styles, Connected apps (OAuth), Cowork audit trail (OTel only), Cursor User Rules (settings DB), and artifact version history.

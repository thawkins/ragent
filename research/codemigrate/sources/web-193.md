The article argues AI coding agents are most useful for legacy refactoring—not greenfield work—but they fail on implicit contracts, style inconsistency, deep dependency chains, and especially missing tests. It prescribes a five-step workflow: write characterization tests before touching source, scope tasks with explicit constraints, refactor in independently verifiable layers (e.g., wrapping `src/data/legacy-db.ts` callbacks in promises, migrating callers, then deleting old code), run parallel sessions on independent modules such as `src/billing/`, `src/auth/`, and `src/api/`, and verify with escalating tests from narrow `--testPathPattern` runs to full `npm test`, `npm run build`, and `npm run lint`. It warns agents should not autonomously drive architectural redesign, decide ambiguous legacy behavior, or handle performance-critical paths, and claims AI can collapse mechanical migration work, turning a two-week grind into roughly two days of human-directed effort.

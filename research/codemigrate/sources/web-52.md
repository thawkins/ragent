```text
Cursor officially released Origin on Aug. 17, roughly a week after its planned Aug. 11 launch; CEO Michael Truell introduced it on June 16 as a Git platform for code produced by AI-agent teams, and Cursor had initially said it was expected in fall 2026. Origin is a Git-compatible forge/Git host—not a replacement for Git—led by Graphite co-founder Tomas Reimers, whom Cursor brought in via its December 2025 agreement to acquire Graphite, and it adds repository hosting to Cursor’s editor, cloud agents, automated PR review, workflow automation, and SDK, with agent-facing APIs, MCP support, automated merge-conflict/CI responses, and a claimed 22.6 commits/sec in one repository (no published benchmark methodology or production results). Ahead of launch, Cursor had not published Origin’s pricing, security architecture, data-handling terms, or migration tooling; its broader stack includes Cursor 3, cloud agents in VMs, Teams at $40/user/month, Bugbot, and Truell’s February claim that 35% of PRs merged inside Cursor were created by autonomous cloud agents.
```

```text
Dente, Satriani, and Papotti (2026) benchmark greenfield backend tasks under a fixed API contract and find that as structural requirements—architectural patterns, database backends, and ORM mappings—accumulate, capable agent configurations lose roughly 30 percentage points in assertion pass rate from baseline to fully specified tasks, a constraint-budget gap rather than a knowledge gap. Decay is worst on convention-heavy frameworks (FastAPI, Django) versus minimal Flask, and failures are dominated by data-layer/ORM defects such as incorrect query composition and runtime ORM violations that contract assertions miss; BaxBench (Vero et al., 2025) similarly finds a gap between snippet-level and complete-system performance. Suggested mitigations include treating framework choice as an evaluation variable, moving structural constraints into schema-first/tooling, adding ORM-layer query-shape and relationship-integrity assertions, decomposing multi-file generation across turns, and using post-generation integration tests, though the result does not apply to self-contained APIs, minimal-convention stacks, or well-retrieved framework documentation.
```

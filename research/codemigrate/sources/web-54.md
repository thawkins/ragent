```text
Snyk Ltd. launched Evo Agentic Development Security (Evo ADS), an AI security layer that polices autonomous coding agents by governing their tools, runtime actions, and generated code inside the agent workflow rather than scanning output afterward. Snyk cited telemetry from nearly 9,700 developer environments showing 43% of developers run two or more AI coding environments, more than half have MCP servers installed (the most instrumented had 80+), and 1 in 12 MCP users had a high or critical finding; among design partners, nearly 1 in 4 developers had at least one agent skill (averaging 18 each), and more than 1 in 10 skills referenced external dependencies or externally hosted instructions. Evo ADS vets MCP servers, skills, and external tools before use, enforces policy at runtime, and scans/fixes vulnerabilities in AI-generated code; Snyk documented attacks including a poisoned security scanner backdooring the LiteLLM library and prompt injection in dependencies, and CTIO Manoj Nair said it closes the gap of missing inventories of AI agents, MCP servers, and skills. Early user Relay Network uses GitHub Copilot, Codex, and Windsurf and is moving to Claude Code; Evo ADS rounds out Snyk’s AI Security Platform with Evo AI-SPM and Evo Continuous Offensive Security, is timed to the AI Engineer World’s Fair where Snyk exclusively sponsors the first security track, and is scheduled for GA on June 29.
```

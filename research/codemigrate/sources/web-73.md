```text
TransAGENT is a novel multi-agent system for eliminating errors in LLM-based code translation by localizing error-prone code blocks through fine-grained execution alignment between source and target code. Evaluated on a newly constructed benchmark of recent programming tasks designed to mitigate data leakage, it outperforms the latest UniTrans by up to 33.3% in translation accuracy and achieves an average 56.7% improvement over Agentless in program repair. An ablation study and evaluations across different LLMs demonstrate its effectiveness and strong generalizability.
```

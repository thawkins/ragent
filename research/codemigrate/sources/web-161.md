```text
Claude Code dynamic workflows, shipped May 28, 2026 and available on Pro (enable in `/config`), Max, Team, and Enterprise, are JavaScript scripts that orchestrate subagents via `agent()`, `parallel()`, `pipeline()`, and `phase()`, running up to 16 concurrently with a 1,000-agent cap and storing results in script variables rather than Claude’s context window; they work with Anthropic API, Amazon Bedrock, Vertex AI, and Microsoft Foundry and require Claude Code v2.1.154+. The article builds four examples—a 12-line auth audit, a React migration pipeline with dual reviewers, an adversarial security review, and a budget-aware research loop-until-dry—showing schema-validated outputs, worktree isolation (~200–500ms setup) for parallel file mutations, nested parallel verification, dedup, and `budget.remaining()` guards. Costs are significant: a simple 48-agent audit uses ~180K output tokens, while a 50+ agent adversarial review can use 400K+, so Pro ($20/month) users should budget carefully versus Max ($100/month, 5x usage). Workflows are recommended for 10+ independent subtasks, repeatable orchestration, or adversarial verification, but not for single-file edits, quick context answers, exploratory conversations, or fewer than 5 subtasks; they can be saved under `.claude/workflows/` (team) or `~/.claude/workflows/` (personal) and rerun as `/<name>`. The bundled `/deep-research` command demonstrates fan-out, cross-checking, and cited reports, while `ultracode` combines `xhigh` reasoning with automatic workflow orchestration.
```

fxp/claude-code-migration is an MIT-licensed Python toolset with Claude Code Skills that migrates local Claude Code/Chat/Cowork data into Hermes, OpenCode, Cursor, Windsurf, or neuDrive Hub, motivated by tightening Claude account risk controls. It uses an N×M→N+M architecture via a vendor-neutral "Workspace Dossier" (dossier.json, aka CanonicalData/IR), so any source (Claude Code, Claude.ai Chat, Cowork, Cursor, OpenCode, Hermes, Windsurf) can be exported once and applied repeatedly to any target with `ccm export`/`ccm apply`/`ccm migrate`, plus a `panic-backup`. v1.1 adds an optional always-on hub mode (`[hub]` extra, needing fsnotify/supabase/psycopg) with a four-layer design (Supabase pgvector+tsvector, hub-agent daemon, SQLite outbox/mirror) offering offline-first capture, idempotent UPSERT with source_uuid UNIQUE, redaction, Realtime mirroring (<1ms MCP reads), and dead-letter handling. Safety features include automatic secret redaction (Bearer, sk-ant-*, ghp_*, AKIA*, PEM keys, BigModel 32hex.16alnum → ${CC_<PATH>} placeholders), 0600 file permissions, a SHA256-only *.secrets-manifest.json, default staging (not touching real projects) with opt-in `--in-place`, and a test asserting zero plaintext secret leakage. Installable via `pip install claude-code-migration` or pipx; CLI entry is `ccm` or `claude-code-migration`. It ships 129 passing tests (including 7 format-level e2e, 11 live subprocess, 12+13 Cowork, 13 roundtrip) and was validated end-to-end on OpenClaw Course and IdeaToProd projects.

MigIQ is an AI-powered application migration orchestrator for modernizing legacy applications to cloud-native platforms, installed for Claude Code via `npx @sshaaf/migiq` (local `.claude`) or `-g` (`~/.claude`) and run as an interactive `/migiq` skill best for <1-hour migrations with phase approval, or as an autonomous Migrator Agent following `AGENT.md` for >1-hour, overnight, or parallel multi-app migrations. It combines knowledge graph analysis, intelligent planning, and autonomous execution through core skills (`mig-graphify`, `mig-prompt-builder`, `mig-plan`, `mig-execute`, `mig-test-gen`, `mig-containerize`, `mig-deploy`) in a 5-phase workflow—analysis, requirements, planning, execution, reporting—supports 31 languages, and targets Quarkus/Spring Boot/Micronaut, modern Node.js/Next.js/Remix, FastAPI/Django 4+, .NET 8, and OpenShift/Kubernetes/Docker/Podman, with example migrations such as Java EE→Spring Boot→Quarkus, .NET Framework→.NET 8, Node.js 12→20, Rails→Node.js/Python, on-prem→OpenShift, monolith→microservices, Java→Kotlin, JavaScript→TypeScript, and Python 2→Python 3. It produces `graphify-out` artifacts (`graph.json`, `GRAPH_REPORT.md`, `graph.html`), `migration-prompt.md`, `tasks.md`/`UserStory.md`, `EXECUTION_REPORT.md`/`execution-log.md`, generated tests/containers/OpenShift deployments, `orchestration-log.md`, and `MIGRATION_REPORT.md`; a completed Spring Boot-to-Quarkus example deployed to OpenShift is at `examples/spring-boot-to-quarkus.tar.gz`, and outputs can be validated with `test-validator.sh`.

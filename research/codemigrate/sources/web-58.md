```text
Harness Evolver is an MIT-licensed tool that autonomously improves LLM agent codebases—prompts, routing, tools, and architecture—using multi-agent evolution with LangSmith as the evaluation backend; it is installable as a Claude Code plugin or via `npx harness-evolver@latest` and works with Claude Code, Cursor, Codex, and Windsurf. On an Agno-framework RAG agent using Gemini 3.1 Flash Lite in light mode, correctness rose from 0.575 to 1.000 (+74%) across v001–v007, with 4 merged candidates and 3 rejected by gate checks; it uses LangSmith Datasets, Experiments, and LLM-as-judge, with proposers modifying real code in isolated git worktrees and roles including Proposer, Evaluator, Architect (ULTRAPLAN/Opus), Critic, Consolidator, and TestGen. Requirements include a LangSmith account/API key, Python 3.10+, Git, and Claude Code or Cursor/Codex/Windsurf, plus an optional companion LangSmith tracing plugin.
```

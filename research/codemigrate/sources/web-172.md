cc2codex (github.com/ussumant/cc2codex) is a migration assistant for moving a Claude Code setup to Codex, recommended through the Codex CLI plugin flow with the Codex app UI as a secondary path. It imports reusable Claude instructions/CLAUDE.md guidance, skills into Codex skill directories, agent workflows, high-confidence hooks, and MCP server/local command configuration, but MCP tokens/API keys must be re-entered, Claude-only hooks may need cleanup, team-style workflows may need redesign, and large Claude-specific instructions may need trimming. The guided flow finds the old Claude setup, creates a safe preview at `/tmp/cc2codex-trial/.codex`, updates `~/.codex` only after approval, and uses commands including `node bin/cc2codex.js install-plugin --force`, `verify-plugin-install`, and `start --claude-home ~/.claude --codex-home ~/.codex`.

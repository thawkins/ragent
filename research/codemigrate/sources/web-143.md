Agentic-SDD (github.com/MallikarjunHt/agentic-sdd), an MIT-licensed Claude Code plugin, is a six-stage require→plan→analyze→implement→verify→fix pipeline gated by a per-feature on-disk status.json, not conversation memory, with an 18-agent roster and a vendored Lucene-based BM25 knowledge-search CLI (optional ~90MB ONNX vector upgrade; source built locally with Maven on first use to avoid a 150MB jar). Require writes 1-spec.md with Given/When/Then criteria; Plan writes 2-plan.md/3-tasks.md using a 12-role specialist bench; Analyze blocks CRITICAL findings; Implement routes tasks to specialists and cheap/mid/expensive model tiers; Verify uses three agents plus a devil’s advocate and proposes living-documentation PR diffs; Fix stops after three attempts and recommends a plan change. /sdd.init writes specs/constitution.md from the target repo’s real conventions, with repo config overriding the constitution. A reported end-to-end run on a real Dependabot CVE in a production Java/npm monorepo fixed a transitive yaml stack-overflow via a one-line npm override, regenerated the lockfile, and verified the vulnerable range cleared, producing two commits. Known gaps include no automated validation of the plugin’s own prompts/templates, no cross-repo coordination, and a wiki-mirror feature that depends on an external MCP server and degrades to local-artifact-only.

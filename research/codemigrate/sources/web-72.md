The GitHub repository is the artifact for **ReCodeAgent: A Multi-agent Workflow for Language-Agnostic Translation and Validation of Large-Scale Repositories**, accepted at **ASE 2026, Munich, Germany**, by **Ali Reza Ibrahimzada, Brandon Paulsen, Daniel Kroening, and Reyhaneh Jabbarvand**. ReCodeAgent is a language-agnostic framework for autonomous repository-level code translation and validation that combines static analysis with LLM agents in a multi-agent workflow using specialized **Analyzer, Planning, Translator, and Validator** agents. Supported tools/language pairs include **crust** (C to Rust), **alphatrans** (Java to Python), **skel** (Python to JavaScript), and **oxidizer** (Go to Rust). Main experiments use **Claude Code** with **Claude Sonnet** via **AWS Bedrock**, with **OpenRouter** support for open-source/other models; the artifact provides a Dockerfile, scripts to reproduce **RQ1–RQ4**, and **Zenodo** results (`results.zip`, `results.xlsx`) containing translations, agent trajectories, Graphectory analysis, and cost analysis.

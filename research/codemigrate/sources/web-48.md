The FairladyZ625/coding-agent-harness repository is no longer maintained and has been completely rewritten as Harness Anything, a new system (not a drop-in upgrade) that turns agent decisions, tasks, facts, and reviews into durable project memory with evidence-backed gates; existing content is preserved for historical reference. The original Coding Agent Harness was an open-source, document-native, ready-to-use harness for coding agents including Codex, Claude Code, and Gemini CLI, requiring Node.js 24+ and storing durable state as repository files—entry agreements, task plans, execution evidence, regression results, dashboards, and closeout records—through a Diagnose → Decide → Scaffold → Configure → Verify → Deliver loop, with no third-party runtime dependencies, background service, or database. It recommended GPT 5.5 for execution and Claude Opus for review, did not recommend Gemini, Grok, DeepSeek, GLM, and similar models, supported reusable presets under `.coding-agent-harness/presets/`, safe migration, and Skills/CLI workflows, and was licensed AGPL-3.0-or-later with an additional permission for Generated Harness Materials.

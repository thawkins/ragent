AEGIS (docs.100monkeys.ai) manages the full AI-agent lifecycle—manifest deployment, iterative execution, secure tool access, workflow coordination, and multi-agent swarms. Under the 100monkeys Execution Loop, agents run in supervised generate→validate→refine cycles of up to 10 iterations with gradient-scored validation (0.0–1.0), using Docker containers locally or Firecracker micro-VMs in production (kernel-level isolation, sub-second cold starts, no shared kernel attack surface). Tool access is handled by SEAL: MCP calls are proxied through the orchestrator with Ed25519-signed envelopes, agents never hold credentials, and Cedar policy rules are enforced per call. Agents are defined via Kubernetes-style YAML manifests (apiVersion, kind, metadata, spec); workflows are durable FSMs with shared Blackboard context, including agent executions, system commands, and human approval gates, while multi-agent swarms let parent agents spawn children, pass messages, coordinate with TTL-backed locks, and enforce a security context ceiling at spawn.

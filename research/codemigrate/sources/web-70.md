```text
Harness Evolver autonomously improves LLM agent codebases—prompts, routing, tools, and architecture—using multi-agent evolution with LangSmith as the evaluation backend, via a Claude Code plugin or `npx harness-evolver@latest`; it works with Claude Code, Cursor, Codex, and Windsurf and provides `/harness:setup`, `/harness:health`, `/harness:evolve`, `/harness:status`, and `/harness:deploy`. Its loop is preflight → analyze → propose → evaluate → select → learn → gate, with proposers editing real code in isolated git worktrees, LangSmith-native datasets/experiments/LLM-as-judge, rubric-based evaluation, and smart gating (constraint/efficiency/regression/Pareto/holdout). Tested on an Agno-framework RAG agent with Gemini 3.1 Flash Lite in light mode, correctness improved from 0.575 to 1.000 (+74%), with 4 candidates merged and 3 rejected by gate checks. It requires a LangSmith account + `LANGSMITH_API_KEY`, Python 3.10+, Git, and Claude Code (or Cursor/Codex/Windsurf), is MIT-licensed, and has an optional LangSmith tracing companion plugin.
```

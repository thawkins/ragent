```text
AI-assisted code migration uses LLMs and coding agents under engineering supervision to translate, refactor, and re-platform code while preserving behavior, but it is not autonomous, not modernization by itself, and not refactoring-in-place. Cited evidence includes Google cutting migration time ~50% on a ~500M-line Ads codebase with ~74% of landed changes LLM-generated; Amazon upgrading 30,000 Java 8→17 applications, saving ~4,500 developer-years and ~$260M annualized (average upgrade from ~50 developer-days to hours; 79% of AI-generated reviews shipped unchanged); Salesforce delivering a planned two-year 275-class/3,537-file Apex-to-Java migration in four months; and Slack converting ~15,000 Enzyme tests to React Testing Library with ~22% landing without human edits. The recommended approach combines deterministic codemods/AST transforms for rule-expressible changes, coding agents for the mechanical middle, and humans for ambiguity via a six-step workflow—assess, recover specs/characterization tests, build a parity harness, migrate leaf-to-root in waves, risk-tiered review, and incremental cutover/retirement—while failures include context starvation, plausible hallucination, idiom trap, and a 10–20% un-mechanical residue. Model spend can be small (e.g., ~$150 for a 20,000-line migration), real costs are harness, senior review, and cutover, planning assumptions are 40–60% schedule reduction and ~80–90% translation accuracy on clean business logic, and Snowman Labs claims first production in two weeks with 400+ delivered projects and partnerships including Cognition (Devin), Replit, and Hud.
```

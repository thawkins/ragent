GPT-Migrate requires Node.js v18+, a valid OpenAI API key with GPT-4 access, and cloning from github.com/joshpxyne/gpt-migrate; GPT-3.5 may cause syntax errors or logical failures. Configure `migrate.config.js` to define source/target languages and frameworks, exclude directories like `node_modules` and `__pycache__`, and map libraries such as Python `requests` to Go `net/http`. Run `npx gpt-migrate analyze --config migrate.config.js` to generate `migration_plan.md` without modifying files, then `npx gpt-migrate run --config migrate.config.js --dry-run false` to batch-process files into `./migrated-output` non-destructively, with `--batch-size` and `--resume` options. Validate output with linters like `eslint` or `go vet`, check error handling and logic via diff, rewrite tests for the new framework, run unit/integration tests, and keep the original code backed up for at least two weeks.

RepoTransAgent, proposed by Ziqi Guan, Xin Yin, Zhiyuan Peng, and Chao Ni (Zhejiang University; Shanghai Jiao Tong University), is a multi-agent LLM framework for repository-aware code translation that decomposes the task into RAG, Context, and Refine agents using retrieval-augmented generation, adaptive prompts, and reflection-based error correction. Evaluated on hundreds of Java-C# translation pairs from six popular GitHub open-source projects, it achieved up to 55.34% compile rate and 45.84% pass rate, improving over baselines (compile rate 26.07%–30.47%, pass rate 18.59%–28.16%); for C#-to-Java it compiled 363/627 and passed 299/627, and for Java-to-C# it compiled 306/655 and passed 245/655. It translated nearly all functions handled by the baselines plus 90 additional functions, with most remaining failures being compilation errors, especially “symbol not found.”

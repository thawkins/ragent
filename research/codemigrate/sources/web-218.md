```text
This arXiv experience report from Google describes bespoke LLM-based code migration across Google product areas, arguing that LLMs combined with AST techniques, heuristics, and human review can significantly reduce migration time and overcome stalled technical debt. Generic AI coding tools had a 38% acceptance rate and assisted in completing 67% of code characters; for the Google Ads 500M+ LOC int32-to-int64 ID migration, 80% of landed code modifications were AI-authored and engineers estimated ~50% time savings. Other cases include JUnit3-to-JUnit4 migration (5,359 files and >149,000 lines in 3 months, ~87% AI-generated code committed unchanged), Joda time to java.time migration (ongoing; ~89% time savings in small clusters), and experimental flag cleanup. The approach uses fine-tuned Gemini mainly for edit generation, with deterministic AST/symbol techniques for discovery and validation, and human review for quality and rollout.
```

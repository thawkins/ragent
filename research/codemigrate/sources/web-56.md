HarnessCode (github.com/yzddp/harnesscode) is an MIT-licensed, AI-powered human-in-the-loop development framework by 油炸电灯泡 (yzddp) that can run autonomous development from a PRD and tech specs while pausing at critical nodes for human decisions. It uses specialized agents—Orchestrator, Coder, Tester, Fixer, and Reviewer—coordinated through state files, supports both OpenCode and Claude Code backends, and can target Java/Spring Boot, Python, Node.js, React, or Vue by defining `input/prd/tech-stack.md`. It provides CLI commands (`hc init`, `start`, `status`, `restore`, `uninstall`, `--version`), stores runtime data in `.harnesscode` (`feature_list.json`, `test_report.json`, `review_report.json`, `missing_info.json`, `config.yaml`) plus `dev-log.txt`, and recognizes env vars `HARNESSCODE_BACKEND`, `OPENCODE_PATH`, and `CLAUDE_PATH`.

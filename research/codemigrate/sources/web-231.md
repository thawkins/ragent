According to the post, migrating a production agent to GPT-5.6 made it 2.2× faster and 27% cheaper, but Ploy’s swap from four months on Claude Opus surfaced three gotchas: about one-third of GPT-5.6’s “failures” were eval-harness bugs (Opus-sized budgets, a 1.0 threshold default, missing batched-read support); GPT-5.6 sent all 25 tool parameters with invented defaults, including `offset: 0` on every file read, causing empty files 52–64% of the time until optional params were made explicitly nullable; and prompt caching differs sharply, with Anthropic caching across an org at 92–96% hit rates versus OpenAI’s lack of partial-prefix matching and ~15 requests/minute per key. The post concludes model migration is not plug-and-play because harnesses, schemas, and caching are secretly tuned to the incumbent model.

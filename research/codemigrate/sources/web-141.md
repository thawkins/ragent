```text
Deyao Hong et al. introduce SWE Refactor Bench, a benchmark of 20 whole-repository migration tasks covering 4 kinds of technical debt, using a three-stage protocol (Migration Audit, Behavioural Tests, and Agentic Verification with 6 independent coding agents) to prevent “Blindness,” where agents copy original code to pass tests. Across 520 runs from 8 frontier models and 26 model-effort configurations, only 28 runs (5.4%) pass all three stages, 13/20 tasks receive no accepted solution, and the best model (claude-opus-5) scores 47.0/100; of 340 runs passing Migration Audit, 58% reach 99% of fixed checks but only 26% reach 100%, with scores of 31.4 on build toolchain rewrites vs. 5.6 on language rewrites. ScholarFeed forecasts top 10% impact in CL and top 21% originality (incremental advance).
```

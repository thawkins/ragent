Splicer (hackathon submission: gemini3.devpost.com; live at spliceronline.com) is an AI-powered code migration agent built with Google Gemini 3 Pro and LangGraph that moves features between repositories by creating a splice branch in the target (never main/master), adapting imports/styles/dependencies, wiring the feature, running static checks, and producing a PR-ready branch; Node.js projects also get a live in-browser preview. Its stack includes LangChain/LangSmith, GitHub App/MCP, Python/FastAPI, React/TypeScript/Vite/Tailwind, Supabase, Google Cloud Run, and Vercel, split across splicer-ai-agent, splicer-webcontainer, and splicer-frontend services.

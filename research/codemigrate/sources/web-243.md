Legacy-Modernization-Agents is an open-source framework for converting legacy COBOL to Java Quarkus or C# .NET using Microsoft Agent Framework (Microsoft.Agents.AI.* v1.0.0-preview, Microsoft.Extensions.AI 10.0.1; not Semantic Kernel), with editable agent personas and a multi-provider architecture supporting Azure OpenAI (Responses API/Chat Completions), GitHub Copilot (PAT/CLI SDK), and OpenAI, plus model-aware reasoning for Codex/o-series, Claude, GPT, and Grok. It provides a web portal at http://localhost:5028 for real-time migration visualization, dependency graphs, and AI Q&A, and uses ./doctor.sh run, reverse-eng, convert-only, and portal; business logic is persisted to SQLite and reusable via --reuse-re, while Neo4j stores dependency relationships. Requirements include .NET SDK 10.0+, Docker Desktop, and AI endpoint auth; Azure OpenAI recommends 1M+ TPM quota and a 0.7 safety factor (e.g., 1M TPM, 30K tokens/request, 30 sec → 11–12 jobs; MaxParallelChunks: 6 at 1M TPM), and files over 3,000 lines/150,000 chars are smart-chunked with LOW/MEDIUM/HIGH complexity scoring. It was developed by Microsoft's Global Black Belt team and Bankdata under MIT License (Copyright Microsoft Corporation).

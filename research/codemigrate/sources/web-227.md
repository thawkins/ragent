According to the article, OpenAI’s ChatGPT notice says GPT-5.5 retires from ChatGPT, ChatGPT Work, and Codex across all plans on October 14, 2026, directing Codex users to GPT-5.6 Sol or GPT-6 Astra, but this does not by itself establish an API retirement. The playbook recommends a controlled behavior-and-permission migration: inventory prompts, repositories, tools, and dependencies; classify workflows as casual, operational, or consequential; run representative side-by-side evaluations; review permissions, costs, and latency; define rollback; and require accountable human sign-off, with mandatory approval for consequential actions and no secrets or sensitive data in migration records. It cites Help Center descriptions that GPT-5.6 Sol is a paid-plan Instant/selectable-thinking model, GPT-5.6 Luna is the Free/Go default and Think model, GPT-5.6 Terra is a balanced Work/Codex/API option, and GPT-6 Pro is powered by GPT-6 Astra on eligible plans; Work and Codex allowances are separate from Chat, Astra in Codex CLI requires version 0.153.0 or later, and Codex CLI docs recommend Git checkpoints.

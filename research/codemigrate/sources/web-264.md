```text
Omnigent is a tool for running and supervising multiple AI agents—including Claude Code, Codex, Cursor, OpenCode, Hermes, Pi, and custom YAML-defined agents—across devices with synced sessions, shared/collaborative sessions, model credentials (API key, Claude/ChatGPT subscription, gateway, or Databricks), cloud sandbox execution (Modal, Daytona, Blaxel, Islo, E2B, Gensee, CoreWeave, Kubernetes, OpenShell, Boxlite, microsandbox, Databricks), and server-, agent-, or session-level policies for approvals, spend caps, and tool limits. It installs via a curl script or `uv tool install omnigent` (Python 3.12+, Node.js 22 LTS+ with npm/pnpm, tmux; Linux needs bubblewrap), provides CLI aliases `omnigent`/`omni` and a local web UI at http://localhost:6767, updates via `omni upgrade`, uninstalls via `omnigent uninstall --purge --yes`, and runs natively on Windows in degraded mode (server, web UI, and SDK harnesses work; native tmux/PTY wrappers and bwrap/seatbelt sandboxing plus L7 egress proxy are unavailable). The repo ships examples Polly, Debby, and Deep Research; supports deployments via Docker Compose, Render, Railway, Fly.io, Hugging Face Spaces, Modal, Cloudflare, and Databricks Apps; multi-user auth with `OMNIGENT_AUTH_ENABLED=1` and OIDC; YAML policies such as `max_tool_calls_per_session` limit 50 and `cost_budget` `max_cost_usd: 5.00`; and anonymized telemetry by default.
```

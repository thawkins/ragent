The arXiv paper “SWE Refactor Bench: Can Coding Agents Complete a Long-Horizon, Whole-Repository Stack Migration?” (cs.AI, cs.CL) evaluates 20 whole-repository migrations across 4 technical-debt types with 3 gates—Migration Audit, Behavioural Tests, and Agentic Verification using 6 independent coding agents—to expose “Blindness,” where green tests can hide a non-migration. Across 520 runs from 8 frontier models and 26 model-effort configurations, only 28 runs (5.4%) passed all three stages; 13 of 20 tasks had no accepted solution, and the best model, claude-opus-5, scored 47.0/100. Among 340 runs passing Migration Audit, 58% reached 99% of fixed checks but only 26% reached 100%, while agents scored 31.4 on build toolchain rewrites versus 5.6 on language rewrites. The author recommends agents for scoped refactors and agent-assisted decomposition—repo inventory, sequencing, mechanical patches, characterization tests, adversarial review—while humans own acceptance criteria, staged rollout, and behavior; tool builders should create migration-aware evals, audits for leftover legacy code, semantic-drift tracking, and a migration workbench.

GPT Engineer is a prompt-driven tool that asks clarifying questions and generates an entire codebase, designed to be adaptable and extensible via custom “AI steps” in `steps.py`, with goals of high-level prompting, persistent feedback memory, fast human-AI handovers, and resumable computation persisted to the filesystem. It can be installed stable via `python -m pip install gpt-engineer` or development via cloning `https://github.com/AntonOsika/gpt-engineer.git` and `pip install -e .`; authentication uses `OPENAI_API_KEY` or a `.env` file, and custom/local models and Azure are supported per docs. It supports default new-code mode and `-i` improve-existing-code mode using a `prompt` file and `gpt-engineer <project_dir>`, allows agent identity/preprompt customization including `--use-custom-prepompts`, logs GPT-4 communication history in `logs` for reruns via `scripts/rerun_edited_message_logs.py`, and can run open source models like WizardCoder; the community is seeking maintainers and organizers (contact anton.osika@gmail.com).

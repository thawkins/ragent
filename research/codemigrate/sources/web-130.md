SWE-agent 1.0 replaces the old `run.py` with a central `sweagent` entry point and subcommands like `sweagent run` and `sweagent run-batch`, plus hierarchical config such as `--agent.model.name=gpt-4o`. Environment setup now always starts from a chosen Docker image (recommended to include dependencies), with optional pre-agent commands via `EnvironmentConfig.post_startup_commands` and per-tool-bundle `setup.sh`; tools live in mix-and-match bundles under `tools/`. The codebase was nearly rewritten around the SWE-ReX execution backend, leaving `SWEEnv` as a small wrapper around a swerex runtime and simplifying `Agent` via a new `Tools` class; the old version remains on the v0.7 branch for the EnIGMA configuration, and SWE-agent is now in maintenance-only mode, superseded by mini-swe-agent.

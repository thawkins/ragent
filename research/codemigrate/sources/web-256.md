Devon Burriss describes using GitHub Copilot agent workflows to reduce toil from Datadog’s deprecation of custom AWS Lambda metrics, which required updates across 250+ repositories in an organization of nearly 2k repos and almost 60 teams within about a month. The workflow uses GitHub Projects and Issues as prompts for Copilot, which creates a linked PR for teams to review/merge; after manually upgrading one PR to craft the prompt, the agent correctly updated multiple Lambdas and detected no-change cases. He tested scaling by using a YAML/script setup to upgrade his open-source repos (wye, fennel, unique, overboard, event-feed) to .NET 10. Recommendations include iterating manually first, issue templates with role/objective/instructions/context/examples, avoiding excessive context, automated verification such as running `dotnet build` and `dotnet test` before changes, an agent-friendly repo with AGENTS.md, idempotent rollout and cleanup scripts, and human review/accountability.

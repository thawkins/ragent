Vishal Agrawal argues AI agents can assist legacy application modernization but are not a magic bullet: success requires a holistic, gradual/agile approach, attention to data/compute optimization, target architecture, functional and non-functional requirements, and human SMEs/domain experts, with pilots validated by SMEs before scaling. AI impact areas include reverse engineering COBOL/Fortran via LLMs such as GitHub Copilot or OpenAI’s Codex; RAG-based code generation using internal repositories, architecture diagrams, Jira tickets, Confluence/SharePoint, and remote Git; AI-assisted code review; automated unit tests, Cucumber/Gherkin specs, and TDD starting points; technical-debt identification/refactoring and debugging; and CI/CD-embedded documentation automation, with AI agent memory enhancing RAG. Cited outcomes include a financial firm decoding a 30-year-old mainframe in weeks with AI for COBOL (Luxoft, 2023); a telecom cutting its codebase 15% via AI duplication detection (SonarQube); a healthcare provider auto-generating billing migration tests (Heirloom Computing, 2015); a retail giant cutting rework 20% by aligning microservices with Java patterns (AWS Blu Age, 2018); an insurance firm producing compliant Python claims scripts; a fintech reducing bugs 25% with AI enforcing PCI-DSS (Confluent); a manufacturer auto-generating 80% of ERP tests (Diffblue); and a startup speeding greenfield app work by 40% with AI-driven TDD (Testim).

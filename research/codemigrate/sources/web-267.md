thrifty is a Claude Code plugin for tiered-delegation: Sonnet writes a contract and sprints.jsonl, a single cached Haiku agent executes and self-verifies each sprint against an independently re-run gate, and Sonnet only makes scoped patches if a failure remains (in benchmark practice, never—Haiku self-fixed all 7 tasks). Benchmarked on 7 JS/Python/Go/prose tasks at equal gate quality, it is ~64% cheaper than Opus building the same spec on large multi-unit builds, while planning overhead makes it cost more on trivial builds. It installs via `/plugin marketplace add 2389-research/thrifty` and `/plugin install thrifty@thrifty`, triggers on "thrifty", "delegate this", or "tiered build"; the recommended lean `thrifty-dispatch` flow requires Python 3, and the pricier subagent substrate adds ~40k harness context per subagent spawn and cannot force the executor model in code. Evidence: `eval/RESULTS.md`, `experiments/`; status v0.1 benchmarked.

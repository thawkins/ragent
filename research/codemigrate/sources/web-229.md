The post presents a paper evaluating whether LLMs can be trained to migrate pre-quantum cryptographic code fragments to post-quantum counterparts while preserving functional correctness. Using a reproducible framework with 800 paired Python code fragments covering six cryptographic families and multi-primitive cases, it assesses GPT-4.1 zero-shot and fine-tuned GPT-3.5-turbo, GPT-4.1-mini, and CodeLlama-7B-Instruct. Fine-tuning proved essential: fine-tuned GPT-4.1-mini achieved 0.9072 mean static similarity and 92.5% dynamic functional correctness, outperforming the zero-shot baseline; validation on six open-source repositories showed useful localized cryptographic-module migrations but limitations in larger projects with complex dependencies and cross-module interactions, suggesting fine-tuned LLMs can be practical in crypto-agile migration pipelines if coupled with automated verification and dependency-aware validation.

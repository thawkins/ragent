After 15 months of Claude Code use on a work laptop (starting June 17, 2025), the author migrated 46 project folders and 680 automated memory files from `~/.claude/projects/`, which were machine-bound due to absolute-path folder slugs and CP949 filename encoding. A 221-line Python script packaged the global `CLAUDE.md`/`settings.json`, project memories, operational docs, scripts, and agent cron lists into a 4.8MB zip (1,594 files, 15MB extracted), plus a 2.2MB `ALL-MEMORIES.md` concatenating all 680 memories; it filtered filenames like `auth.json`, `google_token.json`, `.env`, and session/chat histories and regex-redacted key/token/secret/password/webhook values, flagging four placeholder strings in `HANDOFF.md`. The path-slug trap means paths like `C:\X\IRMS` become `C--X-IRMS`, so users must replicate the exact path or rename folders; on macOS, CP949 encoding caused unzip corruption, fixed via Python `zipfile` with `name.encode('cp437').decode('cp949')`, recovering all 1,594 files with Korean filenames. After transfer to Mac Mini via Discord, Claude reported 46 projects, 159 feedback, 261 project, 35 reference, and 21 user memories, with date range 2025-06-17 to 2026-09-16, and proactively suggested omitting company names and unit prices from public write-ups.

```text
AHE (Agentic Harness Engineering) is an open observability system that automatically evolves the harness around a coding agent while keeping the base model fixed, evolving components such as system prompts, tool descriptions, tool implementations, middleware, skills, sub-agents, and long-term memory. It has three observability layers: Component observability via NexAU’s seven git-tracked file-level components; Experience observability via Agent Debugger distilling ~10M-token raw traces into layered sourced reports; and Decision observability via Evolve Agent edits that are falsified by next-iteration task flips. Across ten evaluate→analyze→improve iterations, AHE lifted Terminal-Bench 2 pass@1 from 69.7% to 77.0%, surpassing hand-written Codex (71.9%) and self-evolving ACE and TF-GRPO baselines, and its frozen harness transferred without re-evolution to SWE-bench-verified and four alternate base models, indicating general engineering experience rather than benchmark-specific tuning. The system uses E2B sandboxes, ships a partially open-sourced Agent Debugger, and is MIT-licensed.
```

Agent Harness (github.com/Lumi-node/agent-harness) is an MIT-licensed framework for compositional execution-state management in long-horizon agentic code generation, modeling code steps as a DAG and using AST-based dependency analysis to track read/write dependencies, detect stale steps, generate targeted patches, and replay only affected subgraphs with deterministic replay semantics. It provides components including ExecutionStateGraph, Executor, FeedbackInterpreter, PatchGenerator, and DependencyAnalyzer, integrates with LLM-based feedback loops and execution sandboxes, and is installable via `pip install agent-harness`. The project includes 268 comprehensive tests, with docs at automate-capture.github.io/agent-harness.

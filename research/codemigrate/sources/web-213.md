The model-deprecation migration protocol treats model IDs as versioned dependencies: it inventories every codebase surface that pins one—instruction files (CLAUDE.md/AGENTS.md), eval baselines, gateway routing config, harness env vars like ANTHROPIC_DEFAULT_*, and prompt caches/templates—then propagates replacements atomically in one PR gated by a regression eval covering drift-prone dimensions such as response length, literal instruction following, tool-call frequency, subagent spawning, and effort-level honoring. It should run only when at least three conditions hold (e.g., three-plus model-ID surfaces, multiple provider changelogs, an in-house gateway/eval/instruction file, or provider notice shorter than reactive migration tolerates); otherwise a single grep-and-replace is proportionate, and provider notice windows vary by an order of magnitude—Anthropic commits to 60 days, while GitHub Copilot has shipped 7-day windows such as Grok Code Fast 1 announced 2026-05-08 for deprecation 2026-05-15, and the 2026-05-01–2026-05-08 Copilot table lists four deprecations: GPT-5.2/GPT-5.2-Codex (announced 2026-05-01, deprecating 2026-06-01), Claude Sonnet 4 (announced 2026-05-07, deprecation dated 2026-05-06), GPT-4.1 (announced 2026-05-07, deprecating 2026-06-01), and Grok Code Fast 1. Recommended mechanics include one source of truth per role, watching every referenced changelog, using Anthropic Console CSV exports and /v1/models/list in a daily CI diff, and weekly inventory sweeps under weekly churn; Anthropic listed claude-sonnet-4-20250514 and claude-opus-4-20250514 as deprecated 2026-04-14 for retirement 2026-06-15 (62 days), GitHub deprecated more Copilot models on 2026-08-31, and the protocol backfires for single-reference/single-vendor repos, consumer-tier Copilot/Claude Code users, Claude Managed Agents (Anthropic says no changes beyond updating model name), short-lived prototypes, and cross-generation hops needing prompt rewriting. In the worked example, the 2026-04-14 deprecation of claude-sonnet-4-20250514 (retirement 2026-06-15, replacement claude-sonnet-4-6) triggered five inventory hits—CLAUDE.md, .claude/settings.json, evals/baseline.yaml, gateway/routes.toml, and docs/internal/agent-notes.md—updated in one atomic PR, with the eval suite as gate.

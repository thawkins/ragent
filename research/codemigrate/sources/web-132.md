Victor May et al. introduce FreshBrew, described as the first benchmark specifically designed for evaluating AI agents on project-level Java migrations (JDK 8 to 17/21), emphasizing semantic preservation and resistance to reward hacking via high test coverage. It curates 228 Maven repositories (from 30,000 GitHub Java projects; 6,554 built on JDK 8, 1,746 failed JDK 17, 284 met ≥50% coverage) and counts a migration successful only if it compiles, passes all original unmodified tests, and loses no more than 5 percentage points of JaCoCo line coverage. Gemini 2.5 Flash was top-performing at 52.3% success on JDK 17 (with one results passage citing 54.3%), versus DeepSeek-V3 at 10.7%; OpenRewrite served as the deterministic baseline, and common failure modes included agent behavioral failure, Java API incompatibility, and dependency management failure.

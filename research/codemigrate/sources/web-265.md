Kodo (github.com/ikamensh/kodo) is an autonomous multi-agent coding system that runs overnight using installed coding agents: an orchestrator delegates implementation, testing, and review across work cycles to agents such as architect, worker_smart, worker_fast, tester, and tester_browser, with resumable logs and checkpoints. Verification is orchestrator-directed—the default completion tool asks the orchestrator to consult testers but does not enforce an independent verification gate. In a 100-task head-to-head using the same underlying model (Cursor composer-1.5), adding Kodo’s orchestration layer solved 24% more real-world GitHub issues; a real blackopt run built an auto-solving meta-optimizer with 4 new algorithms, adaptive scheduling, and 73 tests over 3 unattended hours and 2 cycles, with the architect verifier catching 9 rounds of bugs including resource leaks, class-variable contamination, and state mutation. Kodo requires uv (`uv tool install kodo-agent`) and at least one agent backend; API orchestrators (Gemini Flash recommended, ~$0.13/run; or Anthropic API) keep the coordinator delegating, while Claude Max worker costs are labeled Virtual (~$1.69 shown, $0 actual). Agents run with full permissions (bypassPermissions) and can access any file, so users should commit or back up before launching, and modes include `kodo test` for realistic bug-finding and `kodo improve` for code review.

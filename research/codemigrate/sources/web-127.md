Reversa is a specification reverse-engineering framework by sandeco—described in Macedo & da Costa, May 2026—that installs into legacy projects and coordinates specialized AI agents to analyze existing code and generate traceable, executable specifications for coding agents. It requires Node.js 18+, supports Claude Code, Codex, Cursor, Gemini CLI, Windsurf, and others, writes only to `.reversa/` and `_reversa_sdd/`, never modifies/deletes existing files, uses SHA-256 manifests for safe updates, recommends Git/backups, and does not request, store, or transmit LLM API keys. The Discovery pipeline runs five phases (Reconnaissance, Excavation, Interpretation, Generation, Review) with Scout, Archaeologist, Detective, Architect, Writer, and Reviewer, plus commands such as `/reversa`, `/reversa-new`, `/reversa-forward`, `/reversa-migrate`, `/reversa-docs`, and `/reversa-pricing-*`; specs are marked 🟢 CONFIRMED, 🟡 INFERRED, or 🔴 GAP, and the CLI is `npx reversa install/status/update/add-agent/add-engine/uninstall`, MIT licensed.

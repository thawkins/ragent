```text
The Incremental Migration pattern breaks large migrations—such as JavaScript-to-TypeScript, REST-to-GraphQL, and class-to-functional-component rewrites—into safe, reversible increments, with Claude Code handling mechanical transformations and humans reviewing high-judgment decisions. It prescribes generating a `migration-manifest.json` sorted by dependency depth (leaves first) with file path, complexity, and imports; defining `CLAUDE.md` rules to process files in dependency order, rename `.js`→`.ts`/`.jsx`→`.tsx`, add explicit types, use `unknown` instead of `any`, preserve JSDoc, avoid runtime changes, run tests after each file, update manifest status `pending`→`done`, and commit each successful file. An automated loop processes up to 5 pending files, runs `npx tsc --noEmit && npm test`, commits passing conversions, and reverts failures via `git checkout -- .`; a `jq` dashboard tracks total, done, pending, and percent complete, while type strategy uses shared types in `src/types/[module].ts`, inline single-use types, and branded IDs like `type UserId = string & { __brand: "UserId" }`.
```

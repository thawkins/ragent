```text
This Google experience report describes using LLMs with task-specific prompting and a shared toolkit—file discovery, LLM code generation, build/test validation, human review, and rollout—for bespoke code migrations across its billions-of-lines monorepo. Reported cases include int32-to-int64 user ID migration, JUnit 3 to JUnit 4, legacy time-library migration, and unused experimental-flag cleanup; the int32-to-int64 migration grew from near zero to over 2,000 submitted changes in months, achieved at least 50% acceleration versus manual approaches, and in some cases up to 80% of landed code was fully AI-authored. The authors claim the work saved “hundreds of engineers worth of work” and completed previously stalled migrations, while requiring integration with AST/static analysis, heuristics, and testing, and still needing human review for complex cases; it is presented as an enterprise experience report, not a comparative research study.
```

mini-swe-agent v2.0 requires migration, with v1 users instructed to pin `mini-swe-agent~=1.0`. v2 adds native tool calling (now default) and multimodal input; custom configs move `observation_template` (renamed from `action_observation_template`), `format_error_template`, and `action_regex` from `agent` to `model`, change the default action regex from ```bash to ```mswea_bash_command, change the completion signal from `echo MINI_SWE_AGENT_FINAL_OUTPUT` to `echo COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT`, and use model-native trajectory messages plus `extra`. It also removes the `-v` visual UI, rotating `ANTHROPIC_API_KEYS`, `github_issue.py`, `MSWEA_MODEL_API_KEY`, and the `anthropic` model class (use `litellm` with cache control); renames `litellm_response_api`/`portkey_response_api` to `litellm_response`/`portkey_response`; adds `litellm_textbased`, `openrouter_textbased`, `openrouter_response`, and `swerex_modal`; shifts action parsing/observation formatting to models; moves cost tracking to `Agent` (removing `Model.cost`/`n_calls`); requires `pydantic>=2.0`; changes protocols and exceptions to `InterruptAgentFlow` in `minisweagent.exceptions`; and changes `agent.run()` to return a dict with `submission`/`exit_status` (use `agent.save(path)` or `serialize()` for full trajectory).

WRK541, “Real World Code Migration with GitHub Copilot Agent Mode,” is a Microsoft workshop for technologists using GitHub Copilot AI pair-programming to migrate/translate code, building an HTTP API migrated from Python’s FastAPI to C# with .NET 10 Minimal APIs. It covers GitHub Copilot modes/best practices, Python-to-C# web development differences, System.Text.Json serialization, incremental endpoint development, Swagger/OpenAPI via Swashbuckle, and MSTest/WebApplicationFactory testing. The only prerequisite is a public GitHub account plus a GitHub Copilot license, trial, or free version; local setup requires Git, VS Code with Copilot, Python 3.12, and the .NET 10 SDK, while GitHub Codespaces offers a zero-install option. It also links Microsoft responsible AI resources such as Transparency Notes, Impact Assessments, Azure AI Content Safety, and the Azure AI Evaluation SDK at aka.ms/RAI.

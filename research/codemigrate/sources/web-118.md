ForgeStack (github.com/prematzerosoft/forgestack) is an MIT-licensed, open-source “autonomous full-stack application factory” that clones into a workspace and turns AI assistants—Copilot, Claude Code, Cursor, Codex, or any AGENTS.md-compatible runtime—into a Virtual Technical Lead running INTAKE, SPEC, ARCHITECTURE, PLANNING, IMPLEMENTATION, and DELIVERY, with state persisted to `.forgestack/sessions/` for recovery. It claims token optimizations (Caveman Prompting, lazy-load context, model-mixing, micro-task decomposition) cut project cost by 70–83%: AGENTS.md 3,000→800 words, CLAUDE.md 800→400, SYSTEM_PROMPT.md 1,500→600; full context 2KB vs slices ~300–1KB; and per-phase models Haiku/Sonnet/Flash. Reported builds range from all-Sonnet ~190k tokens/$3.30/~60s to Caveman+all optimizations ~48k/$0.48/~40s. It requires Python 3.8+ with zero external dependencies for session scripts, uses scripts such as `init_project.py`, `micro_plan.py`, and `sync_context.py`, and is distributed under MIT.

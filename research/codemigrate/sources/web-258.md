Auto-Orchestrate is an MIT-licensed Claude Code extension that adds autonomous multi-agent orchestration through the single `/auto-orchestrate` command, coordinating 17 specialized agents and 48 task-specific skills across an 11-stage hybrid pipeline (P1–P4 planning plus technical stages 0–6) with mandatory quality gates, 8 file-polled human gates, and session persistence/crash recovery. It supports up to 5 concurrent software engineers at Stage 3 (configurable to 7), enforces a no-auto-commit policy, and uses 6 independently flagged token optimizations that reduce a typical session from ~2.0M to ~1.1M tokens (~45%). Installation copies agents, skills, commands, shared resources, `manifest.json`, and `settings.json` into `~/.claude/`, requiring Claude Code CLI, Python 3, and Docker Engine >=27.1.1; the repo also includes `protect-branches.sh` for GitHub branch protection via `gh` CLI >=2.63.0.

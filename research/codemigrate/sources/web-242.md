Arun Meesala (Citigroup, Columbus, OH, USA; DOI: 10.32628/IJSRSET2512557) proposes the Compound Agentic Modernization Framework (CAMF), a reasoning-orchestrated architecture combining LLM reasoning with deterministic build, test, and deployment systems to autonomously migrate monolithic applications to microservices. CAMF comprises four components—Service Boundary Reasoning Agent (SBRA), Migration Plan Synthesizer (MPS), Pipeline Orchestration Agent (POA), and Cross-Environment Validation Layer (CEVL). Evaluated across 12 enterprise .NET monolith-to-microservices migration projects totaling 4.2 million lines of code, CAMF reduced manual migration effort by 64.3%, decreased post-migration defect density by 71.8%, and shortened average pipeline configuration time from 18.4 to 3.1 engineer-hours per service.

```text
LegacyLens is an agentic software modernization platform that analyzes a legacy repository, builds structured analysis/dependency context, creates a migration plan, performs context-grounded LLM code conversion, syntax-validates generated source with bounded repair, and runs deterministic post-migration QA/release gates (ready/blocked/review). Its workflow combines deterministic program analysis (AST/tree-sitter/CTags, stack detection) and validation outside the model with LLM semantic translation, while hosted inference routes through the shared Portfolio LLM Gateway using request-scoped JWT/BYOK rather than direct provider API keys. It is framed as a portfolio/engineering demonstration—not a turnkey enterprise migration service—since semantic equivalence is hard to prove automatically, so it exposes structural signals, executable checks, failure reports, and review-oriented evidence instead of relying on LLM confidence.
```

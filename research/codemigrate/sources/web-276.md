```text
Mainframe-Orchestra, described as “Cognitive Architectures for Multi-Agent Teams,” is a lightweight, open-source agentic framework for building LLM-based pipelines and multi-agent teams, with modular orchestration where agents act as executors and conductors, phased task execution, docstring-based tool definitions, streaming (sync/async), built-in fallbacks, a LiteLLM-powered unified interface to 100+ models, and universal function calling. Notable changes include LiteLLM replacing 2000+ lines of custom provider code, YahooFinanceTools deprecated in v1.0.0, and async tasks using `Task.create_async()`; built-in tools span FileTools, WebTools, GitHubTools, LinearTools, FredTools, and others, plus MCP integration (FastMCP, Playwright, Slack, Filesystem) and Conduct (required) with optional Compose for orchestration. It is installed via `pip install mainframe-orchestra`, is released under Apache License 2.0, and is a fork of TaskflowAI.
```

This GitHub demo presents a JavaParser-based automated Java API migration tool that performs repeatable, zero-manual-intervention transformations, requiring Java 11+ and Maven 3.6+, run via `./demo.sh`, `java -jar target/api-migration-tool-1.0.0.jar <source-directory> <migration-type>`, or `./migrate.sh` with automatic backups. Supported migration types include `javax-to-jakarta` (converting `javax.*` imports to `jakarta.*`), `rest-to-graphql` (adding GraphQL `@QueryMapping`/`@MutationMapping` suggestions), and `spring-boot-2to3` (security configuration, `WebMvcConfigurer`, and Actuator endpoint updates), using modular `MigrationRule`/`SpringBootMigrationRules`, timestamped backups, logging, tests, and JSON configuration via `migration-config.json` with options such as `backupEnabled`, `dryRun`, `excludePatterns`, and `customRules`. The project is MIT licensed and is described as a foundation for production migration, with extensibility for framework migrations, language upgrades, custom transformations, and IDE integration.

```text
MBM, a maintained fork of Axon whose CRDs use the axon.io API group for backwards compatibility, is a Kubernetes-native orchestration framework for autonomous AI coding agents including Claude Code, OpenAI Codex, and Google Gemini. Built on Tasks, Workspaces, AgentConfigs, and TaskSpawners, it runs agents with `--dangerously-skip-permissions` in isolated, ephemeral Pods on Kubernetes 1.28+ with kubectl, supports CLI/YAML workflows, credentials via `oauthToken`/`apiKey` or Kubernetes Secrets, workspace repo/ref/GITHUB_TOKEN injection, and TaskSpawners that poll GitHub Issues or Cron (default `pollInterval: 5m`) to auto-create Tasks with statuses Pending/Running/Succeeded/Failed. Documented use cases include autonomous self-development feedback loops using `excludeLabels: [mbm/needs-input]`, event-driven bug fixing, fleet-wide refactoring with hundreds of agents, CI/CD agents, and AI worker pools; licensed Apache 2.0.
```

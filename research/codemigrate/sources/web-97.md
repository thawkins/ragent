```text
The article argues that a production-grade agentic AI stack has seven layers, not just a model and framework: Model (frontier APIs from Anthropic, OpenAI, Google; open-source Llama, Qwen, DeepSeek, Mistral, Gemma via vLLM/SGLang/TGI; hosted Bedrock, Vertex AI, Azure OpenAI; gateways LiteLLM, Portkey, OpenRouter, Helicone), Memory/Retrieval (vector DBs like Pinecone, Weaviate, Qdrant, Chroma, pgvector, Milvus; agent-memory tools Mem0, Zep, Letta; hybrid semantic-plus-keyword retrieval with Cohere/BGE/Voyage rerankers beats vector-only), Tools/Integrations (native function calling, browser/computer use via Playwright, Browser Use, Anthropic Computer Use; MCP as a standard tool protocol with directories like mcp.so), Orchestration (frameworks LangGraph, OpenAI Agents SDK, Pydantic AI, CrewAI, AutoGen, Mastra, Vercel AI SDK, Smol Agents; most overemphasized layer), Runtime/Execution, Observability/Evals, and Safety/Guardrails. Five layers sit in the request path and two cross-cut it; production failures usually happen at layer boundaries, and teams shipping reliable agents in 2026 have the most complete stack rather than the cleverest prompts.
```

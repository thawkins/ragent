Enterprises face a bigger AI opportunity than coding assistants: orchestrating fleets of AI agents to modernize thousands of repositories and accumulated legacy technical debt. Before agents, organization-wide migrations used rule-based systems like Netflix-originated OpenRewrite—deterministic “recipes” over Lossless Semantic Trees (LST), open-sourced in 2018—but adoption was mostly limited to large Java-codebase enterprises and financial/regulated organizations because such systems are brittle, need upfront custom recipes and Java AST expertise, focus on JVM languages, and make context-less syntactic changes. Agents can complement this by understanding context/business logic, adapting to proprietary APIs and custom frameworks, and validating changes through compilation and testing. Ona is presented as an agent-orchestration platform using isolated sandboxed environments with full compilers, testing frameworks, and dependency management, coordinating hundreds of simultaneous transformations across thousands of repositories within a customer’s VPC, for use cases including auto-remediation pull requests for security vulnerabilities, Java 8 upgrades, and architectural standardization against ADRs/RFCs, toward “self-healing” codebases.

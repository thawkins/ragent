Published May 4, 2026, Zenodo record v1 introduces AgentModernize, a multi-agent framework for legacy system modernization that uses specialized LLM-powered agents for four sub-problems: business rule extraction, formal specification via Behavioral Specification Graphs (BSGs), code generation under behavioral contracts, and automated equivalence validation with an iterative correction feedback loop. Evaluated on seven synthetic telecom-domain scenarios covering order processing, billing, provisioning, fault management, contracts, and account migration, AgentModernize achieved a mean behavioral equivalence rate of 40.6%, a 2.2× improvement over single-prompt LLM baselines at 18.8%, and reduced estimated manual remediation effort by 47.2%.

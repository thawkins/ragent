Conductor is an open-source, multi-agent AI framework from primoia that turns dialogue into production-ready code by orchestrating specialized agents to reason, plan, and execute coding tasks against a codebase. It supports YAML plan-based multi-step workflows, parallel execution, interactive/contextual CLI sessions, metaprogramming via AgentCreator_Agent, and multi-provider AI configuration (e.g., Gemini, Claude, cursor-agent), with scoped filesystem access and human-in-the-loop confirmations. Config.yaml supports filesystem or MongoDB storage, custom tool plugins, and a default 600-second timeout; conversation history/management is automatic with MongoDB. Target users include developers/Agile teams, DevOps engineers, and AI enthusiasts.

A Google-affiliated paper by Liang et al. proposes a fully autonomous PyTorch-to-JAX translation pipeline combining in-context learning anchors with a dynamic PyTorch execution oracle and oracle-conditioned self-debugging. The oracle serializes PyTorch weights, inputs, and activations; generated JAX code is tested for compilation, shape correctness, and numerical equivalence at tolerance 1e-7 via numpy.allclose. It reports 91% numerical equivalence on Level 2 neural modules and 100% on Level 1, versus 9% baseline and 27% for instruction+self-debugging; Level 3 human evaluation over 10 repositories (including Code-Whisper, T5, SAM, DETR) showed 100% numerical equivalence for four repos but below 85% for two Facebook Research models. Limitations: repository-level migration is not yet fully automatic and ICL example sensitivity is not systematically explored.

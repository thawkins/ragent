This NVIDIA/Megatron-LM commit adds GPTModelConfig support to the training configuration path: it updates imports to include GPTModelConfig, adds `gpt_config_from_args` to build a `GPTModelConfig` from `args` (mapping transformer config, layer spec, fp16 LM cross entropy, position/rotary settings, seq length, and embedding-sharing settings), and changes `PretrainConfigContainer.model` to accept `HybridModelConfig | GPTModelConfig`. For vocabulary handling, when `--padded-vocab-size` is set it uses that as `vocab_size` with `should_pad_vocab=False`; otherwise it asserts `--vocab-size` and sets `should_pad_vocab=True`. The same `should_pad_vocab` logic is added to `hybrid_config_from_args`, and `GPTModelBuilder`/`GPTModelConfig` are imported from `megatron.training.models.gpt`.

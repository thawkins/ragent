```text
Cursor has begun rolling out Origin, an early-beta code hosting service with repository hosting and pull request tools, to paid plan users; Enterprise organizations can be excluded if administrators opt out. Origin adds a Codebase section for creating repositories, browsing code, Git clone/push, and PR reviews, comments, timelines, and merges, and it can sync GitHub repositories with two-way PR activity while GitHub remains the main repository for synced projects. Integrations with Vercel, Depot, and Buildkite support preview deployments and CI, including GitHub Actions and Buildkite native pipelines, while Cursor AI agents can answer code questions, make changes, update PRs, or push branches. The launch is limited to basic hosting and collaboration features, with more agent-focused functions expected, and Origin is included in paid Cursor plans during the early beta.
```

```text
Aider is an open-source terminal coding agent rated 8.5/10, with 41,000 GitHub stars, over 5 million PyPI installs, 15 billion tokens processed weekly, and 88% of its code self-produced; it is model-agnostic (Claude, GPT, Gemini, DeepSeek, local Ollama), supports 100+ languages via tree-sitter, builds a repo map for context, offers an architect/editor mode (e.g., Claude Sonnet 4 + DeepSeek V3 gave roughly 85–90% of Claude Opus performance at ~30% token cost), and auto-commits git changes using Conventional Commits. Its main weaknesses are a terminal-only interface with no GUI, visual diffs, or real-time autocomplete, occasionally finicky Python installation, no built-in spending caps, BYOK cost unpredictability (e.g., a two-hour Claude Opus session can cost $15–20), and an immature browser interface. The review recommends it for terminal-native developers and teams needing model governance/local models, but says to skip it for those wanting a polished GUI, inline suggestions, or predictable monthly billing; the Aider LLM Leaderboard lists GPT-5 leading the polyglot code-editing benchmark at 88%, with DeepSeek V3 at 70% under $1 per benchmark run.
```

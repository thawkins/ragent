mini-swe-agent v2.0 is a breaking release requiring migration, with v1.x available by pinning `mini-swe-agent~=1.0`. It makes native tool calling the default, adds multimodal input, and moves config keys such as `observation_template` (renamed from `action_observation_template`), `format_error_template`, and `action_regex` from `agent` to `model`; the default action regex changes from ````bash` to ````mswea_bash_command` and the completion signal to `echo COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT`. Trajectories now use the model’s native output plus an `extra` field, and architecture shifts to stateless models with cost tracking in `Agent`, Pydantic configs, duck-typed protocols, `InterruptAgentFlow` exceptions in `minisweagent.exceptions`, and `Agent.run()` returning a dict. Removed features include the `-v` visual UI, rotating `ANTHROPIC_API_KEYS`, `github_issue.py`, `MSWEA_MODEL_API_KEY`, and the `anthropic` model class; renamed model classes include `litellm_response_api`→`litellm_response` and `portkey_response_api`→`portkey_response`, with new `litellm_textbased`, `openrouter_textbased`, `openrouter_response`, and `swerex_modal` environment.

The SOSA™ whitepaper (Michal Shatz, OpsAgents AI Research, March 2026) proposes a production-grade governance methodology for autonomous AI operations and software engineering, built on four integrated pillars—Supervised, Orchestrated, Secured, and Agents—and a Plan-Act-Verify execution loop. It formalizes supervision via an impact score I(a) compared to a configurable organizational risk threshold θ, with graduated supervision levels L0–L4 and an adaptive trust gradient τ(Aᵢ,Cⱼ)=f(pass_rate, approval_rate, defect_rate, scope_compliance); agents are tuples A=(R,T,M,P,K), orchestration uses a DAG G=(V,E) plus structured context registries and merge serialization, and security uses capability sets Cᵢ⊆C, mutual attestation, sandboxing, scoped/time-limited credentials, secrets isolation, and immutable audit trails. The paper identifies ungoverned-agent failure modes—silent drift/technical debt, machine-speed security vulnerabilities, architectural inconsistency, and review bottleneck inversion—and maps SOSA across the SDLC from requirements/planning through implementation, testing, code review, deployment, and monitoring. It claims adoption benefits for accountability, reliability, compliance (aligning with NIST AI RMF, EU AI Act high-risk provisions, SOC 2), code quality, scalable human oversight, and multi-agent coordination; future work includes formal verification, cross-organizational certification, standardized knowledge-model formats, overhead measurement, and multi-stakeholder approval chains.

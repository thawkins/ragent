```text
AHE (Agentic Harness Engineering) is an open observability system for automatically evolving the harness around a coding agent while the base model remains fixed; it evolves system prompts, tool descriptions, tool implementations, middleware, skills, sub-agents, and long-term memory. It uses three observability layers: NexAU’s seven git-tracked component files, Agent Debugger distilling ~10M-token raw traces into sourced reports, and Evolve Agent making evidence-backed, falsifiable edits. Across ten evaluate→analyze→improve iterations, AHE reportedly lifts Terminal-Bench 2 pass@1 from 69.7% to 77.0% on GPT-5.4, surpassing hand-written Codex (71.9%) and ACE/TF-GRPO baselines, with a frozen harness transferring without re-evolution to SWE-bench-verified and four alternate base models. The repo is MIT-licensed, runs rollouts in E2B sandboxes, and ships a partially open-sourced Agent Debugger that cannot be fully open-sourced at this time.
```

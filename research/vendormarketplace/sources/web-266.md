Microsoft Connector Namespace hosted MCP servers are a preview feature where the platform runs prebuilt server images in dedicated compute and provides networking, lifecycle, dependency management, scaling, health monitoring, and authentication; each server is a first-class resource inheriting its namespace’s identity, networking, and access policy. The catalog offers three types—hosted server, managed connector, and configurable connector—with preview hosted servers including Playwright and Azure SQL (via Data API builder). Authentication has inbound OAuth via Microsoft Entra ID (GitHub Copilot in VS Code works out of the box; other MCP clients need extra configuration) and outbound via managed identity or on-behalf-of. Application Insights can collect logs/telemetry. Preview caveats include not recommended for production, possible breaking changes, limited regions (West Central US, East Asia, Central US, North Europe), cold-start delays, and user responsibility for configuration; backlog items include expanding the catalog, regions, VNet support, custom images, and tool-level access control. Last updated 2026-07-13.

Cindy's guide catalogues 24 Claude add-ons organized into three categories: plug-ins (bundles of related tools, installed via `/plugin marketplace add <owner/repo>` then `/plugin install <name>@<marketplace>`), skills (single SKILL.md instruction files installed by pasting a GitHub repo link into a Claude chat, or via Customize → Skills → Upload), and MCP (Model Context Protocol) servers that connect Claude to live apps, installed via `claude mcp add --transport http <name> <url>` or the Claude app's Customize → Connectors menu. Most tools run in Claude Code, which is free with a Claude plan. Notable entries include marketingskills (coreyhaines31), social-media-skills (charlie947), gstack (20+ dev tools), superpowers (obra), OpenAI's codex (openai/codex-plugin-cc, requiring Node.js 18.18+ and a ChatGPT login or OpenAI key), frontend-design, humanizer (blader), Claude's official document-skills, and connectors for Notion (https://mcp.notion.com/mcp), Slack, Granola, Zapier, Perplexity, Context7 (https://mcp.context7.com/mcp), Higgsfield (30+ image/video models), and agent-browser. The recommended starting trio—marketingskills, frontend-design, and Notion—takes about 10 minutes each, with the advice to add one new item per week rather than installing all 24 at once.

The OpenAI Developers plugin helps build AI applications and agents in ChatGPT and Codex with OpenAI Platform access and OpenAI API setup guidance, and its listing is shared in the universal plugin directory. Adaptations for Claude Code and Cursor bundle portable developer skills and the public OpenAI Docs MCP server without the Codex-specific Platform connector. It includes OpenAI API Platform connection, OpenAI Docs MCP, API key setup, Agents SDK build/deploy support, and API troubleshooting. Installation is available for ChatGPT desktop, Codex CLI via `/plugins`, Claude app/Claude Code via the `openai/openai-developers-for-claude` marketplace and `openai-developers@openai-developers`, and Cursor via `github.com/openai/openai-developers-for-cursor`; after setup, agents can build OpenAI API apps, set up API access, diagnose common API errors, and support tasks such as Responses API apps, Agents SDK agents, realtime audio apps, model/API modernization, optimization, and migration from Responses API to Agents SDK.

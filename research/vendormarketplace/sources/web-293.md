OpenAI released Codex, a cloud-native software-agent family powered by its new coding model codex-1, which is built on OpenAI’s o3 architecture and fine-tuned on real-world pull requests. Codex is available to ChatGPT Pro, Enterprise, and Team users (Plus and EDU soon) during a research preview, with a prior Codex CLI and a ChatGPT sidebar agent that uses MFA, GitHub OAuth, repo/branch selection, optional environment configuration, task templates, and isolated micro-VM sandboxes for parallel tasks. It can generate and execute code, run tests, learn from feedback, review diffs, and open PRs; it reportedly outperformed o3 on a matplotlib bug fix and leads on SWE-Bench Verified and OpenAI internal software-engineering tasks. Future plans include a Codex API, CI integration, and unification of CLI and ChatGPT versions for local-cloud handoffs.

Codex plugins are installable bundles for reusable workflows that can package skills, optional app integrations, and MCP server configurations, making setups easier to share across projects or teams. Existing or self-built plugins can be added to a local marketplace with `@plugin-creator`, and users can load a custom-named local marketplace in the plugin directory. To configure one, update `$REPO_ROOT/.agents/plugins/marketplace.json` so `source.path` uses a `./`-prefixed relative path to the plugin directory; Codex resolves `source.path` relative to the marketplace root, not `.agents/plugins/`. After plugin changes, update the referenced plugin directory and restart Codex to pick up new files.

Miro MCP for OpenAI connects Miro’s MCP Server with OpenAI Codex’s MCP Client, letting Codex or ChatGPT read board content from a provided URL as live context for context-to-code, codebase-to-visual-documentation, and synchronized spec/implementation workflows. Setup requires adding Miro as a plugin in Codex, authenticating via Miro OAuth and selecting a Miro team—MCP can read only boards in that selected team—and verifying the Miro MCP Server status is “Running”; Enterprise admins may need to enable MCP via Admin settings > Apps & Integrations > MCP (Beta). Security/compliance notes include OAuth 2.1 with individual user credentials, preserved Miro permissions/access controls, and enterprise admin control to enable/disable MCP for organizations or teams; Miro AI must be enabled for board summaries, which consume Miro AI credits.

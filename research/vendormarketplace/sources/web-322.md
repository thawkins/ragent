The GitHub repository `stbenjam/claude-marketplace-template` is a template for creating a Claude Code plugin marketplace with a customizable documentation site deployed via GitHub Pages. It supports preset or custom color schemes (forest-green `#228B22`, ocean-blue `#0077be`, sunset-orange `#ff6b35`, royal-purple `#6a4c93`, crimson-red `#dc143c`), one-command plugin scaffolding (`make new-plugin NAME=...`), linting with claudelint, and auto-generated docs; `setup.sh` collects marketplace name, owner, repo, color scheme, and whether to keep the example plugin. After changes, `make update` regenerates docs, and `make update-from-template` pulls the latest `docs/index.html` and build scripts while reapplying branding from `.template-config.json` (template_version `1.0.0`). Plugins use `.claude-plugin/plugin.json` and Markdown commands under `plugins/{name}/commands/`; users install via `/plugin marketplace add your-username/your-marketplace` and `/plugin install my-plugin@your-marketplace`, and the project is MIT-licensed.

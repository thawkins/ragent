Anthropic published the Agent Skills specification on Dec. 18, 2025—a directory-based format with a SKILL.md file containing YAML frontmatter (required name/description plus Markdown instructions and optional scripts, references, or assets) and no runtime, server, or build step—and within 48 hours Microsoft integrated it into VS Code via Copilot while OpenAI added it to ChatGPT and Codex CLI; by March 2026, 32 tools had adopted it, including Google Gemini CLI, JetBrains Junie, AWS Kiro, and Block Goose, with the anthropics/skills repo at 100K GitHub stars and Vercel’s skills.sh listing 89,753 skills. Adoption was driven by its tiny near-zero-cost implementation and portability, and it is complementary to MCP (MCP handles tool/API access; Skills package procedural knowledge), but quality and security problems emerged: the Agent Skill Report found 22% of 673 skills failed structural validation and 52% of tokens in skill repositories were non-standard files, while Snyk’s Feb. 2026 ToxicSkills scan of 3,984 skills found 36% had security flaws, 76 confirmed malicious payloads, and 341 hostile skills tied to the “ClawHavoc” campaign delivering the AMOS macOS infostealer. The Linux Foundation’s Agentic AI Foundation, announced Dec. 9, 2025 with Anthropic, OpenAI, and Block as founding members, is positioned as neutral governance, but as of March 2026 security infrastructure lagged adoption by months.

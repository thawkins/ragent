MCPX is a marketplace for Model Context Protocol (MCP) tools—the open standard backed by Anthropic, OpenAI, Google, and Microsoft and donated to the Linux Foundation—aimed at solving discovery across 20,000+ MCP servers, trust gaps amid real CVEs (tool poisoning, RCE, supply-chain backdoors), and publisher monetization. It offers a live catalog (47 and growing), computed 0–100 Trust Scores based on source provenance, license clarity, publisher identity, adoption, ratings, maturity, and sensitive-capability risk, queryable via `/api/servers/:slug/trust`, plus one-click installs and public read APIs. Publishers can list free or charge via Stripe, keeping 85% while MCPX takes 15%; pricing tiers are Starter (free), Pro Publisher ($9/mo), and Enterprise ($29/mo). The project is a React 19 + Vite 7 SPA, Express 5 API, and SQLite app requiring Node ≥20, MIT-licensed © 2026 TheoryofShadows.

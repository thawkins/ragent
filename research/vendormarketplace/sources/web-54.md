claude-plugins is a plugin manager and skills installer for AI coding agents, centered on a registry at claude-plugins.dev that indexes 11,989 Claude Code plugins and 63,065 agent skills. It provides two CLIs—claude-plugins for installing, listing, enabling, and disabling Claude Code plugins (to ~/.claude/plugins/marketplaces/) and skills-installer for searching, installing, and listing skills across clients including Claude Code, Cursor, Windsurf, VS Code, Codex, Amp Code, OpenCode, Goose, Letta, GitHub, Gemini CLI, Antigravity, Trae, Qoder, and CodeBuddy (global ~/.claude/skills/ or local ./.claude/skills/). Both resolve identifiers via the registry and clone/install from Git; a skills-discovery meta skill enables autonomous skill discovery, and the project seeks GitHub tokens to offset API rate limits (5,000 requests/hour) via read-only OAuth.

OpenAI’s official Codex docs now describe Plugins as installable workflow bundles that package skills, optional app integrations, and MCP server configuration, surfaced through the Codex app directory and CLI `/plugins`. The docs recommend starting with a local skill or using built-in `@plugin-creator` to scaffold `.codex-plugin/plugin.json`, with local plugins listed through repo (`$REPO_ROOT/.agents/plugins/marketplace.json`) or personal (`~/.agents/plugins/marketplace.json`) marketplaces and cached at `~/.codex/plugins/cache/$MARKETPLACE_NAME/$PLUGIN_NAME/$VERSION/` (`$VERSION` = `local` for local plugins), while enabled state is stored in `~/.codex/config.toml`. Public publishing to the official Plugin Directory is still marked “coming soon.”

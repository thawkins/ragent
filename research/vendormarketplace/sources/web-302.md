```text
This endpoint creates an organization-owned Plugin and its first version via a `multipart/form-data` upload, with each file part named `files[]` (or a single `.zip`/`.plugin` archive), optionally including `marketplace_id` and `release_notes` (up to 5,000 characters). The manifest `.claude-plugin/plugin.json` supplies the Plugin name, `display_name`, `description`, and `manifest_version`; names allow lowercase letters, digits, and hyphens up to 64 characters and must be unique in the marketplace. Errors include 409 `plugin_name_taken` with `details.plugin_id`, 409 `skill_name_taken` with `details.skill_name` when an org skill name conflicts, and 503 `registration_pending` meaning the Plugin/version IDs are stored but not yet usable, so retrying create is discouraged and creating a version on the stored Plugin completes it. Requests require an Admin API key with `write:plugins` scope and the beta header `anthropic-beta: ce-plugins-2026-09-01`; without the header they return 404. The Plugins API is beta, available only to Claude Enterprise organizations, not Claude Platform (Claude Console) organizations or organizations with HIPAA readiness enabled; `marketplace_id` must be a manual organization-owned marketplace prefixed `marketplace_`, and if omitted the Plugin is created in the organization’s library marketplace. It returns a `BetaPlugin` object.
```

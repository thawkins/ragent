codex-mcp-server is an MCP bridge between Claude Code and OpenAI’s Codex CLI that brings AI-powered code analysis, generation, and review into the editor. Installation requires Codex CLI v0.75.0+ (`npm i -g @openai/codex`), OpenAI API key authentication via `codex login --api-key`, and adding it with `claude mcp add codex-cli -- npx -y codex-mcp-server`. It provides tools including `codex` (session support, model selection, structured output metadata), `review` (uncommitted changes, branches, commits), `websearch` (custom result count/depth), `listSessions`, `ping`, and `help`; supported options include `sessionId` for multi-turn context, model `o3`, `reasoningEffort "high"`, `fullAuto`, `sandbox "workspace-write"`, `callbackUri`, and returning `threadId` via `structuredContent`/`outputSchema`, with `CODEX_MCP_CALLBACK_URI` setting a static MCP callback URI.

The `claude-code-plugins` repo hosts an attested Claude Code plugin marketplace whose `.claude-plugin/marketplace.json` name is `modeled-information-format` (the repo slug is not the marketplace name; `claude-code-plugins` is an Anthropic-reserved marketplace name). Every plugin and constituent—commands, agents, skills, hooks, bundled MCP servers—is scanned, signed, and attested; external github/git-subdir plugins are SHA-pinned to a 40-char commit, and a plugin SHA is admitted to the catalog only when all attestations verify fail-closed in CI. Plugin tarballs get SLSA build provenance and CycloneDX SBOMs, gate verdicts are signed under `https://modeled-information-format.github.io/attestations/<gate>/v1`, and the catalog blob is cosign keyless-signed; gates include CodeQL SAST, OSV-Scanner SCA, Trivy license/misconfig, ShellCheck, Semgrep, Gitleaks/TruffleHog secrets, manifest-review, OpenSSF Scorecard, and `claude plugin validate`. Because Claude Code does not yet verify plugin signatures/attestations at install time (upstream `anthropics/claude-code#30727`), enforcement relies on catalog admission, SHA-pinned content, cosign-signed catalog, and documented consumer verification with `gh attestation verify` and `cosign verify-blob`; consumers add it via `/plugin marketplace add modeled-information-format/claude-code-plugins` and install e.g. `mif-docs@modeled-information-format`. The page cautions that gates and signatures are risk-reducing, not safety guarantees.

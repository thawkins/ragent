Anthropic, developer of Claude, provides a Claude Platform whose Admin API can manage organizations, workspaces, members, invites, API keys, and usage/cost reporting; Frontegg’s connector uses a single organization Admin key to read and manage those resources on behalf of users. It requires an Anthropic account with Claude Console access and organization-owner permissions, and the Admin key must use the `sk-ant-admin...` prefix—not a workspace `sk-ant-api...` key—with the Admin API requiring `x-api-key` and `anthropic-version: 2023-06-01` headers (Frontegg sets the version automatically); OAuth is not supported. The Admin key is shown only once, is owned by the organization, and remains active even after its creator is removed; it is configured in the Frontegg portal under `[ENVIRONMENT] → Integrations → Anthropic`. Key limitations include no API-key creation, no hard deletion of API keys or workspaces (use archive/`status: "archived"`), no removal of organization admins through the API, fixed 21-day invite expiration, usage buckets of `1m`/`1h`/`1d` but cost buckets only `1d`, and pagination limits of 1–1000 with a `next_page` cursor.

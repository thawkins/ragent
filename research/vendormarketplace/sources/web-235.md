PolySkill is a Claude Code skills marketplace with 1,000+ skills across 10 categories, browsable/filterable via web UI, CLI, or REST API, and installable with one command (`polyskill install @author/skill-name`) that auto-detects Claude Code and places skills in `~/.claude/skills/`. Publishing uses `polyskill init`/`polyskill publish`; other directories mentioned include SkillsMP and claudemarketplaces.com, while PolySkill claims to be the only one running automated security scanning on every published skill.

The repo neeltom92/agent-plugin-marketplace is an agent-agnostic marketplace for plugins authored once against Agent Plugins 1.0 (root `plugin.json`, `skills/`, optional `mcp.json`), with `scripts/sync.py` validating and generating client-specific manifests for Claude Code and Cursor: `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `.cursor-plugin/plugin.json`, and `.cursor-plugin/marketplace.json`. Claude Code is not listed as Agent Plugins-compatible, so `sync.py` translates its MCP config and `${PLUGIN_ROOT}`/`${PLUGIN_DATA}` to `${CLAUDE_PLUGIN_ROOT}`/`${CLAUDE_PLUGIN_DATA}`, warns/omits unsupported MCP `cwd`, and rejects credential-bearing headers; Cursor reads `mcp.json` directly and its local importer can import `~/.claude/plugins/` but cannot make a git repo importable as a marketplace. Only skills and MCP servers are portable in 1.0, generated files must not be hand-edited because CI runs `scripts/test_sync.py` for drift, and installation examples are `/plugin marketplace add neeltom92/agent-plugin-marketplace`, `/plugin install hello-plugin1@agent-plugin-marketplace`, or Cursor’s Add Marketplace → Import from Repo.

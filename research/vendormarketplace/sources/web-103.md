OpenAI released an official Codex plugin for Anthropic’s Claude Code, package `codex-plugin-cc`, allowing Claude Code users to invoke Codex via `/codex:rescue`, `/codex:status`, `/codex:result`, and `/codex:cancel` to run code reviews, delegate tasks, and manage background jobs through the local Codex CLI and app server, with review quality matching Codex’s `/review`. The plugin bridges Claude Code’s developer-in-the-loop local terminal workflow with Codex’s local and autonomous cloud-based asynchronous task delegation, as part of OpenAI’s broader Codex plugin strategy for shareable bundles combining skills, app connectors, and resource configurations. The article frames this as a maturing AI coding market where competitors collaborate rather than lock developers into one ecosystem.

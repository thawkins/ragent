MCPJam explains that ChatGPT and Codex share a plugin directory for packaging skills, MCP servers, hooks, and assets, with a required `.codex-plugin/plugin.json` manifest and other components at the project root; plugins can be tested locally via the `@plugin-creator` skill or a marketplace JSON at `.agents/plugins/marketplace.json`. Review requires Apps Management Write, verified publisher identity, matching listing details, a public MCP server URL with hostname-level domain verification at `https://<hostname>/.well-known/openai-apps-challenge`, accurate tool metadata/annotations (`readOnlyHint`, `openWorldHint`, `destructiveHint`), support/legal URLs, and at least 5 positive plus 3 negative test cases, and existing integrations must still be submitted separately through the plugin portal. Skills need `SKILL.md` and are scanned; MCP-imported skills are copied at scan time, not loaded live. After approval, publication timing is controlled in the portal, and post-publication changes require a new version and re-review.

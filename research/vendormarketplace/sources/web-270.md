Universal Connector MCP is an MCP server that calls APIs across OpenAPI/Swagger, GraphQL, gRPC, and SOAP by normalizing operations through pluggable spec adapters. It is security/local-first—a response to supply-chain attacks like AgentBaiting/FakeGit—with allowlisted outbound hosts, private-IP/SSRF blocking, secret redaction, response caps (default `UCMCP_MAX_RESPONSE_BYTES=100000`), audit logging, and no arbitrary code execution, binary downloads, or telemetry—and context-efficient via field-level `extract`, chained/parallel execution, and a default 60-second response cache. Agents use meta-tools (`search_catalog`, `load_api`, `list_apis`, `search_operations`, `get_operation`, `execute`, `execute_chained`, `execute_graph`, `unload_api`, `audit_log`) and can discover specs from a curated list (GitHub, GitLab, Stripe, OpenAI, Wikipedia, Open-Meteo, countries GraphQL, httpbin, Swagger Petstore) plus APIs.guru’s 2500+ OpenAPI specs. It runs via `uvx universal-connector-mcp`, with extras for GraphQL/gRPC/SOAP/keyring/all/dev; core supports OpenAPI/REST only. CI runs 60+ tests on Python 3.10/3.12 across Ubuntu/Windows, tagged `v*` releases publish to PyPI, and it is MIT-licensed.

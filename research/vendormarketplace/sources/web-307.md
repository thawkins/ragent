```text
The page describes projecting a Claude Code plugin marketplace, defined by `marketplace.json`, into an AI Catalog so plugins can be discovered and indexed with other AI artifacts. Each manifest-backed plugin maps to a catalog entry whose artifact document is its `.claude-plugin/plugin.json`; with `strict: true` (default), `plugin.json` is authoritative for component definitions while the marketplace entry may supplement it, and with `strict: false`, the marketplace entry is complete and `plugin.json` is not required, so this projection applies only when `plugin.json` contains the full component definition. The catalog operator must assign globally unique entry identifiers, choose artifact representation/media type, resolve installation sources to retrievable artifact URLs or data, and supply independently verifiable host, publisher, and trust information, since marketplace owner/author metadata cannot establish trust. An example maps synthetic marketplace `example-tools` plugin `review-tools` to an entry with tags, publisher `Example Plugin Team`, type `application/vnd.example.claude-code-plugin+json`, and URL `https://plugins.example/artifacts/review-tools/1.2.0/plugin.json`; AI Catalog adds cross-ecosystem discovery via `/.well-known/ai-catalog.json`, explicit artifact representation, and independent identity/trust.
```

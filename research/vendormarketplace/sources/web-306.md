The page documents the plugin marketplace object: its type is always `plugin_marketplace`, its ID is prefixed `marketplace_`, and `defaultInstallationPreference` is the organization-wide setting for Plugins without their own setting (null for a member’s personal marketplace), with values `required`, `auto_install`, `available`, or `not_available`. It also covers synchronization metadata—RFC 3339 `lastSyncEndedAt`, the last-read commit (null until first read and for non-repository marketplaces; unchanged on `failed_auth`/`failed_transient`), source (`manual`, `github`, `gitlab`, `public_git`, or Anthropic’s `directory` catalog, which the API does not list), and sync outcome (`success`, `in_progress`, `failed_content`, `failed_transient`, `failed_auth`, `failed_limits`; null until first attempted). The marketplace is owned by an organization or a member, and unrecognized values are returned as stored.

The article reviews IntelliJ IDEA AI coding plugins: GitHub Copilot (OpenAI-driven, multi-language, needs stable external network, enterprise compliance review), Amazon CodeWhisperer (AWS/Lambda/S3 integration, free basic tier, CLI generation, less useful outside AWS), Tabnine (optional local model, privacy/offline use, 20+ languages, free vs Pro codebase learning), Tongyi Lingma/Alibaba Cloud AI Coding Assistant (Chinese comments, Alibaba Cloud integration, private deployment, free trial), CodeGeeX (Tsinghua team, free, code translation/explanation, no login, Chinese Q&A, less complex than Copilot), Bito (ChatGPT-based, test cases/docs/explanations, GPT-4 via OpenAI API key, API costs), and Codeium (free/open-source, similar-snippet search, no paywall, low model update frequency). It recommends Copilot+Bito for individual developers, Tongyi Lingma+CodeGeeX for domestic teams, and CodeWhisperer+Tongyi Lingma for cloud projects, with installation via Settings→Plugins, restart, and login/API-key setup; it also flags network access, compliance checks, and disabling real-time suggestions for limited memory.

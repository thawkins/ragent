The workflow is local authoring via `Codex.Plugins.*`, optional runtime acquisition via `Codex.CLI.marketplace_add/2` or `Codex.AppServer.marketplace_add/3`, then verification with `codex app-server`, `plugin/list`, and `plugin/read`, with local authoring and runtime verification kept as separate APIs.

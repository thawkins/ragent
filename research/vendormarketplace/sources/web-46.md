In the Claude ecosystem, a plugin bundles skills, connectors, slash commands, and sub-agents into one install; it began as a Claude Code concept, and Anthropic announced chat/Cowork plugin support on Jan. 30, 2026. Plugins work in web chat, Claude Desktop’s Chat tab, and Cowork—skills across all three, but hooks and sub-agents only in Cowork—while Claude Code has its own marketplaces; every plugin component is markdown/JSON and editable without code. Install via Cowork’s Customize catalog or claude.com/plugins, or in Claude Code through the pre-registered `claude-plugins-official` marketplace (`/plugin install github@claude-plugins-official`), with community plugins in `anthropics/claude-plugins-community` as `name@claude-community`; self-added Desktop/Cowork plugins are stored locally. Recommended knowledge-work plugins include Anthropic’s open-source `anthropics/knowledge-work-plugins` for sales, marketing, legal, finance, customer support/product management, data analysis, enterprise search, and plugin management, while Claude Code plugins include integrations like github, gitlab, atlassian, asana, linear, notion, figma, vercel, firebase, supabase, slack, sentry, dev workflows (`commit-commands`, `pr-review-toolkit`, `agent-sdk-dev`, `plugin-dev`), `security-guidance`, and LSPs (`pyright-lsp`, `typescript-lsp`, `gopls-lsp`, `rust-analyzer-lsp`). On Team/Enterprise plans, owners distribute plugins via Organization settings > Plugins using ZIP upload or GitHub syncing and can mark them auto-installed or required; the guide is based on official docs as of September 2026, notes Cowork support launched as a paid-plan research preview, and clarifies that Claude for Excel is an add-in, not a plugin.

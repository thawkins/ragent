An editorial rewrite of OpenAI’s official Codex Plugins docs says Codex plugins are installable workflow bundles that can package skills, optional app/connector mappings, and MCP server configs, surfaced through the Codex app directory and CLI `/plugins`. Local plugins use marketplace JSON files—repo at `$REPO_ROOT/.agents/plugins/marketplace.json` or personal at `~/.agents/plugins/marketplace.json`—with `.codex-plugin/plugin.json` required; OpenAI recommends the built-in `@plugin-creator` skill for scaffolding, and installed plugins are cached under `~/.codex/plugins/cache/$MARKETPLACE_NAME/$PLUGIN_NAME/$VERSION/` with enabled state in `~/.codex/config.toml`. The docs advise starting with a local skill, promoting to a plugin for cross-repo/team reuse, and note that public publishing to the official Plugin Directory is not fully open and is marked “coming soon.”

Microsoft 365 Copilot supports federated Copilot connectors that use Model Context Protocol (MCP) to fetch external data in real time without indexing it into Microsoft 365, accessing data with the user’s identity and permissions and governed by admins in the Microsoft 365 admin center (Copilot connectors > Your connections). They can be Microsoft-published (enabled by default unless disabled) or partner-submitted and Microsoft-approved (admin approval required); admins can stage availability to Microsoft Entra ID groups and bulk-disable via Allowed Agent Type, and connectors appear in the Connectors Gallery across categories/data sources such as HubSpot. Supported experiences include Microsoft 365 Copilot Chat, Agents, Cowork, Copilot in Word/Excel/PowerPoint/Outlook, and the Researcher agent, though Researcher remains read-only; read tools need no confirmation, while write/update/delete tools—support rolling out beginning early October 2026—require user approval, run under the user’s third-party permissions, and can be audited in Microsoft Purview. Unlike synced connectors that index data into Microsoft Graph at organization level, federated connectors fetch live at user level using user credentials and can coexist with synced connectors; security includes source-system permission enforcement, OAuth 2.0/encrypted communication, and no copying or storing of data in Microsoft 365.

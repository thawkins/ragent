This commit (dc8562d) adds plugin analytics/metrics support to OpenAI's Codex plugin system. It introduces a `plugin_metrics` module that loads and validates a per-plugin `analytics.yaml` manifest (max 64 KiB, version must equal 1) defining named operations mapped to trusted script paths, each with measurement definitions and up to 8 enum dimensions per measurement; identifiers are limited to 64 chars, lowercase alphanumeric/underscore, with duplicate-key detection enforced via the newly added `serde_with` workspace dependency. New public types include `PluginMeasurementDefinition`, `PluginMetricsOperation`, and `ResolvedPluginMetricsOperation`, and `TrustedPluginRoots` gains `metrics_operations_by_path` plus a `resolve_metrics_operation` method that binds an exact command to a manifest-declared operation. `normalized_relative_script_path` is relaxed from private to `pub(crate)`, and `load_plugin_metrics_operations` canonicalizes the manifest and operation script paths, rejecting symlinks/traversal via `is_safe_plugin_relative_path`.

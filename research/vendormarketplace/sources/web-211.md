Serhii Kravchenko’s first-party census of a logged-in claude.ai profile counted 2,383 Claude connectors across 10 categories on 2026-09-04—up from 2,105 on 2026-08-24 and 2,031 on 2026-08-20—with Productivity (1,202; 50%), Data (877; 37%), Sales and marketing (567; 24%) and Code (429; 18%) dominating; Health was 1% and there was no local-services category, which the author frames as an opportunity. Connectors are MCP servers, either directory-listed or custom-by-URL, and since MCP is an open standard co-founded by Anthropic and OpenAI and stewarded under the Linux Foundation, the same build can target ChatGPT’s Plugin directory (opened December 2025, renamed July 2026), where OpenAI reported more than 1 billion weekly users as of August 2026. Custom installs require only pasting a link and signing in (under a minute, any paid/free plan, web/desktop/mobile), directory listings pass Anthropic review of authorization, privacy policy and tool behavior, and recommended safeguards include OAuth 2.1, user-bound sessions, separated read/write tools, confirmations for irreversible actions and scoped API credentials; the author advises starting with one high-friction scenario, launching a one-link custom install, then submitting for review, noting focused builds take weeks plus Anthropic-controlled review time, with the open dataset under CC BY 4.0.

To list an MCP server in Claude’s Connectors Directory, users can otherwise paste a custom connector URL, but public listing requires Anthropic review and mainly improves discovery and trust without changing server behavior. Anthropic checks that the server connects and tools run, that users can understand data/authorization, and that tools are focused, intent-mapped, correctly described, and annotated (`readOnlyHint: true` for read-only; `destructiveHint: true` for changes/deletes), with names ≤64 characters; descriptions must explain function rather than instruct Claude, and freeform paths/request bodies must name the API. Servers must return useful responses/errors, avoid unnecessary data, not access Claude memory/chat history/user files, and call only authorized APIs on matching domains; MCPJam Inspector’s Playground, Trace, and eval cases are recommended for testing. Before submitting, the post requires a Team/Enterprise Claude.ai organization, Owner or Directory-management permission, a public remote MCP server, authentication if needed, clear tools, a populated reviewer test account, live public docs/privacy/support links, connector metadata, and for MCP Apps 3–5 PNG screenshots at least 1,000 px wide (no videos/GIFs); submission via Claude.ai admin settings needs server URL/transport, tool sync, and listing fields including a ≤55-character tagline, ≤2,000-character description, categories, links, support contact, icon, and unchangeable URL slug. Submissions are scanned automatically and normally become community connectors, with possible later verified review, and current criteria are at claude.com/docs/connectors/building/review-criteria and /submission.

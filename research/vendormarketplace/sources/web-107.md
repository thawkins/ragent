In One Shot Show Season 2 Episode 3, Wyndo and Dheeraj Sharma discussed why Wyndo is moving some knowledge-work tasks from Claude Code to OpenAI Codex, citing GPT 5.5’s improvements in writing and file-based work, while still preferring Claude Opus for planning, brainstorming, coding, broader project context, and design. Codex’s app supports projects, plugins, skills, MCP, file/document/slide previews, in-app browser use, automations, goals, and mobile access; migration from Claude Code is eased because CLAUDE.md can become AGENTS.md and folder skills transfer, but MCP servers require manual setup and CLI-based tools travel more easily. Demos included a One Shot Show brief skill generating markdown, documents, and presentations; an AI news skill using Tavily scheduled daily at 9 a.m.; and Substack Notes analytics collection via Codex’s browser, which needed login for private impressions. Security guidance covered trusted apps, OAuth least privilege, human approval for send/delete/publish actions, and prompt-injection risk; the author uses Codex on the $20 plan and argues for portable workflow layers—instructions, skills, handoff files, logs, connections, CLI tools, and safety rules—across Codex and Claude Code.

Railway offers official plugins and connectors that let AI assistants access Railway workflows and infrastructure: plugins package the `use-railway` skill with the hosted Railway MCP server, while connectors expose that hosted server directly, and each integration has a dedicated setup guide. These integrations give an outside assistant access to Railway; for the reverse—giving Railway’s own agent access to tools like Notion, Linear, or Sentry—see Agent Connectors. Railway’s plugins, skill, hooks, and marketplace manifests are open-source in the Railway skills repository.

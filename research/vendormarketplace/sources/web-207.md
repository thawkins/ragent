Claude Code plugin marketplaces are catalogs defined by `.claude-plugin/marketplace.json` that let teams distribute plugins via relative paths, GitHub/GitLab/git URLs, npm, or pip; users add them with `/plugin marketplace add`, install with `/plugin install plugin@marketplace`, and refresh with `/plugin marketplace update`. Hosting is recommended on GitHub or another git host, with private-repo auto-updates supported through tokens such as `GITHUB_TOKEN`/`GH_TOKEN`, `GITLAB_TOKEN`/`GL_TOKEN`, or `BITBUCKET_TOKEN`. Admins can restrict allowed sources via `strictKnownMarketplaces` in managed settings, and release channels can be created by pointing separate marketplaces at different refs/SHAs. The guide also covers schema fields (`name`, `owner`, `plugins`, `source`, `strict`, `category`, `tags`), validation with `claude plugin validate`, a 120-second git timeout adjustable via `CLAUDE_CODE_PLUGIN_GIT_TIMEOUT_MS`, and caveats for URL-based marketplaces and plugin caching.

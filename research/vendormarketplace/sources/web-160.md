OpenAI’s Codex docs now describe plugins as installable workflow bundles that package skills, optional app integrations, and MCP server config, encountered in the Codex app directory and the CLI `/plugins` surface. Local plugins require `.codex-plugin/plugin.json` and can be exposed through a repo marketplace at `$REPO_ROOT/.agents/plugins/marketplace.json` or a personal marketplace at `~/.agents/plugins/marketplace.json`; installed plugins are cached under `~/.codex/plugins/cache/$MARKETPLACE_NAME/$PLUGIN_NAME/$VERSION/`, with enabled/disabled state in `~/.codex/config.toml`, and the built-in `@plugin-creator` can scaffold them. The docs advise starting with a local skill, then packaging it as a plugin once reuse across repos or teams matters. Public publishing to the official Plugin Directory is marked “coming soon,” while local/private plugin paths are already documented.

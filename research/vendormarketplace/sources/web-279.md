DVKolm/claude-plugin-manager is an MIT-licensed visual web UI for managing Claude Code plugins, built with a 7-module TypeScript/Node.js backend and vanilla HTML/CSS/JS frontend using DM Sans/DM Mono. It browses 34+ installed plugins with skills/agents/commands/hooks/MCP servers/modes/CLAUDE.md previews, toggles enable/disable (applied next Claude Code session), supports search/filter by name, description, skill, source (Official/Community), and status, and browses 43+ official marketplace plugins, with SSE live updates and keyboard shortcuts. It runs as a standalone Edge/Chrome app window with an Anthropic-styled card UI and dark mode; security includes 127.0.0.1-only binding, one-time token + HttpOnly cookie auth, Host header validation, CSRF/XSS defenses, strict plugin-ID regex, atomic writes with backups, and async mutex. It is a skill-only plugin with no always-on MCP server, an on-demand HTTP server that auto-exits after 30 minutes idle, zero runtime dependencies beyond Node built-ins, and installs via `/plugin install plugin-manager` (after approval) or manual clone/npm install/npm run build plus `claude --plugin-dir ./claude-plugin-manager`.

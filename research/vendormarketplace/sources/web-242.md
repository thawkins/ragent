The Codex Plugin for Claude Code is an OpenAI-published, Apache-2.0 plugin (github.com/openai), announced March 30, 2026, that lets Claude Code request OpenAI Codex reviews or delegate tasks via seven slash commands: `/codex:review`, `/codex:adversarial-review`, `/codex:rescue`, `/codex:status`, `/codex:result`, `/codex:cancel`, and `/codex:setup`. It includes a `codex:codex-rescue` subagent, background job tracking, an optional Stop-hook review gate, and `--base` branch-scoped reviews, delegating through the local Codex CLI/app server and reusing local auth, config, environment, and MCP setup. Installation requires Node.js 18.18+, a local Codex CLI, and a ChatGPT subscription (Free tier included) or OpenAI API key, via `/plugin marketplace add openai/codex-plugin-cc`, `/plugin install codex@openai-codex`, `/reload-plugins`, and `/codex:setup`; it is not Anthropic-published or listed on claude.com/plugins, splits token/billing across Anthropic and OpenAI, and has had daily-ish updates since launch.

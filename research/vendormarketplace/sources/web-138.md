```text
Claude Code plugins are packaged, reusable workflow extensions that bundle skills, agents, hooks, MCP servers, a `plugin.json` manifest, and namespaced commands such as `/plugin-name:skill`; they can be browsed via `/plugin` → Discover and found through official, community, or local marketplaces, then installed with `/plugin install <name>@<marketplace>`, scoped as User, Project (shared via repo `.claude/settings.json`), or Local, and reloaded with `/reload-plugins`. Recommended first categories include code intelligence (often LSP-based and requiring local binaries), source control (GitHub/GitLab), project management (Linear/Jira/Notion/Asana), deployment/infrastructure (Vercel/Firebase/Supabase), and communication/monitoring (Slack/Sentry). For personal or one-off setups, a standalone `.claude/` config is usually enough; use a plugin for repeated/shared workflows, and reserve custom plugins for specialized internal needs, starting with only one or two plugins. Before installing, the guide advises checking trustworthy sources, public repos/docs, external dependencies, recent maintenance, and actual need; common fixes include running `/reload-plugins`, updating Claude Code, verifying scope/path, and installing missing executables.
```

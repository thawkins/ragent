An Aug. 7, 2026 MGMCSA Guru Team guide explains that Claude Code plugins are installed in two stages—first add a marketplace with `/plugin marketplace add <owner/repo-or-url>`, then browse and install with `/plugin`—since there is no single app store. After installing, verify bundled slash commands, MCP servers, and subagents via the command menu, `/mcp`, and `/agents`; manage or remove plugins with `/plugin`, reviewing bundles because MCP servers cost context and hooks run commands. For teams, it recommends publishing a git-based marketplace repository with a `.claude-plugin` manifest and plugin directories such as `plugins/team-setup/` containing commands, agents, skills, and hooks, so teammates can add the repo and install one shared setup.

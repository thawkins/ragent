```text
Claude plugins are installable packages, usually git repos, that extend Claude Code and Claude Cowork by bundling skills, agents, hooks, and MCP server configs for one-step installation; they are distributed through marketplaces (any repo with `.claude-plugin/marketplace.json`) and Anthropic’s curated Plugin Directory, and differ from skills (knowledge) and connectors (OAuth-protected MCP access). Install via `/plugin marketplace add sitegpt/agent-skills` then `/plugin install sitegpt@sitegpt`; the official SiteGPT plugin ships only the `sitegpt-cli` skill, enabling no-signup creation/training of an AI support chatbot for any website URL with a preview-and-claim link, while the separate SiteGPT connector provides live MCP account access with OAuth and read/write separation. The page recommends judging plugins by readable vendor provenance, focused footprint, and honest authentication (OAuth or no credentials over pasted API keys).
```

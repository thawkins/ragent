OpenConnector is an open-source connector/auth gateway for AI agents—positioned as an alternative to Pipedream/Composio—that connects user app accounts once and exposes a shared catalog of 1,000+ providers and 10,000+ prebuilt Actions, including GitHub, Gmail, Notion, BigQuery, Google Analytics, Supabase, Airtable, and Slack. It supports Connector SDK, `oo` CLI, MCP, HTTP/OpenAPI, and a Web Console, with handling for API keys, OAuth2, custom and no-auth credentials plus scopes, tokens, allow/block policies, and redacted run logs. Deployment options include OOMOL hosted, self-hosted Docker/Node.js or Fly.io with SQLite, and Cloudflare Workers/D1/R2/Static Assets; the code is Apache-2.0 licensed, with a Docker image at `ghcr.io/oomol-lab/open-connector`.

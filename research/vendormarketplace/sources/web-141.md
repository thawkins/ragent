The Rundown guide explains how to install a skills marketplace in Claude Code via CLI to add reusable document, frontend-design, and project-file skills; it targets website developers, users working with PDFs/DOCX/Excel, and those wanting to avoid custom sub-agents. It requires Claude Pro or above, Claude Code installed, and optional Git; users run `/plugin marketplace add anthropics/skills`, browse `claude-plugins-official`, install `context7` and `frontend-design`, add `anthropic-agent-skills`, and install `document-skills`. After adding project context such as a Markdown file or CSV (example: current NBA stats/news), they optionally `git init`, run `claude /init` to create `Claude.md`, then ask Claude to create a PDF explaining the Markdown using the PDF doc tool and use `frontend-design` to make a landing page (example: early 2000s-style sports website). Further options include adding `alirezarezvani/claude-skills` for marketing/business operations skills and using `skills.sh` to inspect skills.

```text
Anthropic’s Claude Code is a local terminal/CLI agentic coding tool that reads and edits files, runs bash/tests/git, uses Sonnet/Opus with large context, supports real-time interaction, headless/CI use, sub-agents/agent teams, Skills/Plugins/MCP, and computer-use/Playwright automation; it starts at $20/month (Pro) or $100/month (Max), with typical task costs of $0.10–$0.60 and about 12% of extended-test tasks needing more than minor fixes. OpenAI’s 2025 Codex is a cloud-sandboxed, asynchronous ChatGPT-paid-tier agent powered by codex-1 (o3 family) that clones GitHub repos, runs tests, opens PRs, supports parallel managed queues plus a local Codex CLI, costs roughly $0.40–$2.50 per task, and has limited browser use; its sandbox reduces blast radius but raises data-residency/compliance concerns. The article concludes Claude Code fits interactive, exploratory local development while Codex fits delegated, well-defined batch/PR workflows, and both score well on SWE-bench but remain architecturally divided between local and cloud execution.
```

```text
MCP, launched Nov. 25, 2024, became the default AI-to-tool protocol—adopted within a year by Cursor, Windsurf, ChatGPT, Google Gemini, and Microsoft Copilot—and was donated by Anthropic to the Agentic AI Foundation under the Linux Foundation on Dec. 9, 2025. The article maps the stack: MCP is the foundation; connectors are pre-built MCP servers (Claude.ai integrations, Microsoft Copilot Studio connectors); plugins bundle MCP servers, skills, and commands; MCP Apps (launched Jan. 26, 2026, by Anthropic and OpenAI, supported in Claude, ChatGPT, and VS Code) return interactive UI; and A2A (Google Cloud Next, Apr. 9, 2025; v1.0 Mar. 12, 2026) is a separate AI-to-AI protocol, not an MCP replacement. It distinguishes MCP primitives—tools (executable/model-driven), resources (read-only/application-driven), and prompts (reusable templates)—and reports that the ecosystem passed 10,000 public servers by Apr. 2026, while an audit of 1,847 found 52% abandoned, 31% lightly maintained, and only 17% production-ready. It also notes that MCP tool schemas in a mid-sized stack used 66,000–67,000 tokens before a question (~one-third of Claude Sonnet’s context, per Scott Spence and an r/ClaudeAI developer, not DeployStack’s 75k formula), though Anthropic later shipped lazy loading (Jiquan Ngiam: Claude Chat, Cowork, and Code load MCP tools on demand).
```

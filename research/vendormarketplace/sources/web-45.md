MongoDB announced MongoDB Agent Skills—structured instructions, best practices, and resources agents can apply across the development lifecycle, from connection management and schema design to advanced capabilities like AI retrieval—to address common agent errors such as over-normalizing schemas, underusing compound indexes, and misusing indexes/search indexes. It is launching plugins for Claude Code, Cursor, Gemini CLI, and VS Code that bundle Agent Skills with the MongoDB MCP Server, which provides connectivity, authentication, and configurable permissions/governance. The post cites Stack Overflow Developer Survey 2025 data showing 84% of respondents use or plan to use AI tools, up from 76% the prior year; Agent Skills follow Anthropic’s open standard, and installation is available via Claude Code’s `/plugin install mongodb`, Vercel Skills CLI `npx skills add mongodb/agent-skills` (Node.js required), or `npx mongodb-mcp-server@latest setup`.

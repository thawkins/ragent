AnkiMCP says users can connect Anki to Claude in about 5 minutes via three paths: Claude Web using the add-on’s built-in tunnel (tied to the Claude account, reaching web, mobile in beta, and Claude Code), a free local-only Claude Desktop bundle, or Claude Code CLI. The add-on needs one command and no Node.js or AnkiConnect because it talks directly to Anki; the CLI path is for those without the add-on or already using AnkiConnect, and only it requires Node.js. For every path, Anki must be open and the computer on or Claude sees no cards; the add-on and Desktop bundle are free, while the Web tunnel has free and paid tiers. Troubleshooting includes checking AnkiConnect at http://localhost:8765, reinstalling AnkiConnect code 2055492159 if needed, or using Tools → AnkiMCP Server Settings for the add-on.

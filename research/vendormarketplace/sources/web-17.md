```text
Claude Code plugins extend Claude Code with shareable custom functionality, installable from marketplaces, adding commands, agents, hooks, Agent Skills, and MCP servers. The quickstart creates a `test-marketplace` containing `my-first-plugin` with `.claude-plugin/plugin.json` and `commands/hello.md`, plus `.claude-plugin/marketplace.json`; installation uses `/plugin marketplace add ./test-marketplace` and `/plugin install my-first-plugin@test-marketplace`, followed by restarting Claude Code. Plugins are managed with `/plugin` commands (install, enable, disable, uninstall) and verified via `/help`; team workflows configure plugins in `.claude/settings.json` so trusting the repository auto-installs them. Developers can add model-invoked Skills via `skills/*/SKILL.md`, test locally with a `dev-marketplace` and reinstall cycle, and distribute by adding a README, semantic versioning, and a marketplace.
```

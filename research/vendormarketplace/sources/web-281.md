On May 4, 2026, Prismatic announced Prismatic Skills for Claude Code, a free, open-source plugin available on GitHub for all Prismatic customers regardless of plan tier, which gives Claude Code specialized knowledge of Prismatic’s embedded integration platform so developers can build, deploy, and operate integrations directly in Claude Code. It works with the Prism MCP dev server and TypeScript code-native integrations, and includes purpose-built skills: CNI Builder, Component Builder, Embed Advisor, Orby for monitoring/operations, and Migration Analyzer. Prismatic CTO Tanner Burson said AI coding assistants can generate integration code but don’t understand how integrations operate in production; the plugin aims to provide that context end-to-end without leaving the development environment.

Claude Code plugins extend it with skills, agents, hooks, and MCP servers, discovered and installed through marketplaces; the official Anthropic marketplace (`claude-plugins-official`) is auto-available and installs via `/plugin install plugin-name@claude-plugins-official`. Official plugins cover LSP code intelligence for languages including C/C++, C#, Go, Java, Kotlin, Lua, PHP, Python, Rust, Swift, and TypeScript (requiring matching language-server binaries), external integrations (GitHub, GitLab, Atlassian, Asana, Linear, Notion, Figma, Vercel, Firebase, Supabase, Slack, Sentry), development workflows (`commit-commands`, `pr-review-toolkit`, `agent-sdk-dev`, `plugin-dev`), and output styles (`explanatory`, `learning`). Marketplaces can be added from GitHub `owner/repo`, Git URLs, local paths, or remote `marketplace.json` URLs; installs default to user scope, with project/local/managed scopes, managed via `/plugin` tabs and commands such as `/reload-plugins`, disable/enable/uninstall, and marketplace list/update/remove. Anthropic also maintains a manually added demo marketplace (`claude-code-plugins`); auto-update defaults on for official marketplaces and off for third-party/local, teams can configure `extraKnownMarketplaces` in `.claude/settings.json`, plugins require version 1.0.33+, and plugins/marketplaces are highly trusted components that can execute arbitrary code.

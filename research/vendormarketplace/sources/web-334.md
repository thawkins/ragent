OpenAI released Codex CLI 0.146.0 on July 29, 2026, adding Agent Plugins manifest support (root plugin.json using Agent Plugins 1.0 schema), workspace plugin publishing capability, and broader marketplace compatibility, while preserving legacy .codex-plugin/plugin.json as a fallback overlay and rejecting unsupported schema versions. The guide recommends keeping a working skill as a skill until sharing/install/server-backed tools justify a plugin, choosing one manifest authority, limiting skill discovery to direct child folders inside the plugin root, and testing via a local marketplace in a fresh Codex session. Workspace publication should occur only when app-server metadata explicitly reports canPublishToWorkspace; null/missing/error metadata must fail closed, and package availability does not grant connector access, external identity, write actions, MCP authentication, hooks, or runtime/sandbox permission, which must be verified separately along with rollback. It lists eight rollout gates and a plugin_rollout record, and warns against turning every skill into a plugin, maintaining competing manifests, testing in the installation session, treating workspace visibility as publish permission, equating installation with authorization, and shipping hooks without side-effect review.

The GitHub repo `anthropics/claude-plugins-public` is a curated directory of Claude Code plugins, organized into `/plugins` for Anthropic-maintained internal plugins and `/external_plugins` for third-party partner/community plugins, installable via `/plugin install {plugin-name}@claude-plugins-official` or `/plugin > Discover`. Anthropic warns that it does not control or verify the MCP servers, files, or other software included in plugins and cannot guarantee they will work as intended or won’t change; external plugins must meet quality and security standards and be submitted through a form. Plugins follow a standard structure with a required `.claude-plugin/plugin.json` plus optional `.mcp.json`, `commands/`, `agents/`, `skills/`, and `README.md`, and plugin names are immutable slugs (use `displayName` for UI labels or a top-level `renames` map in `.claude-plugin/marketplace.json` to auto-migrate). If a source repository ships `SKILL.md` files without a plugin manifest, a marketplace entry can declare them with `strict: false` and explicit `skills` paths, registering each as `<plugin-name>:<skill-name>`.

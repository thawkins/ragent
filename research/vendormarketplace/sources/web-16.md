```text
XMTP hosts an official Claude Code plugin marketplace, `xmtp/claude-plugins`, that catalogs Claude Code plugins for distribution; plugins are installed per-user and auto-update when the marketplace is refreshed. Users add it with `/plugin marketplace add xmtp/claude-plugins` and install plugins such as `/plugin install xmtp-docs-mcp@xmtp-plugins`. The listed plugins are `xmtp-docs-mcp`, an MCP server exposing XMTP documentation as searchable tools from `xmtp/xmtp-docs-mcp`, and `xmtp-cli`, a skill for XMTP messaging via the `xmtp` CLI tool (Local). Plugins can bundle skills, MCP servers, hooks, agents, commands, and LSP servers; contributors add them via `.claude-plugin/marketplace.json` either by referencing an external GitHub repo with `strict: false` or by placing code under `plugins/` with a `.claude-plugin/plugin.json` manifest and relative-path source.
```

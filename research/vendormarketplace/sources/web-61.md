pi-claude-marketplace is a Pi Coding Agent extension (v0.19.2, published Sep 25, 2026; author acolomba; MIT; 2.6 MB; 2,655 downloads/mo and 906/wk; 3 dependencies plus 4 peers) that installs and manages plugins from Claude plugin marketplaces, supporting Claude commands, skills, agents, hooks, and MCP servers through the `/claude:plugin` command. It uses declarative configuration in `~/.pi/agent/claude-plugins.json` (user scope) or `<cwd>/.pi/claude-plugins.json` (project scope), with `.local.json` overrides, and can bootstrap the official `anthropics/claude-plugins-official` marketplace. It also handles name mapping, generated pi-subagents agent files, `--partial` installs for unsupported components, remote plugin fetching, and Claude Code settings import; `/reload` applies changes.

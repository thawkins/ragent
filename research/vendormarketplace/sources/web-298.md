The Claude Beta API docs list organization plugin marketplace endpoints: GET /v1/organizations/plugin_marketplaces returns marketplaces where plugins live, newest first, including the organization’s own and members’ personal ones; GET .../{marketplace_id} retrieves one by ID; POST .../{marketplace_id} sets a default installation setting for an organization-owned marketplace, applying to every plugin without its own setting, including plugins added later. Two validation endpoints, POST /v1/organizations/plugin_marketplaces/validate_repository and /validate_archive, check whether a public GitHub-hosted marketplace or an uploaded .zip of the marketplace directory would synchronize into claude.ai, without connecting or storing it. Validation returns a non-stored BetaPluginMarketplaceValidationReport (type "plugin_marketplace_validation_report", with commit_sha, manifest_error, and 6 more fields), while plugin errors/warnings carry stable error_code identifiers and plugin names as declared in marketplace.json. The BetaPluginMarketplace object has type "plugin_marketplace", id, created_at, and 7 more fields.

As of June 2026, OpenAI’s Codex runs natively on Windows: the CLI reached v0.136.0 on June 1 and installs via `npm install -g @openai/codex` (Node 22+) or a PowerShell one-liner, while the separate Microsoft Store/winget desktop app adds worktrees, in-app Git/browser, artifact previews, plugins, skills, parallel agent threads, and computer use for Windows desktop apps (late-May build 26.527, broader rollout June 2; unavailable in EEA/UK/Switzerland and desktop-only). OpenAI now recommends native PowerShell by default, WSL2 for Linux-native toolchains (WSL1 unsupported since 0.115), and sandbox modes elevated—admin-required, alpha provisioning via `codex sandbox setup --elevated`—or unelevated fallback; known bugs include apply_patch failures (WindowsApps access denied, sandbox refusals, argv-transported large patches, mapped/UNC worktrees) and elevated-sandbox in-app browser/Chrome plugin failures, with workarounds including local drives, unelevated mode, and version pinning. Codex skills also use the open Agent Skills standard shared with Claude Code, Cursor, and Gemini CLI.

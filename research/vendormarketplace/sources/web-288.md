Plum (github.com/itsdevcoffee/plum) is a fast, fuzzy-search TUI for discovering and installing Claude Code marketplace plugins from 11 popular marketplaces—600+ plugins, including from uninstalled marketplaces—installable via Homebrew, prebuilt binaries for Windows/Linux/macOS, or `go install` (Go 1.24+).

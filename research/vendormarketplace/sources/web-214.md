```text
Claude connectors are secure, authenticated links letting Claude read from—and, where permitted, act in—business tools like CRM, email, file stores, and accounting systems, set up in about two minutes via the + button and Connectors menu, with Claude inheriting the user's existing permissions rather than a master key. Read and write access are separate permissions, available on all plans including Free and Pro, while Team and Enterprise admins can centrally enable connectors and enforce read-only. They are built on MCP (Model Context Protocol), an open standard Anthropic published that is compared to USB-C, now supporting hundreds of connectors (including niche tools) rather than handfuls. The article recommends connecting one tool first, starting read-only, keeping a human between AI drafts and sends, addressing data-protection terms, and rolling out company-wide via four decisions: an approved tool list, read-only default with per-role write access, one named owner, and usage visibility. Author: Poyan Karimi, last updated September 2026.
```

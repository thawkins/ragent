```text
On March 27, OpenAI launched a Codex plugin marketplace with more than 20 integrations from partners including Slack, Figma, Notion, and Sentry, working across Codex’s desktop app, CLI, and VS Code extension. Plugins bundle skills, app connectors, and MCP servers, while enterprise admins can govern them via JSON policy files with states `INSTALLED_BY_DEFAULT`, `AVAILABLE`, or `NOT_AVAILABLE`, plus install-vs-first-use authentication controls. Codex has reached 1.6 million weekly active users—more than tripling after February’s GPT-5.3 Codex launch—and weekly token usage grew fivefold; enterprise users include Cisco, Nvidia, Ramp, Rakuten, and Harvey. OpenAI is the last major AI coding vendor to ship plugins, trailing Anthropic’s Claude Code and Google’s Gemini CLI in integration count, and Codex starts at $200/month versus Claude Code Max at $100/month. Distribution runs through OpenAI’s curated Plugin Directory, repo-scoped marketplaces, and personal marketplaces, though third-party directory submissions and self-serve publishing are listed as coming soon.
```

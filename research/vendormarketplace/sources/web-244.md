Claude Code MCP Server Selector is an npm package (`@henkisdabro/mcp-selector`, run as `mcp` or `claudemcp`, Node.js 20+) by Henrik Söderlund that manages MCP servers to reduce Claude Code context-window bloat: each tool consumes ~600–800 tokens, average servers with 20–30 tools use ~15,000–25,000 tokens, large servers (e.g., google_workspace, alphavantage, mikrotik) with 60–100+ tools use 50,000–85,000 tokens each, and 10 enabled servers can consume 200,000–250,000 tokens (100–125% of a 200k budget). It provides a React Ink TUI with a three-way toggle (RED off, GREEN on, ORANGE runtime-disabled), merges 12+ config sources, discovers/installs marketplace plugins, supports CLI subcommands and integration commands, and includes enterprise allowlist/denylist/command/URL policies via `managed-mcp.json`/`managed-settings.json`. v2.5.0 adds plugin marketplace integration, install/uninstall commands, available-plugin discovery, and compact status-bar support; v2.0 added CLI subcommands and plugin management. It also offers migration, backups, file locking, cross-platform support, and is MIT licensed.

There is no official Claude Code plugin marketplace; the ecosystem is decentralized across GitHub repos, curated lists, and community directories. Key directories include awesome-claude-code (github.com/hesreallyhim/awesome-claude-code; 40K+ stars; awesomeclaude.ai), claude-code-templates (github.com/davila7/claude-code-templates; 25K+ stars; aitmpl.com; 600+ agents, 200+ commands, 55+ MCPs, 60+ settings, 39+ hooks; install via `npx claude-code-templates@latest`), awesome-claude-code-toolkit (1.4K stars; 135 agents, 35 skills, 42 commands, 176+ plugins), and awesome-mcp-servers (85K+ stars; 200+ servers across 30+ categories). Plugins are distributed as CLAUDE.md files, Skills, Hooks in `.claude/settings.json`, MCP servers, and Agent templates, and can be installed via CLAUDE.md drop-in, CLI tools (`pipx install superclaude`; `npx claude-code-templates@latest`), manual `.claude/settings.json` configuration, or npm global install. The guide advises security/quality/compatibility checks before installing, notes plugins can conflict, recommends keeping combined CLAUDE.md instructions under 2,000 words because they consume context, says hooks add latency but not tokens, and states the ecosystem is currently open source/free with no universal uninstall command.

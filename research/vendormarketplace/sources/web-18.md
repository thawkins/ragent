The GitHub repository **eduardoarantes/claude-code-plugin-marketplace** (by Eduardo Rodrigues) is a Claude Code plugin marketplace focused on production-ready Python development, containing the plugins **python-coding-agents** and **voice-notification**. It can be added with `/plugin marketplace add /path/to/marketplace` or `owner/repo`, pointing to the marketplace directory rather than `marketplace.json`; plugins can be installed globally in `~/.claude/settings.json` or project-level via `.claude/settings.json`, with `.claude/settings.local.json` for machine-specific overrides. **python-coding-agents** (`/plugin install python-coding-agents@code-plugin-marketplace`) supports task implementation/review, code complexity analysis, test-driven development, architecture planning, and Python expert code review. **voice-notification** (`/plugin install voice-notification@code-plugin-marketplace`) provides TTS notifications when Claude needs input, auto-detects ElevenLabs, OpenAI, or pyttsx3, supports optional `ELEVENLABS_API_KEY`, `OPENAI_API_KEY`, and `ENGINEER_NAME`, uses personalized names 30% of the time, and falls back to offline pyttsx3 without API keys.

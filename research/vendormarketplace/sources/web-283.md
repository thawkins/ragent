The npm package `claude-code-marketplace` is an MIT-licensed local web dashboard for browsing, installing, and managing Claude Code plugins across marketplaces. It requires Node.js 18+ and Claude Code on the PATH, runs plugin operations through the `claude plugin` CLI, serves on `http://localhost:3542` with fallback to a free port, and reads the registry in `~/.claude/plugins/`. Features include a unified tree for GitHub repos, git URLs, and local folders; user/project/local scope management; search; update alerts; component/file previews; marketplace management; usage heatmap; shareable views; editor opening; 17 light/dark themes; keyboard-first navigation; and PWA support. Configuration covers port, config dir, project, open, host, and allowed hosts; the server has no authentication and binds to loopback by default.

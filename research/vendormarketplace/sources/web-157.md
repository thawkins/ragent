OpenAI introduced Plugins in Codex via its March 26 Business release notes as a curated directory for packaged workflows, with official docs saying plugins bundle skills, app integrations, and MCP servers into reusable Codex workflows. In the Codex app users browse Plugins and in the CLI use `/plugins`; installed plugins or bundled skills can be invoked with `@`, while approval settings and connected-service auth/privacy policies still apply. The build docs define a marketplace as a JSON catalog of plugins and specify a `.codex-plugin/plugin.json` manifest that can reference bundled skills, `.app.json`, `.mcp.json`, and install-surface metadata such as displayName, descriptions, developer, category, capabilities, website, privacy policy, terms, starter prompts, icons, logos, and screenshots. OpenAI cites examples including Gmail, Google Drive, and Slack, and says public official-directory publishing and self-serve plugin publishing are “coming soon,” positioning Codex plugins as a distribution system for agent workflows.

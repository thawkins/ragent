No first-party Google Meet connector exists in Anthropic's Connectors Directory; Claude can reach Meet only via a custom or third-party MCP server added as a custom connector, which requires a paid Claude plan plus self-managed Google API credentials and OAuth (a partial workaround is Claude's Google Drive connector reading saved Meet transcripts, but only inside a chat when asked). Because Claude connectors have no event triggers, scheduled tasks fire on a clock or user prompt, never when a meeting ends, making the integration "a transcript reader you query" rather than an agent that runs meetings. The page promotes Carly as the alternative — an AI executive assistant that fires on events 24/7 in the cloud, records meetings, turns them into notes/tasks/follow-ups, sends Gmail and Outlook email, updates a CRM, and connects to 200+ tools across 40+ categories, with AI agents starting at $35/month and non-AI workflow steps free.

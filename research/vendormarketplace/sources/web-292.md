```text
On Windows Codex Desktop, reinstalling the Chrome extension caused bundled plugins—Browser/in-app browser, Chrome extension integration, and Computer Use—to become unavailable; Computer Use logged `missing-helper-path` and native pipe startup failures, while Browser calls failed with `browserBackend.callTool: Target page, context or browser has been closed`. The bundled plugin marketplace rebuild failed with `EBUSY` on `rmdir` of `%USERPROFILE%\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\chrome\extension-host\windows\x64`, leaving the temporary marketplace incomplete even though the Computer Use helper executable still existed in the plugin cache. The issue recovered after fully exiting Codex and Chrome, ensuring no `extension-host.exe` process was running, restarting Codex, and waiting for the bundled plugin runtime to rebuild; the report says Chrome extension reinstall should not break unrelated bundled plugins or discard the previous working state.
```

OpenAI shipped Codex CLI v0.117.0 on March 27, 2026 with a built-in plugin marketplace for its 1.6M weekly active users, offering five curated plugins—Slack, Notion, Figma, Gmail, and Google Drive—that bundle skills, app integrations, and MCP server configs; third-party publishing is “coming soon.” For enterprises, JSON policy files control plugins via INSTALLED_BY_DEFAULT, AVAILABLE, or NOT_AVAILABLE states and ON_INSTALL/ON_FIRST_USE auth, resolved through official, repo-scoped ($REPO_ROOT/.agents/plugins/marketplace.json), and user-level (~/.agents/plugins/marketplace.json) catalogs; Forrester analyst Charlie Dai said this aligns AI agents with existing IT governance models. The system requires CLI v0.117.0+ and works in desktop, CLI, and IDE extensions but not ChatGPT web or API cloud features, and token usage is up 5x since GPT-5.3-Codex launched. Gaps include only five apps, no self-serve third-party publishing, a limited security boundary for local marketplace.json, and no disclosed revenue-sharing model.

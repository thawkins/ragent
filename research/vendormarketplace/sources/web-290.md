OpenAI’s Codex Chrome extension, launched 7 May 2026 as “Codex for Chrome,” is a bridge that lets Codex use a browser with the user’s signed-in state rather than a chat sidebar; its Web Store listing now reads “ChatGPT” (published by OpenAI, 4M users, updated 5 Sept. 2026) and is the same extension after Codex merged into the ChatGPT desktop app on 9 July 2026. It requires the ChatGPT desktop app, supports Chrome, Edge, Brave, Opera, and Vivaldi (side chat in all but Opera) on macOS/Windows, is limited on Free with regional limits, and is often unavailable due to gradual rollout/account/region eligibility, EU/UK rollout lag, and stale plugin-cache issues. It can test web apps, gather multi-tab context, use DevTools, fill forms, and review dashboards, but localhost uses the built-in browser, file uploads need “Allow access to file URLs,” history access is scoped per request, and prompt-injection risk is governed by new-site confirmations, allowlists/blocklists, and an elevated-risk “allow for all sites” setting.

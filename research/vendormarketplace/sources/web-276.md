claude-scout is a local web UI for browsing Claude Code plugin marketplaces, with tabs for Official (Anthropic, MCP, LSP), Installed, Added, Discovered, Tools, and Unmonitored; Discovered plugins are auto-crawled from GitHub Code Search and updated twice weekly, tiered by stars as Established (≥25 ★), Founding (5–24 ★), and New & Unverified (<5 ★). It reads live from `~/.claude/plugins/`, supports sorting by install count or name, shows popularity bars with install numbers, and enables one-click copying of `/plugin install` commands. Install via `/plugin marketplace add devycelabs/claude-scout` and `/plugin install claude-scout`, then run `node server/index.js` (Node.js 18+, no npm install/build, default `http://localhost:3747`); `server/index.js` serves as both an MCP stdio server and HTTP server, with `plugin-browser`/`plugin-browser-setup` skills and a SessionStart `setup-check` hook, plus a hosted version at `devycelabs.github.io/claude-scout`.

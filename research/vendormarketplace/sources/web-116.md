OpenAI’s `codex-plugin-cc` is a Claude Code plugin for using Codex on code reviews (`/codex:review`, `/codex:adversarial-review`) and for delegating, transferring, and managing background jobs via `/codex:rescue`, `/codex:transfer`, `/codex:status`, `/codex:result`, and `/codex:cancel`. It requires Node.js 18.18+ and either a ChatGPT subscription (including Free) or an OpenAI API key, with usage counting toward Codex limits, and is installed through Claude Code’s marketplace/plugin commands. The plugin wraps the local Codex CLI/app server, reuses existing Codex authentication and configuration (including `~/.codex/config.toml`, project `.codex/config.toml`, and `openai_base_url`), provides `/codex:setup` to check/install Codex, and optionally enables a Stop-hook review gate that can create long Claude/Codex loops and drain usage limits.

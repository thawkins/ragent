The guide estimates a first Claude Code plugin takes about four hours, mostly design, and explains individual publishing via the GitHub-based Claude Code Plugin Marketplace, distinct from the Claude Enterprise Marketplace (launched 6 March 2026 for integrations from Snowflake, GitLab, and Replit, requiring an Anthropic partnership). It also notes plugins install via `/plugin install <repo-url>`, can be distributed immediately from GitHub, and can be privately curated via a `.claude-plugin/marketplace.json`.

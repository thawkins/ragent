On a 100-point rubric, Claude Code and Kendr Code tie at 88 (Kendr revised from 79 after its 14 August release), followed by Codex at 82 and OpenCode at 79; only Kendr was re-scored, so the tie reflects Kendr closing its own gaps rather than a measured overtake. All four now converge on a flat tool-calling loop, repository-root instruction files, MCP, subagents/delegated contexts, read-only/plan modes, and headless invocation, so differentiation lies in isolation, permissions/durability, model freedom, and off-machine execution. Codex leads on kernel-level sandboxing (Seatbelt on macOS, Landlock plus seccomp on Linux, native Windows sandbox, network off by default); OpenCode leads on model freedom (75-plus providers) and client-server/LSP design; Claude Code leads on surface reach (terminal, IDE, desktop, web, mobile, cloud Routines, Agent SDK) but is Anthropic-first; Kendr Code leads on transactional edits, durable approvals, crash recovery, and a replayable ledger, but trails on model transport (70-plus models across six vendors, described as “degraded” for non-native routes using a constrained JSON protocol) and lacks off-machine execution. The article cautions these are not task-success rates and should be re-checked against current releases for sandboxing, provider streaming, kill survival, and laptop-closed execution.

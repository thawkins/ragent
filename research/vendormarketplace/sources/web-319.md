The beta organization Plugin version API provides endpoints to manage organization-owned Plugin versions: `POST /v1/organizations/plugins/{plugin_id}/versions` uploads a new version’s files, which becomes the version served to members unless the served version is pinned; `GET` on the same path lists versions newest first; `GET .../versions/{version}` retrieves a version by ID or the newest version; and `GET .../versions/{version}/content` downloads the stored `.zip` archive. Each download of a Plugin from a member’s personal plugin marketplace is recorded on the Compliance API activity feed. The `BetaPluginVersion` model includes `type: "plugin_version"`, `id`, `components`, and 9 more fields.

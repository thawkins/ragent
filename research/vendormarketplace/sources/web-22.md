The article explains that “Claude marketplace” generally refers to the Claude Code plugin marketplace, where a marketplace is a catalog of installable plugins and MCP remains the runtime transport for tools. Plugins can bundle skills, agents, hooks, MCP servers, and LSP servers; the official Anthropic marketplace is available by default via `/plugin` (Discover tab) and at claude.com/plugins, while custom marketplaces can be added with `/plugin marketplace add <source>` from GitHub repos, git URLs, hosted `marketplace.json` files, or local paths. The marketplace handles distribution, governance, reuse, and safety rather than execution, and Novita AI positions itself as a safer execution layer for plugin-driven MCP/code/browser automation and as an open-weight model option, including Novita Agent Sandbox for risky tool execution.

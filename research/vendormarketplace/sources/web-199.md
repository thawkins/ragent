```text
Claude Code plugins, per this 2026-06-14 guide, are self-contained, versioned directories that bundle skills, subagents, hooks, MCP servers, LSP servers, monitors, output styles, themes, commands, executables, and default settings for team distribution; they package existing capabilities rather than adding new ones, with skills namespaced (e.g. /release-tools:changelog). A plugin uses an optional manifest at .claude-plugin/plugin.json (only "name" required; "version" drives update detection, otherwise git commit SHA is used) and is discovered via a marketplace.json catalog supporting relative-path, github, url, git-subdir, and npm sources, with official Anthropic marketplaces claude-plugins-official and community-reviewed claude-community. Install scopes are user, project, local, and managed settings, with governance via strictKnownMarketplaces, rollout through repository .claude/settings.json keys extraKnownMarketplaces and enabledPlugins, and container/CI pre-seeding via CLAUDE_CODE_PLUGIN_SEED_DIR; path variables ${CLAUDE_PLUGIN_ROOT}, ${CLAUDE_PLUGIN_DATA}, and ${CLAUDE_PROJECT_DIR} resolve installed locations, and claude plugin validate (with --strict in CI) checks manifests.
```

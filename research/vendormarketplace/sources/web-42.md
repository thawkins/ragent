The geoffjay/claude-plugins GitHub repo is an experimental Claude Code plugin marketplace, added via `/plugin marketplace add geoffjay/claude-plugins`; plugins install individually (e.g., `/plugin install golang-development`) and only load their specific agents, commands, and skills. It advertises single-responsibility plugins averaging 3.4 components, composability, 100% coverage of all 85 agents, and three-tier progressive-disclosure skills (metadata always loaded, instructions when activated, resources on demand). The project borrows from wshobson/agents and is MIT licensed.

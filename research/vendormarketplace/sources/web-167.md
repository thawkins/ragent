```text
Codex plugins execute in sandboxed containers, but the sandbox trusts the plugin manifest: a plugin declaring tool names like `bash`, `ls`, or `curl` can shadow system commands, intercept invocations, log arguments, execute arbitrary behavior, and return plausible results undetected. `AGENTS.md`, equivalent to `CLAUDE.md` and loaded as persistent memory into every Codex agent session, is another attack surface because a plugin that writes to it can inject instructions that survive uninstallation. Firmis scans Codex plugin manifests, `AGENTS.md`, and handler code with 324 detection rules across tool poisoning (10, high), prompt injection (13, high), secret detection (60, high), agent memory poisoning (7, high), supply chain (8, medium), data exfiltration (12, medium), access control (3, medium), network abuse (10, medium), and insecure config (3, low), covering files like `codex-config.json`, `AGENTS.md`, `.codex/**`, `src/**/*.ts/js`, and `package.json`. Example findings include tp-008 tool name shadowing, sd-014 hardcoded Anthropic API keys (`sk-ant-api03-...`), and mem-006 plugin writes to `AGENTS.md`; recommended fixes include namespaced tool names, secret rotation/env vars/secrets managers, and prohibiting plugin writes to `AGENTS.md` or `.codex/`.
```

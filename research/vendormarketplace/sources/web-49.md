ClaudePluginHub describes marketplaces as curated, GitHub-hosted collections of Claude Code plugins grouped by workflow or use case; it regularly re-indexes these repos to reflect curators’ latest selections, and installing one marketplace grants all its plugins. It also offers a “Safe feed” of the most-starred plugins that run no code of their own—excluding hooks, MCP servers, LSP servers, monitors, workflows, executables, and status-line commands—installed via `/plugin marketplace add https://www.claudepluginhub.com/marketplaces/safe.json`.

Claude Plugins (claude-plugins.dev) is an open-source, community-maintained directory and CLI for discovering and installing Claude Code plugins, including ones with Agent Skills; it automates marketplace and plugin installation in one command via `npx claude-plugins install <identifier>` plus `enable`/`disable`, and requires Claude Code v2.0.12+. The catalog includes Anthropic and community plugins such as `frontend-design`, `document-skills` (Excel, Word, PowerPoint, PDF), EveryInc’s `compound-engineering` (29 specialized agents, 22 commands, 19 skills), `code-review`, `feature-dev`, `pr-review-toolkit`, `security-guidance`, `commit-commands`, `python-development`, `backend-development`, `javascript-typescript`, `database-design`, `code-refactoring`, `code-documentation`, `context-management`, `typescript-lsp`, `ui-designer`, and `frontend-excellence`. It also lists Context7, a hosted remote MCP server at `https://mcp.context7.com/mcp` for version-specific documentation lookup that works anonymously without local Node.js/npx, with `CONTEXT7_API_KEY` for higher rate limits.

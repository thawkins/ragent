This commit to OpenAI's Codex repository adds a "marketplace upgrade" feature to the TUI: it introduces `MarketplaceUpgradeParams`/`MarketplaceUpgradeResponse` protocol types, new `AppEvent` variants (`OpenMarketplaceUpgradeLoading`, `FetchMarketplaceUpgrade`, `MarketplaceUpgradeLoaded`), and `fetch_marketplace_upgrade` helpers that send a typed `ClientRequest::MarketplaceUpgrade` with a UUID-based request ID (`marketplace-upgrade-{uuid}`) and an optional `marketplace_name`. When the upgrade result has a non-empty `upgraded_roots`, the app refreshes in-memory config from disk (logging "failed to refresh config after marketplace upgrade"), refreshes plugin mentions, submits `AppCommand::reload_user_config`, and re-fetches the plugins list if the current working directory matches. The diff also excludes `Ctrl+U` from the bottom-pane ctrl-c key handling and makes `set_plugin_mentions` skip updating when plugins are unchanged.

Claude Market (github.com/claude-market/marketplace) is a hand-curated, open-source GitHub plugin marketplace for Claude Code, offering community-built tools, agents, skills, and MCP servers; users can add it with `/plugin marketplace add claude-market/marketplace`. Its Plugin Builder (`/plugin install plugin-builder`) interactively creates plugins with commands, agents, hooks, skills, and MCP servers. Submissions must include `.claude-plugin/plugin.json`, `CODEOWNERS`, `README.md`, `LICENSE`, and at least one component, and can generate a `marketplace.json` entry via `make generate-marketplace-json`; maintainers review for quality, documentation, and functionality. The marketplace repository is MIT-licensed, while individual plugins use their own licenses.

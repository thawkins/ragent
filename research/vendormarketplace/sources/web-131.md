In 2026, OpenAI’s Codex and Anthropic’s Claude Co-work are competing for knowledge-worker agent workflows: Codex offers built-in image generation without external MCP, work-type onboarding (finance, product, marketing, operations, sales, data science, design, student/other), fast/reliable browser use, and GPT-5.5, while Claude Co-work splits from Claude Code and provides a consumer-friendly interface plus connectors for Blender, Adobe, Autodesk, Ableton, Spotify, Instacart, and Booking.com. The Endor Labs benchmark found GPT-5.5 scored 61.5% on functionality in Codex’s native harness versus 87.2% in Cursor’s harness—a 26-point gap—and OpenAI’s Symphony spec reportedly drove a 500% increase in landed pull requests; a browser test involving video-file analysis succeeded in Codex but failed in Co-work. The article recommends Codex for reliable browser use, in-session image generation, technical configurability, and role-specific onboarding, and Co-work for nontechnical users, creative/consumer connectors, and separated technical/nontechnical products; neither fits developers embedding agents, where the Cursor SDK is suggested. It notes the platforms are converging and advises trying both.

Claude Connectors, powered by Anthropic's open Model Context Protocol (MCP), let Claude access external tools and data—including Google Drive, Gmail, GitHub, Slack, Notion, Asana, Spotify, Uber, and 200+ others—via prebuilt first-party integrations, remote MCP servers, interactive MCP Apps, .mcpb desktop bundles, or npm/PyPI plugins. Connectors work across Claude.ai, Desktop, Mobile (beta), Code, and Cowork, are surfaced dynamically without paid placement, and preserve privacy (data not used for training; apps can't see other conversations; purchases require confirmation). Developers can build MCP servers with the MCP SDK, connect them via claude_desktop_config.json, or pass `mcp_servers` in Anthropic API calls to /v1/messages; the Connectors Directory launched July 2025 and consumer connectors (Uber, Spotify, Instacart, TripAdvisor, Resy, Audible, AllTrails) arrived April 2026 on all plans, with mobile in beta.

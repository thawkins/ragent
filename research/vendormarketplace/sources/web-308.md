The `claude-plugins-official` directory is a curated marketplace of high-quality Claude Code plugins, with internal plugins maintained by Anthropic under `/plugins` and third-party or community plugins under `/external_plugins`. Anthropic warns that it does not control or verify the MCP servers, files, or other software included in plugins and cannot guarantee they will work as intended or remain unchanged, so users should trust a plugin before installing, updating, or using it. Plugins can be installed via Claude Code’s plugin system with `/plugin install {plugin-name}@claude-plugins-official` or browsed in `/plugin > Discover`; each follows a standard structure with required `.claude-plugin/plugin.json` metadata and optional `.mcp.json`, `commands/`, `agents/`, `skills/`, plus a README, while external partners must meet quality and security standards for approval.

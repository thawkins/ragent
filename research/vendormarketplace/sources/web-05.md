According to Lenka Vojtechova’s Sept. 25, 2026 guide, “Claude Marketplace” names three distinct products: Anthropic’s enterprise procurement catalog (15 products as of Sept. 24, 2026, sold via “Request to buy”), Claude Code plugin marketplaces for the CLI, and an AWS Marketplace listing for Claude Enterprise. Claude Code automatically adds the official marketplace, claude-plugins-official, on first interactive start; as of Sept. 24, 2026 it listed 311 plugins, versus 2,282 in the community marketplace and a handful in Anthropic’s demo marketplace. Adding a marketplace (`/plugin marketplace add owner/repo`) only registers a catalog and installs nothing, while removing one uninstalls every plugin installed from it. The guide emphasizes Anthropic’s warning that plugins can execute arbitrary code with user privileges, and notes auto-update is enabled by default for official/account marketplaces but disabled for most third-party and local ones.

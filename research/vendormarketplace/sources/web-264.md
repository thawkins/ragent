The `@akeyless-community/codex-mcp` is an SDK-based MCP server that brings Akeyless Agentic Runtime Authority (ARA) to OpenAI Codex without installing the Akeyless CLI, exposing only the ARA MCP tools—`list-secrets`, `query-db`, `service-execute`, and optional `list-sub-tools`—while keeping secret values out of the model context. It is installed via `npm install -g @akeyless-community/codex-mcp`, `npx -y @akeyless-community/codex-mcp`, or the Codex plugin marketplace, and configured in `~/.codex/config.toml` with `AKEYLESS_ACCESS_ID`, `AKEYLESS_ACCESS_KEY`, `AKEYLESS_GATEWAY_URL`, and `AKEYLESS_AGENT_ID` (the gateway URL is the only required gateway setting; SDK `/api/v2` and ARA execution bases are derived automatically). It requires an Akeyless Gateway with Runtime Authority and AI Insights, ARA role rules with Allow Access, and ARA-enabled dynamic secrets; approvals default to `prompt` for `query-db`/`service-execute` and `auto` for `list-secrets`, and the project is Apache-2.0 licensed.

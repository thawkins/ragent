OpenAI Codex coding agent and its VS Code extension are in public preview, use the Codex SDK, and can be powered by an existing Copilot subscription. The coding agent is available to all paid Copilot plans and must be enabled before assigning tasks; supported models include Auto, GPT-5.3-Codex, GPT-5.4, and GPT-5.4 nano, with Auto not using Copilot auto model selection. In the VS Code extension, “Sign in with Copilot” is limited to GitHub Copilot Pro+ and Copilot Max subscribers, who can see it in VS Code Insiders’ Agent Sessions view; all usage is subject to GitHub rate limits and billing, and some models may be available only in the OpenAI Codex extension, not governed by Copilot model configuration policies.

```text
Claude Copilot is a VS Code extension that provides a unified visual management interface for Claude Code, working alongside the official Claude Code CLI. It manages plugins/marketplaces, MCP servers (user-level via CLI and project-level `.claude/settings.json`), skills (`~/.claude/skills` and `.claude/skills`), memory, settings, and usage analytics; its visual settings editor covers User/Project/Local scopes and ~50 options, including provider switching (Anthropic/Bedrock/Vertex/Foundry), auth mode switching, permissions, 15 feature flags, and 6 numeric limits. The usage dashboard parses session jsonl with Chart.js stacked bars and doughnut charts, day/week/month granularity, project and per-model filters, and cost estimates using official Anthropic pricing for Opus/Sonnet/Haiku 4.x and 3.5. It installs from the VS Code Marketplace or latest `.vsix` (`claude-copilot-0.1.16.vsix`), requires Claude Code CLI, and the MIT-licensed repo uses pnpm build/test with 35 mocha core tests and English/Chinese l10n.
```

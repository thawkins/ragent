A plugin packages skills, MCP configuration, or both, and can be loaded into your own environment or uploaded as a ZIP to an OpenAI-hosted sandbox. The example `docs-helper` plugin combines a docs-search skill with the `openai_docs` HTTP MCP server at `https://developers.openai.com/mcp`, using `.codex-plugin/plugin.json` (name `docs-helper`, version `1.0.0`), `.mcp.json`, and `skills/docs-search/SKILL.md`; manifest paths resolve from the plugin root, must start with `./`, stay inside the plugin, and contain no `..` components. For self-hosted sandboxes, copy the plugin to `/workspace/plugins/docs-helper` and add that absolute path to `environment.capability_directories` (e.g., with model `gpt-6-astra` and `workspace_directory: "/workspace"`), connect the executor before use, and allow network access to the MCP URL; list each root for multiple plugins, noting a parent directory can discover nested skills but not every child plugin’s MCP config. For OpenAI-hosted sandboxes, supply one ZIP per plugin in `environment.plugins`, with one plugin folder containing `.codex-plugin/plugin.json`, and the request’s name/description must match the manifest; OpenAI extracts and registers it automatically.

The ZenterFlow/claude-priority GitHub repository is a production-ready Claude Code plugin marketplace (version 3.0.0, updated 2025-11-03, MIT licensed) offering two Tools v1.0.0 plugins: plugin-formatter, which validates/formats plugin.json, marketplace.json, and manifest.json, lowercases file/directory names, auto-fixes author/owner string-to-object conversions, regenerates README skill lists, creates missing templates, and validates skill.md frontmatter; and claude-prioritise, which provides project status assessment, priority surfacing, backlog grooming, continuous activity logging, smart priority suggestions, GitHub integration, and persistent storage. Installation uses `/plugin marketplace add https://github.com/ZenterFlow/claude-priority`, then `/plugin install plugin-formatter@claude-priority` and `/plugin install claude-prioritise@claude-priority`, followed by enabling each plugin. The repo includes cross-platform tests for Linux, macOS, and Windows, GitHub Actions validation/installation workflows, JSON schemas, scripts, templates, documentation, and claims all plugins pass automated tests.

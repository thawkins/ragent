After seeing Claude Code users bring in Codex for code review and use GPT-5.4 for complex tasks, dkundel announced an open-source Codex plugin for Claude Code that lets users trigger Codex from Claude Code, delegate tasks, or have Codex review changes using a ChatGPT subscription; it is built on the Codex app server and uses Codex’s open-source agent harness, enabling parallel background Codex tasks with the same models and code-review functionality (install via `/plugins marketplace add openai/codex-plugin-cc` and `/plugins install codex@openai-codex`). OpenAI’s Romain Huet said Codex should be usable in the app, terminal, JetBrains, Xcode, and now Claude Code. Commenters also highlighted a fork, `byom-review`, which connects the plugin to OpenRouter for multi-model reviews, result comparison, consensus/overlap matrices, and cost tracking.

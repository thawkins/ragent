The June 26, 2026 addendum compares Codex, Claude Code, Cursor, OpenCode, and Pi, splitting the ecosystem into manifest-first (Codex, Claude Code), code-first (OpenCode), IDE-extension (Cursor), and package-based (Pi) models. Codex uses `.codex-plugin/plugin.json` with explicit component pointers, a 15-field interface object, `.app.json` connectors, and lenient validation that preserves unknown keys; Claude Code uses a leaner `.claude-plugin/plugin.json` with convention-based discovery, strict schema validation, and broader components including agents, LSP, monitors, themes, and 30+ hook events. OpenCode has no manifest and runs JS/TS plugins with 25+ events, while Pi relies on `package.json`; MCP servers are the universal portable layer, skills are near-portable, and hooks/manifests are tool-specific.

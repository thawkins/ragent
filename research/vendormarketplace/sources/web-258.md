Within-AI/within-mcp is the public plugin/extension distribution for the Within MCP server, packaging Within as an installable plugin for MCP-speaking AI assistant clients so they can query an organization’s processes, explore the Process Index knowledge graph, and ground answers in how the business actually runs rather than generic guesses. It supports install paths for Claude Code/Claude (Anthropic plugin ecosystem), ChatGPT/Codex (OpenAI app ecosystem), and Gemini CLI (Google CLI extension ecosystem), connects to https://api.within.ai/mcp, and exposes search, fetch, process-hierarchy navigation, evidence retrieval, and Context Graph traversal, with the full skill prompt at skills/within-process-context-graph/SKILL.md. Installation uses Claude commands `/plugin marketplace add Within-AI/within-mcp` and `/plugin install within@within`, Codex `codex plugin marketplace add Within-AI/within-mcp`, or `gemini extensions install https://github.com/Within-AI/within-mcp`; the first MCP tool request prompts Within sign-in, requires Within customer access with possible org approval/user addition, and offers a personal API key/Bearer-token fallback, while the repo contains generated manifests, `mcp.json` HTTP transport config, tests, and is Apache-2.0 licensed for the shim only, with the Within service governed by its commercial Terms of Service and NOTICE.

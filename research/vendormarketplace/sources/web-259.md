The GitHub repo `bidule995/dext-codex-connector` provides an independent, unofficial Codex plugin with an MCP connector for Dext Data Health & Insights; the installed beta is fixture-only, hard-codes three fictional companies and process-local memory, excludes production Dext HTTP/PostgreSQL/credential-decryption code, and cannot connect to a Dext account. It requires Node.js 24 and can be added via `codex plugin marketplace add bidule995/dext-codex-connector` and `codex plugin add dext-codex-connector@dext-codex-connector`; `connection_status` must report `providerMode: fixture` and `liveDextRequestsEnabled: false`. The same repository contains a separately deployable HTTP service exposing streamable MCP at `/mcp`, with OAuth/bearer verification, PostgreSQL storage/RLS, audit events, a 60-request fixed-window limit, and tools for connection status, search/fetch, clients, portfolio/risk comparison, and health snapshots. Commerce has 33 catalogued contracts but no registered tools or live adapter, and Prepare remains disabled pending first-party partner contracts; live Dext mode requires explicit flags, PostgreSQL, tenant-scoped envelope-encrypted credentials, and only `https://api.precision.dext.com/`, while no test contacts Dext.

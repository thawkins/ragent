The `Codex.Plugins.Marketplace` module defines an Elixir schema/parser for plugin marketplace data: a marketplace has `name`, optional `interface.displayName`, and a list of plugins; each plugin has `name`, `source`, `policy`, and `category`. Sources require `source` and `path` (with `source` normalized to `local` and paths via `Paths.normalize_marketplace_source_path`), while policies require `installation` (`InstallPolicy`), `authentication` (`AuthPolicy`), and optional `products`. It uses `Zoi` schemas with key normalization (`display_name` → `displayName`), preserves unrecognized keys as `extra`, and supports parse/from_map/to_map plus merge/put_plugin operations that can overwrite or return `:plugin_conflict` for duplicate plugin names.

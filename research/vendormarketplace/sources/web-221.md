Anthropic’s Claude Connectors, launched July 14, 2025, are direct integrations that let Claude access external apps and data inside a conversation; the directory has over 50 curated integrations and the broader ecosystem exceeds 200 as of mid-2026, all built on the Model Context Protocol (MCP), which Anthropic released Nov. 25, 2024, and donated to the Linux Foundation’s Agentic AI Foundation on Dec. 9, 2025. Categories include nine creative connectors (Apr. 28, 2026: Adobe Creative Cloud, Blender, Ableton Live, Autodesk Fusion, Affinity by Canva, Splice, Resolume Arena & Wire, SketchUp) available on all plans including Free; business/productivity (Google Workspace, Microsoft 365, Notion, Slack, Asana, HubSpot, Stripe, Intuit QuickBooks, Canva); legal (Claude for Legal, May 12, 2026, 20+ MCP connectors and 12 practice-area plugins including Thomson Reuters Westlaw, DocuSign, Box, iManage, Ironclad, Datasite); healthcare; and developer tools (Figma, Prisma, Socket, GitHub via Claude Desktop MCP). Connectors use OAuth and scoped permissions, with setup typically under a minute; Free users can use local desktop connectors and one custom MCP server, but the full remote directory requires a paid plan starting at $20/month (Pro), while custom MCP servers work on all plans. The guide also promotes Easy MCP AI, a WordPress plugin that turns a self-hosted site into a remote MCP server with 280+ structured tools, OAuth 2.1 with PKCE, refresh-token rotation, and Dynamic Client Registration (RFC 7591), compatible with Claude.ai, Claude Desktop, Claude Code, Cursor, and n8n; it offers a ~60-second setup and says future directions are enterprise-grade connectors, custom connector tooling, and agentic workflows.

`krmcbride/claude-plugins` is a personal Claude Code plugin marketplace whose `essentials@krmcbride` plugin provides UltraPlan for multi-step investigation with confidence states (exploring → low → medium → high → certain) and Sonnet validation; CodeReview with severity-classified findings (🔴 CRITICAL, 🟠 HIGH, 🟡 MEDIUM, 🟢 LOW), actionable fixes, and Top 3 priorities; Documentation Lookup via Context7’s HTTP API using a curl/code-execution pattern; code-examples via grep.app; a mechanical code-maintenance specialist for linting, renames, imports, and formatting; and Consensus, which runs three parallel Sonnet agents (FOR, AGAINST, NEUTRAL). Installation uses `/plugin marketplace add krmcbride/claude-plugins`, `/plugin install essentials@krmcbride`, then a Claude Code restart. It follows the Claude Code plugin specification with `.claude-plugin/marketplace.json`, plugin manifests, commands, agents, skills, and `.mcp.json`; MIT license.

Anthropic’s MCP-based Microsoft 365 Connector for Claude lets users search Outlook, SharePoint, OneDrive, and Teams inside Claude with read-only, permission-scoped access; it became available across all Claude plans (Free, Pro, Max, Team, Enterprise) in early April 2026. Setup requires a Microsoft 365 work account tied to an Entra tenant, Entra Global Admin consent (or manual service-principal setup with app IDs 08ad6f98-a4f8-4635-bb8d-f1a3044760f0 and 07c030f6-5743-41b7-ba00-0a6e85f37c17), plus a Claude Org Owner toggle for Team/Enterprise; admins can restrict access via Entra assignments and revoke Graph permissions. Unlike Microsoft-managed Copilot with Anthropic models, the Claude connector is managed by Anthropic/claude.ai. The connector does not cache file content, but retrieved content is retained in Claude conversations; encrypted sensitivity-label files are inaccessible, Team/Enterprise data is not used for training while Free/Pro/Max depends on privacy settings, refresh tokens expire after 90 days inactivity, activity is audited in Microsoft Purview/Graph API and Anthropic logs, and Anthropic cites SOC 2 Type II, ISO 27001, GDPR, and a DPA.

Airbyte Agent Connectors are standalone Python packages that let AI agents call third-party APIs through strongly typed, documented tools, with examples including Gong, Stripe, and GitHub and planned MCP/API exposure. They provide a consistent connector layout, generated Python clients, authentication/schema validation, and typed methods, and can be used with frameworks like PydanticAI and LangChain or custom agent loops; the repo includes a Claude Code skill for all 21 connectors. A roughly 15-minute tutorial uses `uv`, Pydantic AI, `airbyte-agent-github`, and `pydantic-ai` to configure `GITHUB_ACCESS_TOKEN` and `OPENAI_API_KEY`, then adds tools to list GitHub issues and pull requests with `openai:gpt-4o`. Planned additions include writes, MCP support, hosted execution/authentication/search, demo apps, starter templates, and more connectors weekly.

Claude Code and OpenAI Codex both support agent skills and plugin marketplaces, sharing a core `SKILL.md` package with name/description frontmatter, optional references/scripts/templates/assets, progressive loading, and model-invoked activation; plugins are installable bundles that can package many skills plus platform-specific capabilities such as commands, hooks, agents, MCP server config, app metadata, and visual assets. Differences include Claude Code’s `~/.claude/skills/`, `.claude/skills/`, and plugin `skills/` discovery, `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`, and `/plugin marketplace add` plus `/plugin install`, versus Codex’s `.codex-plugin/plugin.json`, `.agents/plugins/marketplace.json`, optional `agents/openai.yaml` per-skill metadata, `codex plugin marketplace add`, and `/plugins` browser. Alison’s LLM Skills Marketplace keeps cross-platform `SKILL.md` content and publishes both `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json` so the same skills can be distributed through both marketplace systems, with `agents/openai.yaml` as compatibility packaging around shared instructions.

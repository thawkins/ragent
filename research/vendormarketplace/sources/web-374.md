On June 11, 2026, xAI launched the Grok Build Plugin Marketplace in beta, built into the Grok Build CLI with an open GitHub index (`xai-org/plugin-marketplace`), SHA pinning of full 40-character commit hashes for every remote plugin, and a plugin format bundling six component types: skills, commands, agents, hooks, MCP servers, and LSP configs. Six launch partners—MongoDB, Vercel, Sentry, Chrome DevTools, Cloudflare, and Superpowers—provide integrations, but access requires SuperGrok ($300/mo) or X Premium Plus, with no free tier, and the catalog is initially thin. Compatibility includes existing Claude/Cursor MCP configs and native reading of `.claude/rules/` and `CLAUDE.md`, plus ACP support and a Python SDK at $1/M input and $2/M output tokens; requirements list macOS/Linux and grok-build-0.1 with a 256K context window. Security relies on SHA verification rather than code review, and xAI lacks Codex-style org-wide plugin governance; the article also notes Grok Build runs grok-code-fast-1, scoring 70.8% on SWE-Bench Verified, 15–18 points below Claude Opus 4.7 and GPT-5.5.

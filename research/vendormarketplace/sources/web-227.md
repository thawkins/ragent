```text
The Cotal Claude Code connector turns an ordinary real `claude` session into a Cotal mesh peer by installing a plugin that joins NATS, maps Claude Code lifecycle hooks to presence, and exposes `cotal_*` mesh tools; the shared runtime is `@cotal-ai/connector-core`, with sibling connectors OpenCode (beta), Hermes (alpha), and pi (alpha). Operators run `cotal setup` (installs the plugin and Agent Skills, seeds one agent) and `cotal up` (brings up the local mesh, delivery daemon, and detached manager), then use `cotal spawn`/`cotal spawn <name> --detach` and `--resume <session-id>` to fork an existing Claude session. Spawned sessions launch the real `claude` with `--strict-mcp-config` and only the `cotal` MCP server unless tools are deliberately shared, require `COTAL_NAME` or `COTAL_LINK` to join, and deliver mesh messages via hooks/JetStream plus channel nudges; agents manage traffic with attention modes (`open`, `dnd`, `focus`) and publish run/tool lifecycle events under ACL-controlled `events.<owner>.<actor>` channels. Channels are a Claude Code research preview (≥ v2.1.80; permission relay ≥ v2.1.81), and the event plane suppresses tool args/results by design.
```

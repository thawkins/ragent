According to Telerik UI for WinForms documentation, migrating a WinForms app from .NET Framework 4.8 or older to .NET Core or newer is generally not difficult; the example starts with a .NET Framework 4.7.2 project named **NetFrameworkDemo** containing a single **RadForm** with a **RadGridView** and migrates it to **.NET 6**. The steps are: create a new .NET 6 project; copy all files from the .NET Framework project into it; include those files and ensure **Program.cs** starts the desired form; install the needed NuGet package if necessary (the Telerik template installs **UI.for.WinForms.AllControls** by default); then build and run the project.

```text
.NET Upgrade Assistant is officially deprecated; Microsoft instead recommends the GitHub Copilot modernization chat agent included with Visual Studio 2026 and Visual Studio 2022 17.14.16 or later, which analyzes projects/dependencies, creates step-by-step migration plans, applies automated code fixes, and commits changes for validation or rollback. The deprecated tool helps upgrade .NET Framework, .NET Core, or .NET projects to newer .NET versions—built into Visual Studio or available as a CLI—and supports C# and Visual Basic projects including ASP.NET, Azure Functions, WPF, WinForms, class libraries, console apps, Xamarin.Forms, .NET MAUI, .NET Native, and UWP, with upgrade paths such as .NET Framework to .NET, .NET Core to .NET, Azure Functions v1-v3 to v4 isolated targeting net6.0+, UWP to WinUI 3, previous .NET to latest .NET, and Xamarin.Forms to .NET MAUI. It offers an analysis engine/report, in-place, side-by-side, and side-by-side incremental ASP.NET upgrade modes, upgrade status artifacts with success/warning/error indicators and Output-window logs; XAML transformations only support namespace upgrades.
```

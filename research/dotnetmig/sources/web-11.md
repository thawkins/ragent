GitHub Copilot upgrade is a GitHub Copilot agent available in Visual Studio, Visual Studio Code, GitHub Copilot CLI, and GitHub.com that helps upgrade and modernize .NET projects, offering scenarios for .NET version upgrades to .NET 8/9/10+, SDK-style conversion, Newtonsoft.Json-to-System.Text.Json, SqlClient, Azure Functions in-process to isolated worker, Semantic Kernel to Microsoft Agent Framework, Aspire integration/version upgrade, and WebForms-to-Blazor, plus 30+ built-in upgrade skills. It supports C# and Visual Basic projects including ASP.NET Core/Web Forms, Blazor, Azure Functions, WPF, WinForms, WinUI, .NET MAUI/Xamarin, class libraries, console, and test projects (MSTest, NUnit, xUnit), with supported paths from .NET Framework (any version) to .NET 8+ or .NET Framework 4.8.1, .NET Core 1.x–3.x to .NET 8+, and .NET 5+ to .NET 8+. The agent runs assessment, planning, and execution stages, saves state in .github/upgrades/{scenarioId} (assessment.md, upgrade-options.md, plan.md, tasks.md), recommends bottom-up, top-down, or all-at-once strategies, supports automatic or guided flow modes, and collects non-user-identifiable telemetry on project types, intent to upgrade, and upgrade duration; the Upgrade Dashboard is currently available only in GitHub Copilot CLI and the GitHub Copilot app. Azure migration is handled by the separate GitHub Copilot modernization agent.

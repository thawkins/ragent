.NET Upgrade Assistant analyzes and upgrades .NET Framework, .NET Core, and .NET projects (C# or Visual Basic) to newer .NET versions, supporting ASP.NET, Azure Functions, WPF, Windows Forms, class libraries, console apps, Xamarin Forms, .NET MAUI, and .NET Native UWP. Supported upgrade paths include .NET Framework/.NET Core to .NET, Azure Functions v1–v3 to v4 isolated (net6.0+), UWP to WinUI 3, previous .NET to latest, and Xamarin Forms to .NET MAUI; XAML transformations only support namespace upgrades. It is built into Visual Studio and available as a CLI, offers in-place, side-by-side, and side-by-side incremental upgrades (the last for ASP.NET to ASP.NET Core), and reports artifacts with status icons plus logs. Microsoft has officially deprecated .NET Upgrade Assistant, recommending the GitHub Copilot modernization chat agent included with Visual Studio 2026 and Visual Studio 2022 17.14.16 or later, which analyzes projects/dependencies, produces a step-by-step migration plan with recommendations and automated code fixes, and commits each change for validation or rollback.

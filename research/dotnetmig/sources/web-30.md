Microsoft’s .NET Upgrade Assistant, built into Visual Studio and available as a CLI, analyzes and upgrades .NET projects to newer .NET versions, including .NET Framework/.NET Core to .NET, Azure Functions v1–v3 to v4 isolated targeting net6.0+, UWP to WinUI 3, and Xamarin Forms to .NET MAUI; it supports C#/Visual Basic projects such as ASP.NET, Azure Functions, WPF, WinForms, class libraries, console apps, .NET MAUI, and .NET Native UWP, with in-place, side-by-side, or side-by-side incremental modes. It is officially deprecated in favor of the GitHub Copilot modernization chat agent included with Visual Studio 2026 and Visual Studio 2022 17.14.16 or later, which analyzes projects and dependencies, produces a step-by-step migration plan with recommendations and automated code fixes, commits each change for validation or rollback, and automates project-file updates, deprecated API replacement, and build-issue resolution. The Upgrade Assistant also generates an analysis report and status artifacts, though XAML transformations only support namespace upgrades.

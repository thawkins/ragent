GitHub Copilot modernization is an agentic, end-to-end solution for analyzing and upgrading Java, .NET, and C++ applications and migrating supported apps to Azure, delivered through a Modernize CLI modernization agent for assessment, migration planning, and framework upgrade automation across multiple apps plus an IDE experience for transformations such as Azure dependency migration, containerization, infrastructure-as-code generation, and Azure deployment, with humans reviewing recommendations and changes. Current availability includes GA IDE language/framework/toolset upgrades for .NET, Java, and C++, GA IDE migration scenarios for .NET and Java, and public preview Modernization agent CLI assessment/planning. It supports codebase analysis, OpenRewrite-based upgrades, AI predefined Azure migration tasks (e.g., secret management, message queues, identity), reusable migration patterns/custom skills from Git commits, build/test validation, CVE scanning and fixes in Agent Mode, and CI/CD/IaC deployment; after modernization, apps can integrate with Azure AI services including Microsoft Foundry’s 11,000+ models, App Service, Azure Container Apps, AKS, and AKS Automatic, and privacy terms state code snippets are not retained beyond the session and custom skills are not collected, transmitted, or stored.

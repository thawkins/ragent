```text
With Rider 2017.3.1, JetBrains extended Rider’s third-party-code debugging to Mono, making the feature—previously limited to .NET Framework and .NET Core—available across all runtimes and platforms (Windows, Mac, Linux, .NET Framework, .NET Core, Mono, and Unity). Users can debug without .pdb files by hitting F11 and having Rider decompile code on the fly, with the same Mono experience as .NET Framework/.NET Core, including navigating decompiled code, setting breakpoints, decompiling call stacks, and setting breakpoints when attaching to running processes. JetBrains also plans future SourceLink support and downloading symbol files from symbol servers.
```

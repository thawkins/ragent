In v24.2 (December 2024), DevExpress will drop support for .NET 6/7 and .NET Framework 4.5.2, 4.6, and 4.6.1, requiring at minimum .NET 8 for .NET Core products and .NET Framework 4.6.2 for .NET Framework products across WinForms, WPF, Blazor, ASP.NET Core, Reporting, Office File API, BI Dashboards, XAF, Web API Service, XPO, and ASP.NET WebForms/MVC 5/Bootstrap. .NET Framework products will require Visual Studio 2019+, .NET Core/.NET 8 products will require Visual Studio 2022, and .NET MAUI already requires .NET 8 and VS 2022. Reasons cited include Microsoft’s April 26, 2022 retirement of .NET Framework 4.5.2/4.6/4.6.1, .NET 7 end of support on May 14, 2024, .NET 6 end of support on November 12, 2024, security concerns, and migration to System.Text.Json. Existing customers targeting .NET Framework 4.6.2+ and .NET 8+ are unaffected; others must re-target, with DevExpress Project Converter v24.2 automating some updates for DevExpress projects, while .NET 8 assemblies can be used with .NET 9 and .NET Framework 4.6.2 assemblies with higher versions such as 4.8.1.

NVIDIA announced DGX Spark software updates rolling out (April 2026), with partner GB10 Grace Blackwell Superchip systems potentially lagging slightly behind; the release targets performance, stability, and workflow improvements across the OS, GPU stack, and connectivity. Key additions are enterprise management features: an Enterprise Management Guide for provisioning, updating, and fleet lifecycle management; an Out-of-Box-Experience (OOBE) bypass; USB and local repository support for installs/updates without cloud connectivity; support for air-gapped deployment and updates; and customized enterprise DGX OS ISOs via Cloud-init so units arrive pre-configured with site-specific users, network settings, software, and policies on first boot. The DGX Dashboard now includes Release Highlights to help users judge update urgency, and update instructions are available via NVIDIA's "OS and Component Update Guide — DGX Spark User Guide."

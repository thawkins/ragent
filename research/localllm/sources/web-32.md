```text
NVIDIA began rolling out a June 2026 DGX Spark software update as part of the GTC Taipei/Computex releases, with partner GB10 Grace Blackwell Superchip systems potentially lagging slightly behind. The update enhances the Out-of-Box-Experience (OOBE) with faster initial setup and easier discovery and installation of local AI agents; over-the-air (OTA) updates are no longer installed by default during setup so users can start sooner, and after first boot users are directed to the DGX Spark playbook site, which prominently features the NemoClaw playbook for streamlined setup of a sandboxed local agent. Additionally, two features are available outside the OTA update: the NVIDIA Sync Cluster Assistant, now accessible via the Settings page in the NVIDIA Sync app, supports connecting up to 3 devices without a network switch and up to 4 devices using one, while the NVIDIA Collective Communications Library (NCCL) version 2.30u1 adds updated support for connecting three DGX Spark systems in a ring topology.
```

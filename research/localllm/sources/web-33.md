NVIDIA's July 2026 Release for DGX Spark began rolling out in July 2026, with partner GB10 Grace Blackwell Superchip systems potentially lagging slightly behind. Key updates include improved Out-of-Memory (OOM) handling for GB10's unified memory architecture, which now provides user feedback during memory pressure to improve robustness and reliability when running larger models; adjustable Display Reserved Memory toggleable between 2GB (default) and 4GB to benefit workflows with many applications and windows, with no changes needed for "appliance mode" users; and enterprise management enhancements expanding the Cloud-Init initialization framework beyond direct USB to support DHCP, HTTP, and TFTP network protocols. Cloud-Init also adds support for customizing NVIDIA's "FastOS" recovery image for the DGX Spark Founder's Edition, alongside existing DGX OS customization support.

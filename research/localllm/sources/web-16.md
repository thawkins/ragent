```text
AMD claims its Ryzen AI MAX+ 395 "Strix Halo" APU delivers up to 3.05x the performance of NVIDIA's RTX 5080 in DeepSeek R1 benchmarks, an advantage that emerges once LLM model sizes exceed the RTX 5080's 16 GB VRAM limit, since the APU's 128 GB unified memory can allocate up to 96 GB as VRAM via Variable Graphics Memory (the RTX 5090 offers 32 GB but at 575W versus the 5080's 360W). AMD notes that for models fitting within the RTX 50-series GPUs' VRAM, the discrete cards still lead, positioning Strix Halo as a strong integrated all-in-one solution. The chip combines Zen 5 CPU cores with a 50 TOPS XDNA 2 NPU and integrated GPU, and AMD claims versus Intel competition it achieves up to 2.2x better token throughput (vs. Arc 140V), up to 4x faster time to first token on Llama 3.2 3B Instruct, 9.1x faster on 7–8B models, and 12.2x faster than Core Ultra 258V on 14B models, plus vision-model gains of up to 7x (IBM Granite Vision 3.2 3B), 4.6x (Gemma 3 4B), and 6x (Gemma 3 12B). Its memory pool also enables running models like Google Gemma 3 27B Vision in consumer applications such as LM Studio (llama.cpp), which rival APUs with 32 GB maximum memory cannot handle.
```

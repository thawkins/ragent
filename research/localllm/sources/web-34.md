NVIDIA announced (February 2026) that a new DGX Spark software update is rolling out to all systems, including partner systems built on the NVIDIA GB10 Grace Blackwell Superchip, delivering performance, stability, and workflow improvements across the OS, GPU stack, and connectivity. Key additions include hot-plug support for the ConnectX-7 network adapter, which can save up to 18W when the adapter is idle; improved multi-monitor, non-native resolution, and refresh rate compatibility; native Bluetooth audio support for headphones and headsets; and expanded security controls allowing Wi-Fi and Bluetooth to be disabled entirely at the UEFI level. Update instructions are available via the "OS and Component Update Guide" in the DGX Spark User Guide.

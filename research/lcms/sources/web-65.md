# SONAR: Multimodal Sentence Embeddings

The document introduces S ONAR, a multilingual and multimodal sentence embedding framework that significantly
outperforms existing models in multilingual similarity search tasks. It utilizes a single text encoder for 200 languages
and incorporates speech encoders trained through a teacher-student approach, enabling effective speech-to-text and
text-to-speech translation. The framework also includes a text decoder for machine translation, demonstrating
competitive results in zero-shot translation scenarios.

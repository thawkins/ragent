## About this course

This course is dedicated to programmers who are already familiar with the world of programming and are looking to become
acquainted with the Rust programming language. We designed this course to be a series of short, interactive articles
that you can skim, dive into, or even skip. We did this so that you can use this course to both learn Rust and to check
as a reference guide.

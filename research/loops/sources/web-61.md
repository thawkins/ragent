```text
The LinkedIn post by Miguel Fierro relays advice from Peter Steinberger, creator of OpenClaw: stop manually prompting AI agents and instead "design loops" in which the agent prompts itself—running, checking, and acting autonomously while the user steps away. In Claude Code this is done with a single command, /loop, which can be self-paced or scheduled (e.g., "/loop 5m run tests and fix failures," "/loop 1h check for new PR comments"), enabling automation such as fixing test suite failures, monitoring PRs and responding to comments, running refactors overnight, and polling APIs—usage the post claims is very cheap. Related discussion in the thread attributes a similar stance to Boris Cherny, creator of Claude Code ("I don't prompt Claude anymore. I write loops"), describing how effective loops require a detailed SOP (data, steps, tools, output standards, QA, guardrails), and noting the tradeoff that loops burn more tokens/compute but save developer time. One commenter pushes back, arguing that agentic loops optimize for correctness but lack a human "taste" step essential in domains like game development, where technically correct output can still feel wrong to users.
```

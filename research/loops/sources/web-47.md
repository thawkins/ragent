This LinkedIn post by Rakesh Gohel lists nine practical LLM agent workflow patterns for beginners—Prompt Chaining, Parallelization, Orchestrator-Worker, Evaluator-Optimizer, Routing, and Autonomous Workflow (with linked code samples), plus Reflexion, ReWOO (Reasoning Without Observation), and Plan-and-Execute (with LangGraph implementations)—each briefly defined by how it decomposes, delegates, evaluates, or routes tasks. Accompanying commentary ("Every Workflow Breaks Without A2SPA") argues that all of these patterns are spoofable, prompt-injectable, or replayable because "every agent framework today runs unauthenticated by default," and promotes A2SPA as "the first protocol" to sign, verify, and log every payload handoff with replay protection (e.g., only cryptographically signed payloads enter parallelization merges, and tasks cannot begin unless verified). The commentary attributes A2SPA to Devin, Gavin, and Jonathan Capriola and states that patents have been filed with 40 claims pending.

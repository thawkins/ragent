```text
Nate Herkelman explains that an agent loop is simply a cycle in which an AI agent reasons about what to do, acts, observes the result, and repeats until it hits a stop condition—framed in his 14-minute YouTube video as "loop engineering," i.e., replacing yourself as the prompter by designing the system that prompts agents. He argues the most critical component is verification: a loop is only as good as its "done" check, so builders must define what "done" means and how the agent verifies it (e.g., a game is checked visually and by playing it; a script by flow and tone). Noting that Boris Cherny and Peter Steinberger say they no longer prompt coding agents but write loops instead, he contends that 24/7 agent fleets may suit full-time coders (potentially 10x-ing output) but aren't necessary for knowledge work—his own practice is to launch one substantial loop before bed, let it run a few hours, and iterate on the results himself. He demonstrates the approach with demos including a thumbnail scorer, a Three.js spinning plane, and an Abbey Road recreation in pure code, emphasizing that loops improve first-try quality through automated iteration rather than producing flawless one-shot outputs.
```

At SCaLE 23x, the presentation "The Agentic Loop: Accelerating Firmware Development for Microcontrollers" (Room 211, Saturday, March 7, 2026, 18:15–19:15) will explore using agentic AI loops to speed up research, development, and programming of firmware for microcontrollers (MCUs) and Single Board Computers (SBCs). The session explains the agentic loop—an iterative cycle in which an AI agent plans, executes code such as a firmware sketch, processes outputs like error logs and sensor readings, and refines its approach—and covers key implementation techniques, including Retrieval-Augmented Generation (RAG) to ground the agent with datasheets, schematics, and example codebases, plus a live demonstration using the Gemini Command Line Interface to program devices such as the Arduino, ESP32, and Raspberry Pi Pico. Aimed at firmware engineers, hobbyists, and AI developers, the talk argues that offloading API memorization and syntax debugging to AI agents lets developers focus on higher-level design, shortening the embedded R&D lifecycle.
